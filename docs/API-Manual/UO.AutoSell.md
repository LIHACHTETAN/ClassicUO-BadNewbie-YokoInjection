# UO.AutoSell

ClassicUO • Runtime API • `UO.AutoSell.md`

Создаёт или обновляет правило продажи по типу и цвету в основном списке текущего профиля. Положительное Quantity — общий лимит на одно поступление списка продажи вендора; Quantity <= 0 удаляет правило. Дополнительные именованные списки не изменяются этой командой. Для продажи должны быть включены общий переключатель и основной список. Выключенный список сам не включается, совпадающие правила не удваивают количество.

## Точный синтаксис / Registered signatures

```text
UO.AutoSell(ItemType:Any, ItemColor:Any, Quantity:Any) -> Unit
```

Порядок аргументов соответствует строкам выше. `Unit` означает отсутствие возвращаемого значения. `Any` — значение BASIC с преобразованием при вызове. Имена нечувствительны к регистру.

## Варианты использования

Это отдельные сценарии. Подставьте свои serial, пути и координаты; серверные действия зависят от текущего состояния игры.

### Прямой вызов

```vb
SUB Main()
    UO.AutoSell(1, 2, 3)
END SUB
```

### Вызов с явно заданными аргументами

```vb
SUB Main()
    VAR arg1 = 1 # ItemType
    VAR arg2 = 2 # ItemColor
    VAR arg3 = 3 # Quantity
    UO.AutoSell(arg1, arg2, arg3)
END SUB
```

### Выполнение действия внутри процедуры

```vb
SUB ReadResult()
    VAR arg1 = 1 # ItemType
    VAR arg2 = 2 # ItemColor
    VAR arg3 = 3 # Quantity
    UO.AutoSell(arg1, arg2, arg3)
END SUB

SUB Main()
    ReadResult()
END SUB
```

## Возвращает

Unit — команда не возвращает значение. Вызывайте её отдельной строкой. Не используйте её результат как serial, type или логический признак успеха. Завершение вызова само по себе не подтверждает выполнение действия сервером.

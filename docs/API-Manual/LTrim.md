# LTrim

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->

Удаляет крайние пробельные символы слева.

## Точный синтаксис

```text
LTrim(value:String) -> String
```

Выберите одну из зарегистрированных форм. Параметры передаются позиционно. Any означает значение BASIC с преобразованием внутри команды; Unit — отсутствие возвращаемого значения.

## Параметры

- `value` — Исходная строка; исходная переменная не изменяется.

## Возвращает

String — преобразованный текст. Пустая строка остаётся пустой. Изменение регистра использует invariant Unicode-правила; Trim/LTrim/RTrim удаляют Unicode whitespace, сохраняя пробелы внутри текста.

## Поведение

- Выполняется локально и не обращается к игровому серверу. Исходная строка не изменяется: результат нужно сохранить или передать дальше.
- Позиции и длины строк считаются в единицах UTF-16. Символ за пределами BMP, например emoji, занимает две единицы. Это не количество байтов UTF-8.

## Примеры

### Пример 1. Преобразовать текст

```vb
# Преобразовать текст
#
# Удаляет крайние пробельные символы слева.
#
# String — преобразованный текст. Пустая строка остаётся пустой. Изменение регистра использует
# invariant Unicode-правила; Trim/LTrim/RTrim удаляют Unicode whitespace, сохраняя пробелы
# внутри текста.

SUB Main()
    # value содержит показанный исходный текст.
    # Ожидаемый результат: 'text  '. В result сохраняется результат выражения; Print только
    # показывает его.

    VAR result = LTrim('  text  ')
    UO.Print(CStr(result))
END SUB
```

**Разбор параметров и выполнения:**

- value содержит показанный исходный текст.
- Ожидаемый результат: 'text  '. В result сохраняется результат выражения; Print только показывает его.

```vb
# Проверить без изменения исходной переменной
#
# Удаляет крайние пробельные символы слева.
#
# String — преобразованный текст. Пустая строка остаётся пустой. Изменение регистра использует
```

# Sgn

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->

Возвращает знак числа.

## Точный синтаксис

```text
Sgn(value:Any) -> Integer
```

Выберите одну из зарегистрированных форм. Параметры передаются позиционно. Any означает значение BASIC с преобразованием внутри команды; Unit — отсутствие возвращаемого значения.

## Параметры

- `value` — Обязательное число Integer/Decimal либо десятичная строка с точкой и необязательной экспонентой, например "-1.25e2". Язык интерфейса не влияет. Нераспознанный текст (включая hex-строку), Unit, Array и Object дают 0; числовой hex-литерал уже является Integer. Возможны NaN/Infinity. -1 для отрицательного, 0 для нуля, +1 для положительного. NaN вызывает математическую ошибку, бесконечности возвращают свой знак.

## Возвращает

Integer — sign(value). -1 для отрицательного, 0 для нуля, +1 для положительного. NaN вызывает математическую ошибку, бесконечности возвращают свой знак. Число, не ID и не признак успеха; 1/0 здесь нельзя трактовать как выполнено/не выполнено.

## Поведение

- Вычисляется локально в потоке скрипта: без запроса серверу, движения, прицела, ожидания и изменения глобальных переменных.
- Decimal хранится как двоичный Double, не .NET decimal. Результат может быть приближённым; сравнивайте конечные дробные значения с допуском. NaN/Infinity не используйте как координаты или количество предметов.
- -1 для отрицательного, 0 для нуля, +1 для положительного. NaN вызывает математическую ошибку, бесконечности возвращают свой знак.

#### 2. BasicDouble

BasicDouble сохраняет Integer/Decimal, читает строку через инвариантный NumberStyles.Float, для неподдерживаемого значения даёт 0. Abs обрабатывает обычный Integer напрямую до перехода к Double.

Обязательное число Integer/Decimal либо десятичная строка с точкой и необязательной экспонентой, например "-1.25e2". Язык интерфейса не влияет. Нераспознанный текст (включая hex-строку), Unit, Array и Object дают 0; числовой hex-литерал уже является Integer. Возможны NaN/Infinity.

## Примеры

### Пример 1. Прямое вычисление

```vb
# Прямое вычисление
#
# Возвращает знак числа.
#
# Integer — sign(value). -1 для отрицательного, 0 для нуля, +1 для положительного. NaN вызывает
# математическую ошибку, бесконечности возвращают свой знак. Число, не ID и не признак успеха;
# 1/0 здесь нельзя трактовать как выполнено/не выполнено.

SUB Main()
    # value = -8; ожидается -1 (~ означает приближённо). value хранит результат, CStr лишь
    # форматирует его для Print.

    VAR value = Sgn(-8)
    UO.Print(CStr(value))
END SUB
```

**Разбор параметров и выполнения:**

- value = -8; ожидается -1 (~ означает приближённо). value хранит результат, CStr лишь форматирует его для Print.

### Пример 3. Полная вспомогательная функция

```vb
# Полная вспомогательная функция
#
# Возвращает знак числа.
#
# Integer — sign(value). -1 для отрицательного, 0 для нуля, +1 для положительного. NaN вызывает
# математическую ошибку, бесконечности возвращают свой знак. Число, не ID и не признак успеха;
# 1/0 здесь нельзя трактовать как выполнено/не выполнено.

# manual-check: scalar-math Sgn
SUB Main()
    # current/destination задают смещение по одной оси. StepToward даёт -1/0/1, не код восьми
    # направлений; движения нет.

    VAR value = StepToward(12,10)
    UO.Print(CStr(value))
END SUB

SUB StepToward(current,destination)
    RETURN Sgn(CDbl(destination)-CDbl(current))
END SUB
```

**Разбор параметров и выполнения:**

- current/destination задают смещение по одной оси. StepToward даёт -1/0/1, не код восьми направлений; движения нет.

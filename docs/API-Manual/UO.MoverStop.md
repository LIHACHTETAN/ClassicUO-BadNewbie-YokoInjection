# UO.MoverStop

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->

Останавливает автоматический маршрут Pathfinder.

## Точный синтаксис

```text
UO.MoverStop() -> Unit
```

Выберите одну из зарегистрированных форм. Параметры передаются позиционно. Any означает значение BASIC с преобразованием внутри команды; Unit — отсутствие возвращаемого значения.

## Параметры

Параметров нет.

## Возвращает

Unit — возвращаемого значения нет. Вызывайте отдельной строкой; это не true/false и не число шагов.

## Поведение

- Снимает локальное автоматическое движение. Уже отправленные шаги и серверные подтверждения не отзываются.
- Это не TerminateAll: выполнение остальных строк скрипта и других процедур продолжается.

## Примеры

### Пример 1. Снять маршрут

```vb
# Снять маршрут
#
# Останавливает автоматический маршрут Pathfinder.
#
# Unit — возвращаемого значения нет. Вызывайте отдельной строкой; это не true/false и не число
# шагов.

SUB Main()
    # Аргументов нет.
    # Команда не возвращает код успеха.

    UO.MoverStop()
END SUB
```

**Разбор параметров и выполнения:**

- Аргументов нет.
- Команда не возвращает код успеха.

### Пример 2. Остановить только при активном маршруте

```vb
# Остановить только при активном маршруте
#
# Останавливает автоматический маршрут Pathfinder.
#
# Unit — возвращаемого значения нет. Вызывайте отдельной строкой; это не true/false и не число
# шагов.

SUB Main()
    # Move() читает автоматическое движение.
    # Print — локальное сообщение скрипта; оно не является подтверждением сервера.

    IF UO.Move() THEN
        UO.MoverStop()
        UO.Print('Route stopped')
    END IF
END SUB
```

**Разбор параметров и выполнения:**

- Move() читает автоматическое движение.
- Print — локальное сообщение скрипта; оно не является подтверждением сервера.

### Пример 3. Прекратить движение и проверить позицию

```vb
# Прекратить движение и проверить позицию
#
# Останавливает автоматический маршрут Pathfinder.
#
# Unit — возвращаемого значения нет. Вызывайте отдельной строкой; это не true/false и не число
# шагов.

SUB Main()
    # WAIT=100 мс даёт клиенту обработать очередные события.
    # После остановки координаты читаются отдельно; задержка не гарантирует получение всех сетевых
    # подтверждений.

    UO.MoverStop()
    WAIT(100)
    UO.Print(STR(UO.GetX()) + ',' + STR(UO.GetY()))
END SUB
```

**Разбор параметров и выполнения:**

- WAIT=100 мс даёт клиенту обработать очередные события.
- После остановки координаты читаются отдельно; задержка не гарантирует получение всех сетевых подтверждений.

# UO.GumpAutoCheckBox

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: ko -->

처음 일치하는 서버 검프의 컨트롤에 값을 한 번 설정합니다. 컨트롤이 없으면 대기 작업을 저장합니다.

## 정확한 구문

```text
UO.GumpAutoCheckBox(CheckBoxID:Any, Value:Any) -> Unit
```

## 매개변수

- `CheckBoxID` — Integer — 해당 종류 컨트롤의 정확한 ID입니다. 인덱스, GumpID, 창의 serial이 아닙니다. 0은 일반 ID이며 첫 컨트롤을 대신 선택하지 않습니다.
- `Value` — Integer — 1은 활성화, 0은 비활성화입니다. 다른 0이 아닌 숫자도 활성화하지만 0/1을 권장합니다. 라디오 버튼을 선택하면 같은 그룹의 다른 선택은 해제됩니다.

## 반환값

Unit — 반환값이 없습니다. 성공 여부, 새 값, 서버 확인 중 어느 것도 반환하지 않습니다.

## 동작

- 현재 UI 순서로 열린 창을 확인한 다음 수신되거나 다시 구성된 서버 레이아웃을 확인합니다. 종류와 ID가 처음 일치하면 한 번 소모됩니다. 특정 창에는 인덱스를 지정하는 NumGump*를 사용하세요.
- 대기 중인 입력은 자동 버튼 응답보다 먼저 적용됩니다. 같은 스크립트에서 같은 종류와 ID를 다시 지정하면 미실행 값을 교체합니다. 클라이언트의 대기 입력은 최대 1024개이며 초과하면 스크립트 오류입니다.
- 프로시저가 정상 종료되어도 대기 작업은 남습니다. 소유자 취소 또는 이름을 지정한 Terminate는 해당 작업을 지웁니다. TerminateAll은 종료된 프로시저가 남긴 작업도 모두 지웁니다. 월드 변경 시에도 큐를 비웁니다. 프로필에는 저장하지 않습니다.

## 예제

### 열린 컨트롤 채우기

```vb
# 열린 컨트롤 채우기
#
# 처음 일치하는 서버 검프의 컨트롤에 값을 한 번 설정합니다. 컨트롤이 없으면 대기 작업을 저장합니다.
#
# Unit — 반환값이 없습니다. 성공 여부, 새 값, 서버 확인 중 어느 것도 반환하지 않습니다.

SUB Main()
    # 33은 예시 컨트롤 ID입니다. InfoGump에서 확인한 실제 ID로 바꾸세요. 두 번째 인수는 설정값입니다. 컨트롤이 없으면 작업이 대기합니다.

    UO.GumpAutoCheckBox(33, 1)
END SUB
```

**매개변수 및 실행 설명:**

- 33은 예시 컨트롤 ID입니다. InfoGump에서 확인한 실제 ID로 바꾸세요. 두 번째 인수는 설정값입니다. 컨트롤이 없으면 작업이 대기합니다.

### 열기 전에 입력 준비

```vb
# 열기 전에 입력 준비
#
# 처음 일치하는 서버 검프의 컨트롤에 값을 한 번 설정합니다. 컨트롤이 없으면 대기 작업을 저장합니다.
#
# Unit — 반환값이 없습니다. 성공 여부, 새 값, 서버 확인 중 어느 것도 반환하지 않습니다.

SUB Main()
    # 33은 컨트롤 ID, 100은 예시 확인 ButtonID, 0x40001234는 양식을 여는 오브젝트의 serial입니다. 모두 실제 값으로 바꾸세요. 창이 나중에
    # 도착해도 응답 전에 입력합니다.

    UO.GumpAutoCheckBox(33, 1)
    UO.WaitGump(100)
    UO.UseObject('0x40001234')
END SUB
```

**매개변수 및 실행 설명:**

- 33은 컨트롤 ID, 100은 예시 확인 ButtonID, 0x40001234는 양식을 여는 오브젝트의 serial입니다. 모두 실제 값으로 바꾸세요. 창이 나중에 도착해도 응답 전에 입력합니다.

### 대기 값 교체

```vb
# 대기 값 교체
#
# 처음 일치하는 서버 검프의 컨트롤에 값을 한 번 설정합니다. 컨트롤이 없으면 대기 작업을 저장합니다.
#
# Unit — 반환값이 없습니다. 성공 여부, 새 값, 서버 확인 중 어느 것도 반환하지 않습니다.

SUB Main()
    # 두 호출 모두 ID 33을 사용합니다. 컨트롤이 아직 없으면 마지막 값이 남습니다. 이미 열려 있으면 호출 순서대로 두 변경을 즉시 적용합니다.

    UO.GumpAutoCheckBox(33, 1)
    UO.GumpAutoCheckBox(33, 0)
END SUB
```

**매개변수 및 실행 설명:**

- 두 호출 모두 ID 33을 사용합니다. 컨트롤이 아직 없으면 마지막 값이 남습니다. 이미 열려 있으면 호출 순서대로 두 변경을 즉시 적용합니다.

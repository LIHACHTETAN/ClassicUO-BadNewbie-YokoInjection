# Cos

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->

Вычисляет косинус.

## Точный синтаксис

```text
Cos(radians:Any) -> Decimal
```

Выберите одну из зарегистрированных форм. Параметры передаются позиционно. Any означает значение BASIC с преобразованием внутри команды; Unit — отсутствие возвращаемого значения.

## Параметры

- `radians` — Обязательное число Integer/Decimal либо десятичная строка с точкой и необязательной экспонентой, например "-1.25e2". Язык интерфейса не влияет. Нераспознанный текст (включая hex-строку), Unit, Array и Object дают 0; числовой hex-литерал уже является Integer. Возможны NaN/Infinity. Вход в радианах, не градусах и не игровых направлениях. Конечный результат в [-1,1]; NaN/бесконечный аргумент дают NaN.

## Возвращает

Decimal — cos(radians). Вход в радианах, не градусах и не игровых направлениях. Конечный результат в [-1,1]; NaN/бесконечный аргумент дают NaN. Число, не ID и не признак успеха; 1/0 здесь нельзя трактовать как выполнено/не выполнено.

## Поведение

- Вычисляется локально в потоке скрипта: без запроса серверу, движения, прицела, ожидания и изменения глобальных переменных.
- Decimal хранится как двоичный Double, не .NET decimal. Результат может быть приближённым; сравнивайте конечные дробные значения с допуском. NaN/Infinity не используйте как координаты или количество предметов.
- Вход в радианах, не градусах и не игровых направлениях. Конечный результат в [-1,1]; NaN/бесконечный аргумент дают NaN.

### Внутренние функции: от вызова до результата

Ниже реальные этапы регистрации и преобразования. Полные функции примеров показывают полезные формулы скрипта, не заменяя математическую реализацию платформы.

#### 1. Register

Register связывает имя BASIC с одним аргументом с нативным вычислением. После преобразования вызывается System.Math; скрытые скрипты и процедуры сервера не запускаются.

Decimal — cos(radians). Вход в радианах, не градусах и не игровых направлениях. Конечный результат в [-1,1]; NaN/бесконечный аргумент дают NaN. Число, не ID и не признак успеха; 1/0 здесь нельзя трактовать как выполнено/не выполнено.

Исходник проекта: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApi.cs`; функция `Register`.

#### 2. BasicDouble

BasicDouble сохраняет Integer/Decimal, читает строку через инвариантный NumberStyles.Float, для неподдерживаемого значения даёт 0. Abs обрабатывает обычный Integer напрямую до перехода к Double.

Обязательное число Integer/Decimal либо десятичная строка с точкой и необязательной экспонентой, например "-1.25e2". Язык интерфейса не влияет. Нераспознанный текст (включая hex-строку), Unit, Array и Object дают 0; числовой hex-литерал уже является Integer. Возможны NaN/Infinity.

Исходник проекта: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApi.cs`; функция `BasicDouble`.

## Примеры

### Пример 1. Прямое вычисление

```vb
# Прямое вычисление
#
# Вычисляет косинус.
#
# Decimal — cos(radians). Вход в радианах, не градусах и не игровых направлениях. Конечный
# результат в [-1,1]; NaN/бесконечный аргумент дают NaN. Число, не ID и не признак успеха; 1/0
# здесь нельзя трактовать как выполнено/не выполнено.

SUB Main()
    # radians = 0; ожидается 1 (~ означает приближённо). value хранит результат, CStr лишь
    # форматирует его для Print.

    VAR value = Cos(0)
    UO.Print(CStr(value))
END SUB
```

**Разбор параметров и выполнения:**

- radians = 0; ожидается 1 (~ означает приближённо). value хранит результат, CStr лишь форматирует его для Print.

### Пример 2. Другой аргумент через переменную

```vb
# Другой аргумент через переменную
#
# Вычисляет косинус.
#
# Decimal — cos(radians). Вход в радианах, не градусах и не игровых направлениях. Конечный
# результат в [-1,1]; NaN/бесконечный аргумент дают NaN. Число, не ID и не признак успеха; 1/0
# здесь нельзя трактовать как выполнено/не выполнено.

SUB Main()
    # radians = 3.141592653589793; ожидается ~-1 (~ означает приближённо). value хранит результат,
    # CStr лишь форматирует его для Print.

    VAR inputValue = 3.141592653589793
    VAR value = Cos(inputValue)
    UO.Print(CStr(value))
END SUB
```

**Разбор параметров и выполнения:**

- radians = 3.141592653589793; ожидается ~-1 (~ означает приближённо). value хранит результат, CStr лишь форматирует его для Print.

### Пример 3. Полная вспомогательная функция

```vb
# Полная вспомогательная функция
#
# Вычисляет косинус.
#
# Decimal — cos(radians). Вход в радианах, не градусах и не игровых направлениях. Конечный
# результат в [-1,1]; NaN/бесконечный аргумент дают NaN. Число, не ID и не признак успеха; 1/0
# здесь нельзя трактовать как выполнено/не выполнено.

# manual-check: scalar-math Cos
SUB Main()
    # degrees — градусы; pi/180 переводит их в радианы перед Cos. CosineDegrees(60)≈0.5.

    VAR value = CosineDegrees(60)
    UO.Print(CStr(value))
END SUB

SUB CosineDegrees(degrees)
    RETURN Cos(degrees*3.141592653589793/180)
END SUB
```

**Разбор параметров и выполнения:**

- degrees — градусы; pi/180 переводит их в радианы перед Cos. CosineDegrees(60)≈0.5.

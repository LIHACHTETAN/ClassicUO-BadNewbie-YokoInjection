# UO.CharTitle

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: ru -->

Читает титул персонажа.

## Точный синтаксис

```text
UO.CharTitle() -> Any
```

## Параметры

Параметров нет.

## Возвращает

String — известное клиенту титул. Пустая строка означает пустое/неизвестное значение либо отсутствие объекта. Это не serial и не путь профиля. Игровое имя/титул не переводится по языку IDE.

## Поведение

- Читаются уже полученные локальные данные. Запрос не открывает status и не заставляет сервер прислать обновление. После смерти, перехода карты или удаления объекта значения могут измениться между двумя вызовами.
- Это функции чтения: присваивание результата переменной сохраняет снимок. Оно не изменяет характеристику персонажа. Имена нечувствительны к регистру; используйте именно показанную форму с нужным числом аргументов.

## Примеры

### Показать текст после входа

```vb
# Показать текст после входа
#
# Читает титул персонажа.
#
# String — известное клиенту титул. Пустая строка означает пустое/неизвестное значение либо
# отсутствие объекта. Это не serial и не путь профиля. Игровое имя/титул не переводится по языку
# IDE.

SUB Main()
    # Параметров нет: читается self.
    # Пустая строка обрабатывается явно; это не текст "0".

    VAR text = UO.CharTitle()
    IF text <> '' THEN
        UO.Print(text)
    ELSE
        UO.Print('Text is unavailable')
    END IF
END SUB
```

**Разбор параметров и выполнения:**

- Параметров нет: читается self.
- Пустая строка обрабатывается явно; это не текст "0".

### Сравнить два снимка

```vb
# Сравнить два снимка
#
# Читает титул персонажа.
#
# String — известное клиенту титул. Пустая строка означает пустое/неизвестное значение либо
# отсутствие объекта. Это не serial и не путь профиля. Игровое имя/титул не переводится по языку
# IDE.

SUB Main()
    # Оба вызова относятся к self; WAIT задаёт паузу 1000 мс.
    # Различие может означать обновление данных либо выход из мира. Пример не меняет имя или титул.

    VAR previous = UO.CharTitle()
    WAIT(1000)
    VAR current = UO.CharTitle()
    IF previous <> current THEN
        UO.Print('Updated text: ' + current)
    END IF
END SUB
```

**Разбор параметров и выполнения:**

- Оба вызова относятся к self; WAIT задаёт паузу 1000 мс.
- Различие может означать обновление данных либо выход из мира. Пример не меняет имя или титул.

# UO.InfoTile

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: ru -->

Показывает сведения о земле/статическом объекте текущей карты.

## Точный синтаксис

```text
UO.InfoTile() -> Unit
UO.InfoTile(x:Any) -> Unit
UO.InfoTile(x:Any, y:Any) -> Unit
```

## Параметры

- `x` — Мировая координата X. В форме с одним аргументом Y берётся у персонажа.
- `y` — Мировая координата Y. Два аргумента задают X/Y; параметров Z или map у этой команды нет.

## Возвращает

Unit — возвращаемого значения нет. Результат нельзя присвоить как serial, graphic/type, количество или true/false. Информация выводится в интерфейс/журнал, а не возвращается скрипту.

## Поведение

- Интерактивная команда без аргументов открывает прицел для земли/статики; выбор предмета или персонажа отклоняется. Выбранный тайл показывается в окне и журнале.
- Обычный скрипт без аргументов читает X/Y персонажа без прицела. Координатные формы ищут именно землю (Land) указанной клетки: они не выбирают статический слой по Z.
- В командном режиме найденная земля показывается также в окне. В обычном скрипте сведения выводятся в журнал. Для чтения статических записей массивом используйте GetStaticTileData/GetWorldCell.
- Карта должна быть загружена. При отсутствии земли возвращаемого объекта нет — выводится сообщение.

## Примеры

### Земля под персонажем

```vb
# Земля под персонажем
#
# Показывает сведения о земле/статическом объекте текущей карты.
#
# Unit — возвращаемого значения нет. Результат нельзя присвоить как serial, graphic/type,
# количество или true/false. Информация выводится в интерфейс/журнал, а не возвращается скрипту.

SUB Main()
    # Аргументов нет; в процедуре X/Y берутся у персонажа.
    # Это вывод информации, а не Array или номер слоя.

    UO.InfoTile()
END SUB
```

**Разбор параметров и выполнения:**

- Аргументов нет; в процедуре X/Y берутся у персонажа.
- Это вывод информации, а не Array или номер слоя.

### Заданная клетка

```vb
# Заданная клетка
#
# Показывает сведения о земле/статическом объекте текущей карты.
#
# Unit — возвращаемого значения нет. Результат нельзя присвоить как serial, graphic/type,
# количество или true/false. Информация выводится в интерфейс/журнал, а не возвращается скрипту.

SUB Main()
    # x=1445, y=1690 — клетка текущей карты.
    # Команда описывает землю этой клетки; для статического объекта нужен интерактивный выбор либо
    # API чтения статик.

    UO.InfoTile(1445, 1690)
END SUB
```

**Разбор параметров и выполнения:**

- x=1445, y=1690 — клетка текущей карты.
- Команда описывает землю этой клетки; для статического объекта нужен интерактивный выбор либо API чтения статик.

### Соседняя клетка по X

```vb
# Соседняя клетка по X
#
# Показывает сведения о земле/статическом объекте текущей карты.
#
# Unit — возвращаемого значения нет. Результат нельзя присвоить как serial, graphic/type,
# количество или true/false. Информация выводится в интерфейс/журнал, а не возвращается скрипту.

SUB Main()
    # Передан только x; Y остаётся координатой персонажа.
    # Высота и map аргументами не задаются.

    VAR x = UO.GetX() + 1
    UO.InfoTile(x)
END SUB
```

**Разбор параметров и выполнения:**

- Передан только x; Y остаётся координатой персонажа.
- Высота и map аргументами не задаются.

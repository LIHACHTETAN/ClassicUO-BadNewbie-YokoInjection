# UO.GetSkillCurrentValue

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: ru -->

Читает эффективное значение навыка с модификаторами.

## Точный синтаксис

```text
UO.GetSkillCurrentValue(SkillName:Any) -> Decimal
```

## Параметры

- `SkillName` — Обязательный навык: имя из данных клиента, например "Mining" или "Animal Lore", либо десятичный индекс от 0 до Skills.Length−1, числом или строкой. Регистр имени не важен, крайние пробелы удаляются, _ заменяется пробелом. Индекс не является ID предмета или индексом от 1. Числовая строка всегда означает индекс.

## Возвращает

Decimal (Double) — очки навыка с шагом 0,1, например 95,1, а не 951. Поле ValueFixed делится на 10 непосредственно в Double. 0 означает нулевой навык либо отсутствие персонажа/навыка. Результат не Boolean. Legacy SkillVal/BaseVal имеют другой масштаб — не смешивайте эти семейства.

## Поведение

- Чтение выполняется через Invoke на игровом потоке по уже полученным данным; сетевые пакеты не отправляются. Навык не используется и не тренируется. Два запроса — два отдельных снимка.
- Обязательный навык: имя из данных клиента, например "Mining" или "Animal Lore", либо десятичный индекс от 0 до Skills.Length−1, числом или строкой. Регистр имени не важен, крайние пробелы удаляются, _ заменяется пробелом. Индекс не является ID предмета или индексом от 1. Числовая строка всегда означает индекс.
- ExecuteStealthCompatibility выбирает ветку команды. Text читает селектор навыка, Arg — числовые номера и режимы. Непреобразуемый аргумент может завершить вызов ошибкой преобразования.

ExecuteStealthCompatibility выбирает ветку команды. Text читает селектор навыка, Arg — числовые номера и режимы. Непреобразуемый аргумент может завершить вызов ошибкой преобразования.

Исходник проекта: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApiUO.cs`; функция `ExecuteStealthCompatibility`.

#### 2. Invoke

Invoke выполняет чтение на игровом потоке; с рабочего потока ожидается обработка запроса менеджером. Отмена скрипта прерывает ожидание. Паузы и дополнительные сетевые запросы не добавляются.

Чтение выполняется через Invoke на игровом потоке по уже полученным данным; сетевые пакеты не отправляются. Навык не используется и не тренируется. Два запроса — два отдельных снимка.

Исходник проекта: `src/ClassicUO.Client/Game/Managers/ClassicUOInjectionApiBridge.cs`; функция `Invoke`.

#### 3. FindSkillUnsafe

FindSkillUnsafe: сначала проверяет десятичный индекс и его границы; иначе нормализует имя и ищет точное совпадение Skill.Name без учёта регистра. Неизвестное имя даёт null, прицел не открывается.

Для неизвестного навыка или отсутствующего персонажа возвращается −1.

Исходник проекта: `src/ClassicUO.Client/Game/Managers/ClassicUOInjectionApiBridge.cs`; функция `FindSkillUnsafe`.

Исходник проекта: `src/ClassicUO.Client/Game/Managers/ClassicUOInjectionApiBridge.cs`; функция `GetSkillValue`.

```vb
# на 10 непосредственно в Double. 0 означает нулевой навык либо отсутствие персонажа/навыка.
```

### Применить в условии или сравнении

```vb
# Применить в условии или сравнении
#
# Читает эффективное значение навыка с модификаторами.
#
# Decimal (Double) — очки навыка с шагом 0,1, например 95,1, а не 951. Поле ValueFixed делится
# на 10 непосредственно в Double. 0 означает нулевой навык либо отсутствие персонажа/навыка.
# Результат не Boolean. Legacy SkillVal/BaseVal имеют другой масштаб — не смешивайте эти

SUB Main()
    # Порог 95.1 и режимы 0/1/2 заданы для примера. −1 проверяется до изменения режима. После записи
```

### Полная вспомогательная функция

```vb
# Полная вспомогательная функция
#
# Читает эффективное значение навыка с модификаторами.
#
# Decimal (Double) — очки навыка с шагом 0,1, например 95,1, а не 951. Поле ValueFixed делится
# на 10 непосредственно в Double. 0 означает нулевой навык либо отсутствие персонажа/навыка.
# Результат не Boolean. Legacy SkillVal/BaseVal имеют другой масштаб — не смешивайте эти
# семейства.

SUB Main()
    # Весь код помощника приведён ниже Main. selector выбирает навык/характеристику, mode задаёт
    # режим записи. ReadValue/ReadMode возвращают исходное число; ApplyMode проверяет аргументы,
    # выполняет действие и не возвращает значение. WAIT(1000) в примере чтения разделяет два снимка.

    VAR before = ReadValue('Animal_Lore')
    WAIT(1000)
    VAR after = ReadValue('Animal Lore')
    UO.Print(CStr(after - before))
END SUB

SUB ReadValue(selector)
    RETURN UO.GetSkillCurrentValue(selector)
END SUB
```

**Разбор параметров и выполнения:**

- Весь код помощника приведён ниже Main. selector выбирает навык/характеристику, mode задаёт режим записи. ReadValue/ReadMode возвращают исходное число; ApplyMode проверяет аргументы, выполняет действие и не возвращает значение. WAIT(1000) в примере чтения разделяет два снимка.

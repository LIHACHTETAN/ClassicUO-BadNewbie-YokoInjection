# UO.Notoriety

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: ru -->

Читает репутацию персонажа из модели клиента.

## Точный синтаксис

```text
UO.Notoriety() -> Integer
```

## Параметры

Параметров нет.

## Возвращает

Integer — 0=unknown, 1=innocent, 2=ally, 3=gray, 4=criminal, 5=enemy, 6=murderer, 7=invulnerable. Это код состояния, а не hue, karma или fame. Неизвестный mobile даёт 0.

## Поведение

- Читаются уже полученные локальные данные. Запрос не открывает status и не заставляет сервер прислать обновление. После смерти, перехода карты или удаления объекта значения могут измениться между двумя вызовами.
- Это функции чтения: присваивание результата переменной сохраняет снимок. Оно не изменяет характеристику персонажа. Имена нечувствительны к регистру; используйте именно показанную форму с нужным числом аргументов.

```vb

# Читает репутацию персонажа из модели клиента.
#
# Integer — 0=unknown, 1=innocent, 2=ally, 3=gray, 4=criminal, 5=enemy, 6=murderer,
# 7=invulnerable. Это код состояния, а не hue, karma или fame. Неизвестный mobile даёт 0.

SUB Main()
    # Вызов без аргументов относится к self. Репутацию персонажа сохраняется в value.
    # STR преобразует число для вывода и не меняет смысл результата.

    VAR value = UO.Notoriety()
    UO.Print('Notoriety: ' + STR(value))
END SUB
```

**Разбор параметров и выполнения:**

- Вызов без аргументов относится к self. Репутацию персонажа сохраняется в value.
- STR преобразует число для вывода и не меняет смысл результата.

### Наблюдать изменение за одну секунду

```vb
# Наблюдать изменение за одну секунду
#
# Читает репутацию персонажа из модели клиента.
#
# Integer — 0=unknown, 1=innocent, 2=ally, 3=gray, 4=criminal, 5=enemy, 6=murderer,
# 7=invulnerable. Это код состояния, а не hue, karma или fame. Неизвестный mobile даёт 0.

SUB Main()
    # Оба вызова без аргумента читают своё текущее значение. WAIT(1000) даёт паузу в миллисекундах
    # между снимками.
    # Сравнивается изменение: репутацию персонажа. Пример ничего не изменяет в мире и не ждёт
    # бесконечно. События внутри этой секунды могут быть пропущены.

    VAR before = UO.Notoriety()
    WAIT(1000)
    VAR after = UO.Notoriety()
    IF before <> after THEN
        UO.Print('Before: ' + STR(before) + '; after: ' + STR(after))
    END IF
END SUB
```

**Разбор параметров и выполнения:**

- Оба вызова без аргумента читают своё текущее значение. WAIT(1000) даёт паузу в миллисекундах между снимками.
- Сравнивается изменение: репутацию персонажа. Пример ничего не изменяет в мире и не ждёт бесконечно. События внутри этой секунды могут быть пропущены.

# UO.ApiParameterExists

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: ru -->

Проверяет регистрацию значения runtime или именованного объекта.

## Точный синтаксис

```text
UO.ApiParameterExists(name:String) -> Integer
```

## Параметры

- `name` — Обязательная String: точное зарегистрированное имя, не выражение вызова. Регистр и пробелы по краям не важны; UO. автоматически не добавляется. Пустое или неизвестное имя даёт 0. Пользовательские процедуры не учитываются.

## Возвращает

Integer 1, если регистрация существует, иначе 0. Допустимы сравнения с TRUE/FALSE либо 1/0. Результат не подтверждает существование игрового объекта, успех действия или разрешение сервера.

## Поведение

- Регистр имён не важен. InjectionApi регистрирует библиотеку Basic без префикса, InjectionApiUO — игровые вызовы с UO. При старом коротком вызове анализатор выдаёт SC005 и подсказывает зарегистрированную замену UO.; скрытого выполнения старого вызова нет. Значения характеристик персонажа тоже требуют UO. ApiNameExists, ApiSignatureExists и ApiParameterExists убирают пробелы по краям и проверяют точное зарегистрированное имя, не дописывая префикс. Это проверка метаданных, не состояния сервера. Оператор рефлексии VB.NET GetType(TypeName) в движке не реализован.

### UO.ApiParameterExists — 1

```vb
# UO.ApiParameterExists — 1
#
# Проверяет регистрацию значения runtime или именованного объекта.
#
# Integer 1, если регистрация существует, иначе 0. Допустимы сравнения с TRUE/FALSE либо 1/0.
# Результат не подтверждает существование игрового объекта, успех действия или разрешение
# сервера.

SUB Main()
    # Первый пример проверяет игровое имя с явным UO. и возвращает 1. Точное проверяемое имя и

    RETURN UO.ApiParameterExists('UO.GetHP')
END SUB
```

- Первый пример проверяет игровое имя с явным UO. и возвращает 1. Точное проверяемое имя и количество аргументов, когда оно требуется, видны в вызове.

### UO.ApiParameterExists — 2

```vb
# UO.ApiParameterExists — 2
#
# Проверяет регистрацию значения runtime или именованного объекта.
#
# Integer 1, если регистрация существует, иначе 0. Допустимы сравнения с TRUE/FALSE либо 1/0.
```

**Разбор параметров и выполнения:**

### UO.ApiParameterExists — 3

```vb
# UO.ApiParameterExists — 3
#
# Проверяет регистрацию значения runtime или именованного объекта.
#
# Integer 1, если регистрация существует, иначе 0. Допустимы сравнения с TRUE/FALSE либо 1/0.
# Результат не подтверждает существование игрового объекта, успех действия или разрешение
# сервера.

SUB Main()
    # Третий пример содержит полную вспомогательную функцию. Он сравнивает удалённую короткую форму
    # или неподдерживаемую арность с доступной формой. Параметры name, first, second и count
    # передают имена/количество без изменений. Результат — 0 для проверок вызова и "0:1" для
    # проверки значений.

    RETURN CompareNames('GetHP','UO.GetHP')
END SUB

FUNCTION CompareNames(first,second)
    RETURN CStr(UO.ApiParameterExists(first)) + ":" + CStr(UO.ApiParameterExists(second))
END FUNCTION
```

**Разбор параметров и выполнения:**

- Третий пример содержит полную вспомогательную функцию. Он сравнивает удалённую короткую форму или неподдерживаемую арность с доступной формой. Параметры name, first, second и count передают имена/количество без изменений. Результат — 0 для проверок вызова и "0:1" для проверки значений.

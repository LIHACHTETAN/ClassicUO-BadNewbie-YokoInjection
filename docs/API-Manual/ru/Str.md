# str

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: ru -->

Str(value) преобразует скалярное значение Basic в текст.

## Точный синтаксис

```text
str(value:Decimal) -> String
str(value:Integer) -> String
str(value:String) -> String
```

## Параметры

- `value` — Один обязательный Integer, Decimal или String. Перегрузка выбирается по фактическому виду значения. Для Array, Object и Unit подходящей перегрузки Str нет.

## Возвращает

String: числовой текст в независимом от языка формате либо исходная String без изменений. Перед положительным числом не добавляется пробел. Параметра количества знаков нет.

## Поведение

- Обе функции вычисляются локально без обращения к игре. Отсутствие аргумента — ошибка. Int() и Str() не читают характеристики: для этого служат UO.Int() и UO.Str(). Int проходит через BasicDouble и Math.Floor; Str выбирает соответствующую InternalSubrutines.Str с независимым от языка форматированием.

## Примеры

### Str — 1

```vb
# Str — 1
#
# Str(value) преобразует скалярное значение Basic в текст.
#
# String: числовой текст в независимом от языка формате либо исходная String без изменений.
# Перед положительным числом не добавляется пробел. Параметра количества знаков нет.

SUB Main()
    # value=42 имеет вид Integer. Str возвращает "42" без начального пробела; Main возвращает эту
    # String.

    RETURN Str(42)
END SUB
```

**Разбор параметров и выполнения:**

- value=42 имеет вид Integer. Str возвращает "42" без начального пробела; Main возвращает эту String.

### Str — 2

```vb
# Str — 2
#
# Str(value) преобразует скалярное значение Basic в текст.
#
# String: числовой текст в независимом от языка формате либо исходная String без изменений.
# Перед положительным числом не добавляется пробел. Параметра количества знаков нет.

SUB Main()
    # amount=-12.5 имеет вид Decimal. Str сохраняет в text строку "-12.5" с точкой при любом языке
    # интерфейса. Main возвращает text, а amount остаётся числом.

    VAR amount = -12.5
    VAR text = Str(amount)
    RETURN text
END SUB
```

**Разбор параметров и выполнения:**

- amount=-12.5 имеет вид Decimal. Str сохраняет в text строку "-12.5" с точкой при любом языке интерфейса. Main возвращает text, а amount остаётся числом.

### Str — 3

```vb
# Str — 3
#
# Str(value) преобразует скалярное значение Basic в текст.
#
# String: числовой текст в независимом от языка формате либо исходная String без изменений.
# Перед положительным числом не добавляется пробел. Параметра количества знаков нет.

SUB Main()
    # ItemLabel принимает name="ore" и count=3. Str(name) сохраняет имя, Str(count) даёт "3".
    # Функция соединяет обе строки через " x", и Main возвращает "ore x3".

    RETURN ItemLabel("ore",3)
END SUB

SUB ItemLabel(name,count)
    RETURN Str(name) + " x" + Str(count)
END SUB
```

**Разбор параметров и выполнения:**

- ItemLabel принимает name="ore" и count=3. Str(name) сохраняет имя, Str(count) даёт "3". Функция соединяет обе строки через " x", и Main возвращает "ore x3".

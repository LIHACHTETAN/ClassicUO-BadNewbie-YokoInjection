# UO.ClearBadObjectList

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: ru -->

Удаляет все правила type/hue/radius, добавленные SetBadObject в текущем runtime.

## Точный синтаксис

```text
UO.ClearBadObjectList() -> Unit
```

## Параметры

Параметров нет.

## Возвращает

Unit — возвращаемого значения нет. Вызывайте отдельной строкой; это не true/false и не число шагов.

## Поведение

- Параметров нет. Повторный вызов при пустом списке безопасен.
- Не очищает SetBadLocation и не убирает естественные препятствия. Новое движение или запрос пути использует очищенный список; ранее запущенный маршрут сохраняет собственный снимок.

## Примеры

### Сбросить правила предметов

```vb
# Сбросить правила предметов
#
# Удаляет все правила type/hue/radius, добавленные SetBadObject в текущем runtime.
#
# Unit — возвращаемого значения нет. Вызывайте отдельной строкой; это не true/false и не число
# шагов.

SUB Main()
    # Аргументов нет; вызов записывается отдельной строкой.
    # Нет результата true/false и нет количества удалённых правил.

    UO.ClearBadObjectList()
END SUB
```

**Разбор параметров и выполнения:**

- Аргументов нет; вызов записывается отдельной строкой.
- Нет результата true/false и нет количества удалённых правил.

### Заменить набор правил

```vb
# Заменить набор правил
#
# Удаляет все правила type/hue/radius, добавленные SetBadObject в текущем runtime.
#
# Unit — возвращаемого значения нет. Вызывайте отдельной строкой; это не true/false и не число
# шагов.

SUB Main()
    # После очистки добавляется только type=0x398C любого цвета.
    # Radius=2 исключает квадрат 5×5 вокруг подходящих предметов при следующем маршруте.

    UO.ClearBadObjectList()
    UO.SetBadObject(0x398C, -1, 2)
END SUB
```

**Разбор параметров и выполнения:**

- После очистки добавляется только type=0x398C любого цвета.
- Radius=2 исключает квадрат 5×5 вокруг подходящих предметов при следующем маршруте.

### Пересчитать путь после полного сброса прикладных запретов

```vb
# Пересчитать путь после полного сброса прикладных запретов
#
# Удаляет все правила type/hue/radius, добавленные SetBadObject в текущем runtime.
#
# Unit — возвращаемого значения нет. Вызывайте отдельной строкой; это не true/false и не число
# шагов.

SUB Main()
    # Два списка независимы: для сброса обоих вызываются обе команды.
    # Три клетки восточнее — пример цели. Проходимость карты, высота и лимит поиска сохраняются;
    # пустой массив остаётся допустимым результатом.

    UO.ClearBadObjectList()
    UO.ClearBadLocationList()
    VAR path = UO.GetPathArray(UO.GetX() + 3, UO.GetY(), TRUE, 0)
    UO.Print(STR(GetArrayLength(path)))
END SUB
```

**Разбор параметров и выполнения:**

- Два списка независимы: для сброса обоих вызываются обе команды.
- Три клетки восточнее — пример цели. Проходимость карты, высота и лимит поиска сохраняются; пустой массив остаётся допустимым результатом.

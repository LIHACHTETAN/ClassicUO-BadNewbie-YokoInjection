# CStr

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: ru -->

Преобразует значение скрипта в текст.

## Точный синтаксис

```text
CStr(value:Any) -> String
```

## Параметры

- `value` — Любое значение BASIC: число, String, Array, Object или Unit.

## Возвращает

String: числа форматируются независимо от языка Windows, с точкой у дробей; строка сохраняется. Array соединяет текст элементов символом |, Object даёт имя типа объекта, Unit — текст <unit>. Это представление для вывода, не обратимая сериализация массивов.

## Поведение

- Числовое форматирование не зависит от локализации. Для явного hex без префикса используйте Hex.
- Разделитель | внутри элементов массива не экранируется. Для хранения структурированных данных используйте явные поля, а не повторный разбор CStr(Array).
- Циклический массив (прямо или косвенно содержащий себя) и вложенность более 256 уровней вызывают ошибку скрипта. Один и тот же вложенный массив в двух независимых элементах допустим.

## Примеры

### Дробное число на любом языке интерфейса

```vb
# Дробное число на любом языке интерфейса
#
# Преобразует значение скрипта в текст.
#
# String: числа форматируются независимо от языка Windows, с точкой у дробей; строка
# сохраняется. Array соединяет текст элементов символом |, Object даёт имя типа объекта, Unit —
# текст <unit>. Это представление для вывода, не обратимая сериализация массивов.

SUB Main()
    # value — Decimal. Десятичный разделитель всегда точка.
    # Ожидаемый результат: строка -1.25. В result сохраняется результат выражения; Print только
    # показывает его.

    VAR result = CStr(-1.25)
    UO.Print(CStr(result))
END SUB
```

**Разбор параметров и выполнения:**

- value — Decimal. Десятичный разделитель всегда точка.
- Ожидаемый результат: строка -1.25. В result сохраняется результат выражения; Print только показывает его.

### Сохранить строку без повторного разбора

```vb
# Сохранить строку без повторного разбора
#
# Преобразует значение скрипта в текст.
#
# String: числа форматируются независимо от языка Windows, с точкой у дробей; строка
# сохраняется. Array соединяет текст элементов символом |, Object даёт имя типа объекта, Unit —
# текст <unit>. Это представление для вывода, не обратимая сериализация массивов.

SUB Main()
    # Вход уже String: hex не преобразуется в десятичное число.
    # Ожидаемый результат: строка 0x0EED. В result сохраняется результат выражения; Print только
    # показывает его.

    VAR result = CStr('0x0EED')
    UO.Print(CStr(result))
END SUB
```

**Разбор параметров и выполнения:**

- Вход уже String: hex не преобразуется в десятичное число.
- Ожидаемый результат: строка 0x0EED. В result сохраняется результат выражения; Print только показывает его.

# Sqr

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: ru -->

Вычисляет квадратный корень.

## Точный синтаксис

```text
Sqr(number:Any) -> Decimal
```

## Параметры

- `number` — Обязательное число Integer/Decimal либо десятичная строка с точкой и необязательной экспонентой, например "-1.25e2". Язык интерфейса не влияет. Нераспознанный текст (включая hex-строку), Unit, Array и Object дают 0; числовой hex-литерал уже является Integer. Возможны NaN/Infinity. Для входа >=0 даёт неотрицательный корень. Отрицательное число даёт NaN, положительная бесконечность — Infinity, NaN сохраняется.

## Возвращает

Decimal — sqrt(number). Для входа >=0 даёт неотрицательный корень. Отрицательное число даёт NaN, положительная бесконечность — Infinity, NaN сохраняется. Число, не ID и не признак успеха; 1/0 здесь нельзя трактовать как выполнено/не выполнено.

## Поведение

- Вычисляется локально в потоке скрипта: без запроса серверу, движения, прицела, ожидания и изменения глобальных переменных.
- Decimal хранится как двоичный Double, не .NET decimal. Результат может быть приближённым; сравнивайте конечные дробные значения с допуском. NaN/Infinity не используйте как координаты или количество предметов.
- Для входа >=0 даёт неотрицательный корень. Отрицательное число даёт NaN, положительная бесконечность — Infinity, NaN сохраняется.

#### 1. Register

Register связывает имя BASIC с одним аргументом с нативным вычислением. После преобразования вызывается System.Math; скрытые скрипты и процедуры сервера не запускаются.

Decimal — sqrt(number). Для входа >=0 даёт неотрицательный корень. Отрицательное число даёт NaN, положительная бесконечность — Infinity, NaN сохраняется. Число, не ID и не признак успеха; 1/0 здесь нельзя трактовать как выполнено/не выполнено.

Исходник проекта: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApi.cs`; функция `Register`.

#### 2. BasicDouble

BasicDouble сохраняет Integer/Decimal, читает строку через инвариантный NumberStyles.Float, для неподдерживаемого значения даёт 0. Abs обрабатывает обычный Integer напрямую до перехода к Double.

Обязательное число Integer/Decimal либо десятичная строка с точкой и необязательной экспонентой, например "-1.25e2". Язык интерфейса не влияет. Нераспознанный текст (включая hex-строку), Unit, Array и Object дают 0; числовой hex-литерал уже является Integer. Возможны NaN/Infinity.

## Примеры

### Прямое вычисление

```vb
# Прямое вычисление
#
# Вычисляет квадратный корень.
#
# Decimal — sqrt(number). Для входа >=0 даёт неотрицательный корень. Отрицательное число даёт
# NaN, положительная бесконечность — Infinity, NaN сохраняется. Число, не ID и не признак
# успеха; 1/0 здесь нельзя трактовать как выполнено/не выполнено.

SUB Main()
    # number = 25; ожидается 5 (~ означает приближённо). value хранит результат, CStr лишь
    # форматирует его для Print.

    VAR value = Sqr(25)
    UO.Print(CStr(value))
END SUB
```

**Разбор параметров и выполнения:**

- number = 25; ожидается 5 (~ означает приближённо). value хранит результат, CStr лишь форматирует его для Print.

### Другой аргумент через переменную

```vb
# Другой аргумент через переменную
#
# Вычисляет квадратный корень.
#
# Decimal — sqrt(number). Для входа >=0 даёт неотрицательный корень. Отрицательное число даёт
# NaN, положительная бесконечность — Infinity, NaN сохраняется. Число, не ID и не признак
```

**Разбор параметров и выполнения:**

### Полная вспомогательная функция

```vb
# Полная вспомогательная функция
#
# Вычисляет квадратный корень.
#
# Decimal — sqrt(number). Для входа >=0 даёт неотрицательный корень. Отрицательное число даёт
# NaN, положительная бесконечность — Infinity, NaN сохраняется. Число, не ID и не признак
# успеха; 1/0 здесь нельзя трактовать как выполнено/не выполнено.

# manual-check: scalar-math Sqr
SUB Main()
    # dx/dy — разности координат. CDbl предотвращает целочисленное переполнение до sqrt(dx²+dy²);
    # SegmentLength(3,4)=5. Это евклидова длина, не длина маршрута и не проверка коллизий.

    VAR value = SegmentLength(3,4)
    UO.Print(CStr(value))
END SUB

SUB SegmentLength(dx,dy)
    VAR x = CDbl(dx)
    VAR y = CDbl(dy)
    RETURN Sqr(x*x+y*y)
END SUB
```

**Разбор параметров и выполнения:**

- dx/dy — разности координат. CDbl предотвращает целочисленное переполнение до sqrt(dx²+dy²); SegmentLength(3,4)=5. Это евклидова длина, не длина маршрута и не проверка коллизий.

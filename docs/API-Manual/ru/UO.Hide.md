# UO.Hide

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: ru -->

Скрывает выбранный предмет или персонажа только в локальной отрисовке клиента.

## Точный синтаксис

```text
UO.Hide() -> Unit
UO.Hide(serial:Any) -> Unit
```

## Параметры

- `serial` — Числовой serial или его hex/десятичная строка. Это не type. Для именованного объекта сначала получите числовую строку через GetSerial(name). Без аргумента появляется локальный прицел.

## Возвращает

Unit — возвращаемого значения нет. Результат нельзя присвоить как serial, graphic/type, количество или true/false. Информация выводится в интерфейс/журнал, а не возвращается скрипту.

## Поведение

- Форма без аргумента открывает прицел и из обычного скрипта. Выберите загруженный предмет или персонажа; землю/статику этим способом скрыть нельзя.
- Собственного персонажа скрывать запрещено. Неизвестный/уничтоженный объект даёт сообщение.
- Меняется локальная видимость объекта. Навык Hiding не применяется, серверное состояние Hidden не меняется, объект не удаляется на сервере.
- Скрытие не является постоянным серверным изменением; повторная загрузка объекта может создать новый видимый экземпляр.

## Примеры

### Выбрать мышью

```vb
# Выбрать мышью
#
# Скрывает выбранный предмет или персонажа только в локальной отрисовке клиента.
#
# Unit — возвращаемого значения нет. Результат нельзя присвоить как serial, graphic/type,
# количество или true/false. Информация выводится в интерфейс/журнал, а не возвращается скрипту.

SUB Main()
    # Параметров нет.
    # Команда возвращает сразу; последующий клик выбирает объект.

    UO.Hide()
END SUB
```

**Разбор параметров и выполнения:**

- Параметров нет.
- Команда возвращает сразу; последующий клик выбирает объект.

### Скрыть известный предмет

```vb
# Скрыть известный предмет
#
# Скрывает выбранный предмет или персонажа только в локальной отрисовке клиента.
#
# Unit — возвращаемого значения нет. Результат нельзя присвоить как serial, graphic/type,
# количество или true/false. Информация выводится в интерфейс/журнал, а не возвращается скрипту.

SUB Main()
    # serial=0x40001234 замените ID предмета.
    # Это локальное скрытие; количество и содержимое контейнера не меняются.

    UO.Hide(0x40001234)
END SUB
```

**Разбор параметров и выполнения:**

- serial=0x40001234 замените ID предмета.
- Это локальное скрытие; количество и содержимое контейнера не меняются.

### Скрыть сохранённый объект

```vb
# Скрыть сохранённый объект
#
# Скрывает выбранный предмет или персонажа только в локальной отрисовке клиента.
#
# Unit — возвращаемого значения нет. Результат нельзя присвоить как serial, graphic/type,
# количество или true/false. Информация выводится в интерфейс/журнал, а не возвращается скрипту.

SUB Main()
    # decoration — имя AddObject; GetSerial даёт числовую строку serial.
    # Проверка Exists отсеивает незагруженный объект. Hidden(self) не является проверкой этого
    # действия.

    IF UO.Exists('decoration') THEN
        UO.Hide(UO.GetSerial('decoration'))
    END IF
END SUB
```

**Разбор параметров и выполнения:**

- decoration — имя AddObject; GetSerial даёт числовую строку serial.
- Проверка Exists отсеивает незагруженный объект. Hidden(self) не является проверкой этого действия.

# Fix

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: ru -->

Отбрасывает дробную часть к нулю.

## Точный синтаксис

```text
Fix(value:Any) -> Integer
```

## Параметры

- `value` — Обязательное число Integer/Decimal либо десятичная строка с точкой и необязательной экспонентой, например "-1.25e2". Язык интерфейса не влияет. Нераспознанный текст (включая hex-строку), Unit, Array и Object дают 0; числовой hex-литерал уже является Integer. Возможны NaN/Infinity. Только конечный вход с результатом в -2147483648..2147483647. -2.9 даёт -2, в отличие от floor(-2.9)=-3. Вне диапазона и NaN/Infinity не являются допустимым входом преобразования.

## Возвращает

Integer — truncate(value). Только конечный вход с результатом в -2147483648..2147483647. -2.9 даёт -2, в отличие от floor(-2.9)=-3. Вне диапазона и NaN/Infinity не являются допустимым входом преобразования. Число, не ID и не признак успеха; 1/0 здесь нельзя трактовать как выполнено/не выполнено.

## Поведение

- Вычисляется локально в потоке скрипта: без запроса серверу, движения, прицела, ожидания и изменения глобальных переменных.
- Decimal хранится как двоичный Double, не .NET decimal. Результат может быть приближённым; сравнивайте конечные дробные значения с допуском. NaN/Infinity не используйте как координаты или количество предметов.
- Только конечный вход с результатом в -2147483648..2147483647. -2.9 даёт -2, в отличие от floor(-2.9)=-3. Вне диапазона и NaN/Infinity не являются допустимым входом преобразования.

### Внутренние функции: от вызова до результата

Ниже реальные этапы регистрации и преобразования. Полные функции примеров показывают полезные формулы скрипта, не заменяя математическую реализацию платформы.

#### 1. Register

Register связывает имя BASIC с одним аргументом с нативным вычислением. После преобразования вызывается System.Math; скрытые скрипты и процедуры сервера не запускаются.

Integer — truncate(value). Только конечный вход с результатом в -2147483648..2147483647. -2.9 даёт -2, в отличие от floor(-2.9)=-3. Вне диапазона и NaN/Infinity не являются допустимым входом преобразования. Число, не ID и не признак успеха; 1/0 здесь нельзя трактовать как выполнено/не выполнено.

Исходник проекта: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApi.cs`; функция `Register`.

#### 2. BasicDouble

BasicDouble сохраняет Integer/Decimal, читает строку через инвариантный NumberStyles.Float, для неподдерживаемого значения даёт 0. Abs обрабатывает обычный Integer напрямую до перехода к Double.

Обязательное число Integer/Decimal либо десятичная строка с точкой и необязательной экспонентой, например "-1.25e2". Язык интерфейса не влияет. Нераспознанный текст (включая hex-строку), Unit, Array и Object дают 0; числовой hex-литерал уже является Integer. Возможны NaN/Infinity.

Исходник проекта: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApi.cs`; функция `BasicDouble`.

Вычисляется локально в потоке скрипта: без запроса серверу, движения, прицела, ожидания и изменения глобальных переменных.


## Примеры

### Прямое вычисление

```vb
# Прямое вычисление
#
# Отбрасывает дробную часть к нулю.
#
# Integer — truncate(value). Только конечный вход с результатом в -2147483648..2147483647. -2.9
# даёт -2, в отличие от floor(-2.9)=-3. Вне диапазона и NaN/Infinity не являются допустимым
# входом преобразования. Число, не ID и не признак успеха; 1/0 здесь нельзя трактовать как
# выполнено/не выполнено.

SUB Main()
    # value = 2.9; ожидается 2 (~ означает приближённо). value хранит результат, CStr лишь
    # форматирует его для Print.

    VAR value = Fix(2.9)
    UO.Print(CStr(value))
END SUB
```

**Разбор параметров и выполнения:**

- value = 2.9; ожидается 2 (~ означает приближённо). value хранит результат, CStr лишь форматирует его для Print.

### Полная вспомогательная функция

```vb
# Полная вспомогательная функция
#
# Отбрасывает дробную часть к нулю.
#
# Integer — truncate(value). Только конечный вход с результатом в -2147483648..2147483647. -2.9
# даёт -2, в отличие от floor(-2.9)=-3. Вне диапазона и NaN/Infinity не являются допустимым
# входом преобразования. Число, не ID и не признак успеха; 1/0 здесь нельзя трактовать как
# выполнено/не выполнено.

# manual-check: scalar-math Fix
SUB Main()
    # total>=0 и size>0 задают полные партии: 27/5 даёт 5. Ошибочный вход даёт собственный запасной
    # 0, который возможен и без полной партии. Частное должно помещаться в Integer.

    VAR value = WholeBatches(27,5)
    UO.Print(CStr(value))
END SUB

SUB WholeBatches(total,size)
    IF total < 0 OR size <= 0 THEN
        RETURN 0
    END IF
    RETURN Fix(CDbl(total)/CDbl(size))
END SUB
```

**Разбор параметров и выполнения:**

- total>=0 и size>0 задают полные партии: 27/5 даёт 5. Ошибочный вход даёт собственный запасной 0, который возможен и без полной партии. Частное должно помещаться в Integer.

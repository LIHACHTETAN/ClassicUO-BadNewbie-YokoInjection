# left

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: ru -->

Возвращает часть строки с начала.

## Точный синтаксис

```text
left(str:String, length:Integer) -> String
```

## Параметры

- `str` — Исходный текст.
- `length` — Число единиц UTF-16. Отрицательное значение заменяется на 0; слишком большое ограничивается длиной строки.

## Возвращает

String — выбранная часть. При length<=0 возвращается пустая строка; при length>=Len(str) возвращается исходный текст целиком.

## Поведение

- Выполняется локально и не обращается к игровому серверу. Исходная строка не изменяется: результат нужно сохранить или передать дальше.
- Позиции и длины строк считаются в единицах UTF-16. Символ за пределами BMP, например emoji, занимает две единицы. Это не количество байтов UTF-8.

## Примеры

### Выделить три символа

```vb
# Выделить три символа
#
# Возвращает часть строки с начала.
#
# String — выбранная часть. При length<=0 возвращается пустая строка; при length>=Len(str)
# возвращается исходный текст целиком.

SUB Main()
    # str="abcdef", length=3; чтение идёт с начала.
    # Ожидаемый результат: строка abc. В result сохраняется результат выражения; Print только
    # показывает его.

    VAR result = left('abcdef', 3)
    UO.Print(CStr(result))
END SUB
```

**Разбор параметров и выполнения:**

- str="abcdef", length=3; чтение идёт с начала.
- Ожидаемый результат: строка abc. В result сохраняется результат выражения; Print только показывает его.


# UO.MoveOn

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: ru -->

Разрешает совместимые клавишные шаги PMove.

## Точный синтаксис

```text
UO.MoveOn() -> Unit
```

## Параметры

Параметров нет.

## Возвращает

Unit — возвращаемого значения нет. Вызывайте отдельной строкой; это не true/false и не число шагов.

## Поведение

- Меняет флаг MoveEnabled в состоянии runtime. Это не универсальная блокировка персонажа: NewMoveXY, MoveXYZ, Step и мышь не управляются этим флагом.
- MoveOff не останавливает уже работающий Pathfinder; для него нужна MoverStop.

## Примеры

### Изменить разрешение клавишных шагов

```vb
# Изменить разрешение клавишных шагов
#
# Разрешает совместимые клавишные шаги PMove.
#
# Unit — возвращаемого значения нет. Вызывайте отдельной строкой; это не true/false и не число
# шагов.

SUB Main()
    # Аргументов нет.
    # Изменяется флаг PMove, без возвращаемого значения.

    UO.MoveOn()
END SUB
```

**Разбор параметров и выполнения:**

- Аргументов нет.
- Изменяется флаг PMove, без возвращаемого значения.

### Явно разрешить следующий PMove

```vb
# Явно разрешить следующий PMove
#
# Разрешает совместимые клавишные шаги PMove.
#
# Unit — возвращаемого значения нет. Вызывайте отдельной строкой; это не true/false и не число
# шагов.

SUB Main()
    # MoveOn включает клавишные шаги перед PMove; MoveOff выключает после его обычного завершения.
    # Это последовательные команды; выключенный флаг не является аварийной остановкой всех процедур.

    UO.MoveOn()
    UO.PMove(UO.GetX() + 1, UO.GetY())
    UO.MoveOff()
END SUB
```

**Разбор параметров и выполнения:**

- MoveOn включает клавишные шаги перед PMove; MoveOff выключает после его обычного завершения.
- Это последовательные команды; выключенный флаг не является аварийной остановкой всех процедур.

### Выключить шаги и отдельно снять автоматический маршрут

```vb
# Выключить шаги и отдельно снять автоматический маршрут
#
# Разрешает совместимые клавишные шаги PMove.
#
# Unit — возвращаемого значения нет. Вызывайте отдельной строкой; это не true/false и не число
# шагов.

SUB Main()
    # Две команды управляют разными механизмами движения.
    # Move() читает автоматический маршрут; не считайте его проверкой MoveEnabled.

    UO.MoveOff()
    UO.MoverStop()
    UO.Print(STR(UO.Move()))
END SUB
```

**Разбор параметров и выполнения:**

- Две команды управляют разными механизмами движения.
- Move() читает автоматический маршрут; не считайте его проверкой MoveEnabled.

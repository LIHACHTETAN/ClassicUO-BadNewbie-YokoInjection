# Exp

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: ru -->

Возводит e в степень.

## Точный синтаксис

```text
Exp(power:Any) -> Decimal
```

## Параметры

- `power` — Обязательное число Integer/Decimal либо десятичная строка с точкой и необязательной экспонентой, например "-1.25e2". Язык интерфейса не влияет. Нераспознанный текст (включая hex-строку), Unit, Array и Object дают 0; числовой hex-литерал уже является Integer. Возможны NaN/Infinity. Exp(0)=1. Большая положительная степень даёт Infinity, очень отрицательная — 0 при потере разрядности. NaN сохраняется.

## Возвращает

Decimal — e^power. Exp(0)=1. Большая положительная степень даёт Infinity, очень отрицательная — 0 при потере разрядности. NaN сохраняется. Число, не ID и не признак успеха; 1/0 здесь нельзя трактовать как выполнено/не выполнено.

## Поведение

- Вычисляется локально в потоке скрипта: без запроса серверу, движения, прицела, ожидания и изменения глобальных переменных.
- Decimal хранится как двоичный Double, не .NET decimal. Результат может быть приближённым; сравнивайте конечные дробные значения с допуском. NaN/Infinity не используйте как координаты или количество предметов.
- Exp(0)=1. Большая положительная степень даёт Infinity, очень отрицательная — 0 при потере разрядности. NaN сохраняется.

### Внутренние функции: от вызова до результата

Ниже реальные этапы регистрации и преобразования. Полные функции примеров показывают полезные формулы скрипта, не заменяя математическую реализацию платформы.

#### 1. Register

Register связывает имя BASIC с одним аргументом с нативным вычислением. После преобразования вызывается System.Math; скрытые скрипты и процедуры сервера не запускаются.

Decimal — e^power. Exp(0)=1. Большая положительная степень даёт Infinity, очень отрицательная — 0 при потере разрядности. NaN сохраняется. Число, не ID и не признак успеха; 1/0 здесь нельзя трактовать как выполнено/не выполнено.

Исходник проекта: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApi.cs`; функция `Register`.

#### 2. BasicDouble

BasicDouble сохраняет Integer/Decimal, читает строку через инвариантный NumberStyles.Float, для неподдерживаемого значения даёт 0. Abs обрабатывает обычный Integer напрямую до перехода к Double.

Обязательное число Integer/Decimal либо десятичная строка с точкой и необязательной экспонентой, например "-1.25e2". Язык интерфейса не влияет. Нераспознанный текст (включая hex-строку), Unit, Array и Object дают 0; числовой hex-литерал уже является Integer. Возможны NaN/Infinity.

Исходник проекта: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApi.cs`; функция `BasicDouble`.

## Примеры

### Прямое вычисление

```vb
# Прямое вычисление
#
# Возводит e в степень.
#
# Decimal — e^power. Exp(0)=1. Большая положительная степень даёт Infinity, очень отрицательная
# — 0 при потере разрядности. NaN сохраняется. Число, не ID и не признак успеха; 1/0 здесь
# нельзя трактовать как выполнено/не выполнено.

SUB Main()
    # power = 0; ожидается 1 (~ означает приближённо). value хранит результат, CStr лишь форматирует
    # его для Print.

    VAR value = Exp(0)
    UO.Print(CStr(value))
END SUB
```

**Разбор параметров и выполнения:**

- power = 0; ожидается 1 (~ означает приближённо). value хранит результат, CStr лишь форматирует его для Print.

### Другой аргумент через переменную

```vb
# Другой аргумент через переменную
#
# Возводит e в степень.
#
# Decimal — e^power. Exp(0)=1. Большая положительная степень даёт Infinity, очень отрицательная
# — 0 при потере разрядности. NaN сохраняется. Число, не ID и не признак успеха; 1/0 здесь
# нельзя трактовать как выполнено/не выполнено.

SUB Main()
    # power = 1; ожидается ~2.718281828459045 (~ означает приближённо). value хранит результат, CStr
    # лишь форматирует его для Print.

    VAR inputValue = 1
    VAR value = Exp(inputValue)
    UO.Print(CStr(value))
END SUB
```

**Разбор параметров и выполнения:**

- power = 1; ожидается ~2.718281828459045 (~ означает приближённо). value хранит результат, CStr лишь форматирует его для Print.

### Полная вспомогательная функция

```vb
# Полная вспомогательная функция
#
# Возводит e в степень.
#
# Decimal — e^power. Exp(0)=1. Большая положительная степень даёт Infinity, очень отрицательная
# — 0 при потере разрядности. NaN сохраняется. Число, не ID и не признак успеха; 1/0 здесь
# нельзя трактовать как выполнено/не выполнено.

# manual-check: scalar-math Exp
SUB Main()
    # value — начальное значение, rate — непрерывный темп за единицу времени, period — число таких
    # единиц. Growth(100,0.05,2)≈110.517; только числовой пример.

    VAR value = Growth(100,0.05,2)
    UO.Print(CStr(value))
END SUB

SUB Growth(value,rate,period)
    RETURN value*Exp(rate*period)
END SUB
```

**Разбор параметров и выполнения:**

- value — начальное значение, rate — непрерывный темп за единицу времени, period — число таких единиц. Growth(100,0.05,2)≈110.517; только числовой пример.

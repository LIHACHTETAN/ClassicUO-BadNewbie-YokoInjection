# UO.GetSex

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: ru -->

Читает код пола и расы из модели клиента.

## Точный синтаксис

```text
UO.GetSex() -> Integer
```

## Параметры

Параметров нет.

## Возвращает

Integer — совместимый код: 0=human male, 1=human female, 2=elf male, 3=elf female, 4=gargoyle male, 5=gargoyle female. Без персонажа также 0, поэтому для наличия проверяйте Exists(self). Это не простой Boolean female.

## Поведение

- Читаются уже полученные локальные данные. Запрос не открывает status и не заставляет сервер прислать обновление. После смерти, перехода карты или удаления объекта значения могут измениться между двумя вызовами.
- Это функции чтения: присваивание результата переменной сохраняет снимок. Оно не изменяет характеристику персонажа. Имена нечувствительны к регистру; используйте именно показанную форму с нужным числом аргументов.

## Примеры

### Вывести текущее значение своего персонажа

```vb
# Вывести текущее значение своего персонажа
#
# Читает код пола и расы из модели клиента.
#
# Integer — совместимый код: 0=human male, 1=human female, 2=elf male, 3=elf female, 4=gargoyle
# male, 5=gargoyle female. Без персонажа также 0, поэтому для наличия проверяйте Exists(self).
# Это не простой Boolean female.

SUB Main()
    # Вызов без аргументов относится к self. Код пола и расы сохраняется в value.
    # STR преобразует число для вывода и не меняет смысл результата.

    VAR value = UO.GetSex()
    UO.Print('GetSex: ' + STR(value))
END SUB
```

**Разбор параметров и выполнения:**

- Вызов без аргументов относится к self. Код пола и расы сохраняется в value.
- STR преобразует число для вывода и не меняет смысл результата.

### Наблюдать изменение за одну секунду

```vb
# Наблюдать изменение за одну секунду
#
# Читает код пола и расы из модели клиента.
#
# Integer — совместимый код: 0=human male, 1=human female, 2=elf male, 3=elf female, 4=gargoyle
# male, 5=gargoyle female. Без персонажа также 0, поэтому для наличия проверяйте Exists(self).
# Это не простой Boolean female.

SUB Main()
    # Оба вызова без аргумента читают своё текущее значение. WAIT(1000) даёт паузу в миллисекундах
    # между снимками.
    # Сравнивается изменение: код пола и расы. Пример ничего не изменяет в мире и не ждёт
    # бесконечно. События внутри этой секунды могут быть пропущены.

    VAR before = UO.GetSex()
    WAIT(1000)
    VAR after = UO.GetSex()
    IF before <> after THEN
        UO.Print('Before: ' + STR(before) + '; after: ' + STR(after))
    END IF
END SUB
```

**Разбор параметров и выполнения:**

- Оба вызова без аргумента читают своё текущее значение. WAIT(1000) даёт паузу в миллисекундах между снимками.
- Сравнивается изменение: код пола и расы. Пример ничего не изменяет в мире и не ждёт бесконечно. События внутри этой секунды могут быть пропущены.

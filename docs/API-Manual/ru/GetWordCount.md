# GetWordCount

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: ru -->

Считает непустые слова после разделения строки.

## Точный синтаксис

```text
GetWordCount(value:String) -> Integer
GetWordCount(value:String, delimiter:String) -> Integer
```

## Параметры

- `value` — Исходный текст.
- `delimiter` — Необязательный разделитель. Отсутствие, пустая строка или один пробел выбирают любые Unicode whitespace; другая строка — точный разделитель целиком.

## Возвращает

Integer — число непустых частей. Пустой текст и текст только из разделителей дают 0. Последовательные разделители не создают пустые слова.

## Поведение

- Выполняется локально и не обращается к игровому серверу. Исходная строка не изменяется: результат нужно сохранить или передать дальше.
- Позиции и длины строк считаются в единицах UTF-16. Символ за пределами BMP, например emoji, занимает две единицы. Это не количество байтов UTF-8.

## Примеры

### Слова с лишними пробелами

```vb
# Слова с лишними пробелами
#
# Считает непустые слова после разделения строки.
#
# Integer — число непустых частей. Пустой текст и текст только из разделителей дают 0.
# Последовательные разделители не создают пустые слова.

SUB Main()
    # Разделитель не передан: пустые части удаляются.
    # Ожидаемый результат: 2. В result сохраняется результат выражения; Print только показывает его.

    VAR result = GetWordCount('  iron   gold  ')
    UO.Print(CStr(result))
END SUB
```

**Разбор параметров и выполнения:**

- Разделитель не передан: пустые части удаляются.
- Ожидаемый результат: 2. В result сохраняется результат выражения; Print только показывает его.

### Разделённый список

```vb
# Разделённый список
#
# Считает непустые слова после разделения строки.
#
# Integer — число непустых частей. Пустой текст и текст только из разделителей дают 0.
# Последовательные разделители не создают пустые слова.

SUB Main()
    # delimiter="|"; два соседних разделителя и последний не увеличивают счётчик.
    # Ожидаемый результат: 2. В result сохраняется результат выражения; Print только показывает его.

    VAR result = GetWordCount('a||b|','|')
    UO.Print(CStr(result))
END SUB
```

**Разбор параметров и выполнения:**

- delimiter="|"; два соседних разделителя и последний не увеличивают счётчик.
- Ожидаемый результат: 2. В result сохраняется результат выражения; Print только показывает его.

### Пустой текст

```vb
# Пустой текст
#
# Считает непустые слова после разделения строки.
#
# Integer — число непустых частей. Пустой текст и текст только из разделителей дают 0.
# Последовательные разделители не создают пустые слова.

SUB Main()
    # Нет непустых слов.
    # Ожидаемый результат: 0. В result сохраняется результат выражения; Print только показывает его.

    VAR result = GetWordCount('')
    UO.Print(CStr(result))
END SUB
```

**Разбор параметров и выполнения:**

- Нет непустых слов.
- Ожидаемый результат: 0. В result сохраняется результат выражения; Print только показывает его.

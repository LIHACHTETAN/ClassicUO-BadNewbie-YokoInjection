# UO.MaxMana

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: ru -->

Читает максимальную ману из локальной модели.

## Точный синтаксис

```text
UO.MaxMana() -> Any
```

## Параметры

Параметров нет.

## Возвращает

Integer — значение поля ManaMax, не процент и не Boolean. 0 бывает настоящим значением или признаком отсутствующих данных. Нулевой максимум нельзя использовать как делитель. У чужого mobile значения могут быть неизвестны. HP/HitsMax могут содержать относительную шкалу сервера вместо точных очков. HP=0 не доказывает смерть; для этого есть Dead/IsDead.

## Поведение

- Команда не открывает status и не запрашивает обновление сервера. В отличие от автоматического запроса отсутствующих HP в Stealth, этот клиент только читает данные. Не меняет характеристики и не отправляет пакеты.
- Результат — отдельное чтение. Мир может измениться между Exists и следующим вызовом; несколько запросов не образуют атомарный снимок.
- При чтении объекта World.Get отвергает отсутствующий или IsDestroyed и получается 0. HP/HitsMax читаются у Entity, включая предметы с этими полями; Mana/Stamina — только у Mobile. Без аргумента читается self. Одноимённый вариант без параметров не обязательно имеет вариант с ID: смотрите сигнатуры.
- Чтение без аргументов тоже возвращает 0 для отсутствующего или уничтоженного Player. Это относится и к прямым Mana/Stamina и их максимумам, а не только к формам через World.Get. Присутствующий мёртвый персонаж может сохранять значения.

#### 2. Invoke

Invoke выполняет чтение на игровом потоке; с рабочего потока ожидается обработка запроса менеджером. Отмена скрипта прерывает ожидание. Паузы и дополнительные сетевые запросы не добавляются.

## Примеры

### Вывести значение своего персонажа

```vb
# Вывести значение своего персонажа
#
# Читает максимальную ману из локальной модели.
#
# Integer — значение поля ManaMax, не процент и не Boolean. 0 бывает настоящим значением или
# признаком отсутствующих данных. Нулевой максимум нельзя использовать как делитель. У чужого
# mobile значения могут быть неизвестны. HP/HitsMax могут содержать относительную шкалу сервера
# вместо точных очков. HP=0 не доказывает смерть; для этого есть Dead/IsDead.

SUB Main()
    # Вызов без аргументов читает self. value сохраняет одно число, STR преобразует его только для
    # сообщения.

    VAR value = UO.MaxMana()
    UO.Print('MaxMana: ' + STR(value))
END SUB
```

**Разбор параметров и выполнения:**

- Вызов без аргументов читает self. value сохраняет одно число, STR преобразует его только для сообщения.

```vb

#
# Читает максимальную ману из локальной модели.
#
# Integer — значение поля ManaMax, не процент и не Boolean. 0 бывает настоящим значением или
```

### Полная вспомогательная функция ReadValue

```vb
# Полная вспомогательная функция ReadValue
#
# Читает максимальную ману из локальной модели.
#
# Integer — значение поля ManaMax, не процент и не Boolean. 0 бывает настоящим значением или
# признаком отсутствующих данных. Нулевой максимум нельзя использовать как делитель. У чужого
# mobile значения могут быть неизвестны. HP/HitsMax могут содержать относительную шкалу сервера
# вместо точных очков. HP=0 не доказывает смерть; для этого есть Dead/IsDead.

SUB Main()
    # У этого имени нет формы с ID. ReadValue без параметров читает self; два вызова разделены
    # WAIT(1000). Сравнение двух снимков может пропустить промежуточные изменения.

    VAR before = ReadValue()
    WAIT(1000)
    VAR after = ReadValue()
    UO.Print('Before: ' + CStr(before) + '; after: ' + CStr(after))
END SUB

SUB ReadValue()
    RETURN UO.MaxMana()
END SUB
```

**Разбор параметров и выполнения:**

- У этого имени нет формы с ID. ReadValue без параметров читает self; два вызова разделены WAIT(1000). Сравнение двух снимков может пропустить промежуточные изменения.

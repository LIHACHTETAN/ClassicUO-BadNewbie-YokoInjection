# contains

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: ru -->

Проверяет наличие всех битов маски, подстроки либо элемента массива в зависимости от видов аргументов.

## Точный синтаксис

```text
contains(collection:Any, flag:Any) -> Integer
```

## Параметры

- `collection` — Integer для битовой маски, String для подстроки либо Array для элемента.
- `flag` — Integer-маска, String-подстрока или искомое значение массива соответственно.

## Возвращает

Integer Boolean: 1 — условие выполнено, 0 — нет. Для пары Integer проверяется (collection AND mask)=mask, поэтому нулевая маска всегда даёт 1. Для строк пустая подстрока совпадает. Вложенные Array и Object сравниваются по тождеству: ссылка на тот же массив/объект совпадает, разные экземпляры — нет. Это не рекурсивный поиск.

## Поведение

- Сравнение внешних элементов не изменяет коллекцию. Integer 1 равен Decimal 1.0, но строка "1" им не равна.
- Для сравнения содержимого двух разных массивов переберите их элементы явно; одинаковый вид Array не означает равенство.

## Примеры

### Проверить элемент списка

```vb
# Проверить элемент списка
#
# Проверяет наличие всех битов маски, подстроки либо элемента массива в зависимости от видов
# аргументов.
#
# Integer Boolean: 1 — условие выполнено, 0 — нет. Для пары Integer проверяется (collection AND
# mask)=mask, поэтому нулевая маска всегда даёт 1. Для строк пустая подстрока совпадает.
# Вложенные Array и Object сравниваются по тождеству: ссылка на тот же массив/объект совпадает,
# разные экземпляры — нет. Это не рекурсивный поиск.

SUB Main()
    # DIM values(1) создаёт два элемента. Первый аргумент команды — Array, второй — число 20.
    # Совпадение во внешнем уровне даёт 1; индекс элемента не возвращается.

    DIM values(1)
    values[0] = 10
    values[1] = 20
    IF contains(values, 20) THEN
        UO.Print('20 is in the array')
    END IF
END SUB
```

**Разбор параметров и выполнения:**

- DIM values(1) создаёт два элемента. Первый аргумент команды — Array, второй — число 20.
- Совпадение во внешнем уровне даёт 1; индекс элемента не возвращается.

### Проверить ссылку на вложенный массив

```vb
# Проверить ссылку на вложенный массив
#
# Проверяет наличие всех битов маски, подстроки либо элемента массива в зависимости от видов
# аргументов.
#
# Integer Boolean: 1 — условие выполнено, 0 — нет. Для пары Integer проверяется (collection AND
# mask)=mask, поэтому нулевая маска всегда даёт 1. Для строк пустая подстрока совпадает.
# Вложенные Array и Object сравниваются по тождеству: ссылка на тот же массив/объект совпадает,
# разные экземпляры — нет. Это не рекурсивный поиск.

SUB Main()
    # outer[0] содержит тот же массив child; оба DIM задают единственный индекс 0.
    # Результат 1. Другой отдельно созданный массив с такими же числами дал бы 0.

    DIM child(0)
    DIM outer(0)
    outer[0] = child
    UO.Print(STR(contains(outer, child)))
END SUB
```

**Разбор параметров и выполнения:**

- outer[0] содержит тот же массив child; оба DIM задают единственный индекс 0.
- Результат 1. Другой отдельно созданный массив с такими же числами дал бы 0.

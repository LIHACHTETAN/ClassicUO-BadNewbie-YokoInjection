# UO.CancelWaitTarget

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: ru -->

Очищает подготовленные ответы на прицел.

## Точный синтаксис

```text
UO.CancelWaitTarget() -> Unit
```

## Параметры

Параметров нет.

## Возвращает

Unit — возвращаемого значения нет. Вызывайте отдельной строкой; не используйте как true/false, serial или type. Метадата Any у совместимых форм не меняет фактический результат Unit.

## Поведение

- Уже отправленные серверу ответы не отзываются.
- Открытый курсор остаётся активным; позднее его можно обработать вручную.
- Очередь общая для клиента: её очистка относится к подготовленным ответам всех процедур.

## Примеры

### Снять подготовку

```vb
# Снять подготовку
#
# Очищает подготовленные ответы на прицел.
#
# Unit — возвращаемого значения нет. Вызывайте отдельной строкой; не используйте как true/false,
# serial или type. Метадата Any у совместимых форм не меняет фактический результат Unit.

SUB Main()
    # Аргументов нет.
    # Отложенный ответ на self удаляется.

    UO.WaitTargetSelf()
    UO.CancelWaitTarget()
END SUB
```

**Разбор параметров и выполнения:**

- Аргументов нет.
- Отложенный ответ на self удаляется.

### Заменить ранее подготовленную точку

```vb
# Заменить ранее подготовленную точку
#
# Очищает подготовленные ответы на прицел.
#
# Unit — возвращаемого значения нет. Вызывайте отдельной строкой; не используйте как true/false,
# serial или type. Метадата Any у совместимых форм не меняет фактический результат Unit.

SUB Main()
    # 1445/1690/0 — пример новой точки мира.
    # Старые ответы убираются до постановки новой цели.

    UO.CancelWaitTarget()
    UO.WaitTargetXYZ(1445, 1690, 0)
END SUB
```

**Разбор параметров и выполнения:**

- 1445/1690/0 — пример новой точки мира.
- Старые ответы убираются до постановки новой цели.

### Отказаться после тайм-аута

```vb
# Отказаться после тайм-аута
#
# Очищает подготовленные ответы на прицел.
#
# Unit — возвращаемого значения нет. Вызывайте отдельной строкой; не используйте как true/false,
# serial или type. Метадата Any у совместимых форм не меняет фактический результат Unit.

SUB Main()
    # WAIT=1000 мс — ограничение этого примера.
    # Проверяется оставшаяся очередь, а не успешность навыка. При отсутствии серверного прицела
    # следующая посторонняя команда не получит старый ответ.

    UO.WaitTargetSelf()
    UO.UseSkill('Anatomy')
    WAIT(1000)
    IF UO.IsWaitTargetActive() THEN
        UO.CancelWaitTarget()
    END IF
END SUB
```

**Разбор параметров и выполнения:**

- WAIT=1000 мс — ограничение этого примера.
- Проверяется оставшаяся очередь, а не успешность навыка. При отсутствии серверного прицела следующая посторонняя команда не получит старый ответ.

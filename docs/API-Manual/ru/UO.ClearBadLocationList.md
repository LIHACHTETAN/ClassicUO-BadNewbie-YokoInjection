# UO.ClearBadLocationList

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: ru -->

Удаляет все пары, сохранённые SetBadLocation.

## Точный синтаксис

```text
UO.ClearBadLocationList() -> Unit
```

## Параметры

Параметров нет.

## Возвращает

Unit — возвращаемого значения нет. Вызывайте отдельной строкой; это не true/false и не число шагов.

## Поведение

- Не меняет карту, персонажей или препятствия на сервере. Очищается только прикладной список runtime.
- Уже полученный массив пути и снимок запретов идущего маршрута не изменяются. Для нового результата повторите запрос пути или запустите движение заново. Список SetBadObject очищается отдельно.

# шагов.

    # Параметров нет.
    # Возвращаемого значения нет.

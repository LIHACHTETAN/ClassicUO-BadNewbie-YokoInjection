# UO.Picking

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: ru -->

Проверяет, занят ли курсор клиента поднятым предметом.

## Точный синтаксис

```text
UO.Picking() -> Integer
```

## Параметры

Параметров нет.

## Возвращает

Integer 1 — ItemHold.Enabled установлен; 0 — не установлен. Это состояние клиента, не ID и не подтверждение серверной доставки. Учитывается предмет, поднятый мышью или другим скриптом.

Это логический результат: 1 = TRUE, 0 = FALSE. После VAR result = команда(...) можно писать IF result = TRUE THEN или IF result = 1 THEN; для отрицательного результата — IF result = FALSE THEN или IF result = 0 THEN. TRUE/FALSE пишутся без кавычек. Вызовите команду один раз и сохраните результат: повторный вызов может повторить действие или прочитать уже изменившееся состояние.

## Поведение

- Чтение не поднимает и не сбрасывает предмет.
- Для собственного переноса проверяйте также результат Drag/DragItem; чужой занятый курсор не означает, что нужный предмет успешно взят.

# подтверждение серверной доставки. Учитывается предмет, поднятый мышью или другим скриптом.
#
# Это логический результат: 1 = TRUE, 0 = FALSE. После VAR result = команда(...) можно писать IF
# result = TRUE THEN или IF result = 1 THEN; для отрицательного результата — IF result = FALSE

    # Аргументов нет.

- Выводится 1 или 0.

# подтверждение серверной доставки. Учитывается предмет, поднятый мышью или другим скриптом.

# Это логический результат: 1 = TRUE, 0 = FALSE. После VAR result = команда(...) можно писать IF

# сохраните результат: повторный вызов может повторить действие или прочитать уже изменившееся
# состояние.

SUB Main()
    # Один аргумент Drag означает весь стек и timeout=0.
    # Picking проверяет общий курсор клиента. Не запускайте два независимых переноса одновременно.

- Picking проверяет общий курсор клиента. Не запускайте два независимых переноса одновременно.

### Подождать свободный курсор с пределом

```vb
# Подождать свободный курсор с пределом
#
# Проверяет, занят ли курсор клиента поднятым предметом.
#
# Integer 1 — ItemHold.Enabled установлен; 0 — не установлен. Это состояние клиента, не ID и не
# подтверждение серверной доставки. Учитывается предмет, поднятый мышью или другим скриптом.
#
# Это логический результат: 1 = TRUE, 0 = FALSE. После VAR result = команда(...) можно писать IF
# result = TRUE THEN или IF result = 1 THEN; для отрицательного результата — IF result = FALSE
# THEN или IF result = 0 THEN. TRUE/FALSE пишутся без кавычек. Вызовите команду один раз и
# сохраните результат: повторный вызов может повторить действие или прочитать уже изменившееся
# состояние.

SUB Main()
    # Проверка повторяется до двадцати раз с паузами по 50 мс.
    # Команда не освобождает курсор и не отменяет чужой перенос.

    VAR tries = 0
    WHILE UO.Picking() AND tries < 20
        WAIT(50)
        tries = tries + 1
    WEND
    IF UO.Picking() THEN
        UO.Print('Cursor is still occupied')
    END IF
END SUB
```

**Разбор параметров и выполнения:**

- Проверка повторяется до двадцати раз с паузами по 50 мс.
- Команда не освобождает курсор и не отменяет чужой перенос.

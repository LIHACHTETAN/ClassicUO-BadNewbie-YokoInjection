# Tan

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: ru -->

Вычисляет тангенс.

## Точный синтаксис

```text
Tan(radians:Any) -> Decimal
```

## Параметры

- `radians` — Обязательное число Integer/Decimal либо десятичная строка с точкой и необязательной экспонентой, например "-1.25e2". Язык интерфейса не влияет. Нераспознанный текст (включая hex-строку), Unit, Array и Object дают 0; числовой hex-литерал уже является Integer. Возможны NaN/Infinity. Вход в радианах. Диапазон результата не ограничен; вблизи pi/2+k*pi величина огромна и неустойчива. NaN/бесконечность дают NaN.

## Возвращает

Decimal — tan(radians). Вход в радианах. Диапазон результата не ограничен; вблизи pi/2+k*pi величина огромна и неустойчива. NaN/бесконечность дают NaN. Число, не ID и не признак успеха; 1/0 здесь нельзя трактовать как выполнено/не выполнено.

## Поведение

- Вычисляется локально в потоке скрипта: без запроса серверу, движения, прицела, ожидания и изменения глобальных переменных.
- Decimal хранится как двоичный Double, не .NET decimal. Результат может быть приближённым; сравнивайте конечные дробные значения с допуском. NaN/Infinity не используйте как координаты или количество предметов.
- Вход в радианах. Диапазон результата не ограничен; вблизи pi/2+k*pi величина огромна и неустойчива. NaN/бесконечность дают NaN.

Ниже реальные этапы регистрации и преобразования. Полные функции примеров показывают полезные формулы скрипта, не заменяя математическую реализацию платформы.

#### 1. Register

Register связывает имя BASIC с одним аргументом с нативным вычислением. После преобразования вызывается System.Math; скрытые скрипты и процедуры сервера не запускаются.

Decimal — tan(radians). Вход в радианах. Диапазон результата не ограничен; вблизи pi/2+k*pi величина огромна и неустойчива. NaN/бесконечность дают NaN. Число, не ID и не признак успеха; 1/0 здесь нельзя трактовать как выполнено/не выполнено.

Исходник проекта: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApi.cs`; функция `Register`.

#### 2. BasicDouble

BasicDouble сохраняет Integer/Decimal, читает строку через инвариантный NumberStyles.Float, для неподдерживаемого значения даёт 0. Abs обрабатывает обычный Integer напрямую до перехода к Double.

Обязательное число Integer/Decimal либо десятичная строка с точкой и необязательной экспонентой, например "-1.25e2". Язык интерфейса не влияет. Нераспознанный текст (включая hex-строку), Unit, Array и Object дают 0; числовой hex-литерал уже является Integer. Возможны NaN/Infinity.

Исходник проекта: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApi.cs`; функция `BasicDouble`.

## Примеры

### Прямое вычисление

```vb
# Прямое вычисление
#
# Вычисляет тангенс.
#
# Decimal — tan(radians). Вход в радианах. Диапазон результата не ограничен; вблизи pi/2+k*pi
# величина огромна и неустойчива. NaN/бесконечность дают NaN. Число, не ID и не признак успеха;
# 1/0 здесь нельзя трактовать как выполнено/не выполнено.

SUB Main()
    # radians = 0; ожидается 0 (~ означает приближённо). value хранит результат, CStr лишь
    # форматирует его для Print.

    VAR value = Tan(0)
    UO.Print(CStr(value))
END SUB
```

**Разбор параметров и выполнения:**

- radians = 0; ожидается 0 (~ означает приближённо). value хранит результат, CStr лишь форматирует его для Print.

### Другой аргумент через переменную

```vb

#
# Вычисляет тангенс.

# величина огромна и неустойчива. NaN/бесконечность дают NaN. Число, не ID и не признак успеха;

#

# manual-check: scalar-math Tan
SUB Main()
    # degrees — градусы; pi/180 переводит их в радианы перед Tan. TangentDegrees(45)≈1; избегайте
    # особых углов.

    VAR value = TangentDegrees(45)
    UO.Print(CStr(value))

SUB TangentDegrees(degrees)
    RETURN Tan(degrees*3.141592653589793/180)
END SUB
```

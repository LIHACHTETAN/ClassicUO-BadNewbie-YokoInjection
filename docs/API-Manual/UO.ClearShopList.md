# UO.ClearShopList

ClassicUO • Runtime API • `UO.ClearShopList.md`

Удаляет все правила покупки и продажи текущего профиля, включая правила дополнительных списков, и отключает общие переключатели AutoBuy/AutoSell. Названия и отдельные переключатели списков сохраняются. Список лута не изменяется. Это очистка настроек автоматической торговли, а не закрытие окна вендора.

## Точный синтаксис / Registered signatures

```text
UO.ClearShopList() -> Unit
```

Порядок аргументов соответствует строкам выше. `Unit` означает отсутствие возвращаемого значения. `Any` — значение BASIC с преобразованием при вызове. Имена нечувствительны к регистру.

## Варианты использования

Это отдельные сценарии. Подставьте свои serial, пути и координаты; серверные действия зависят от текущего состояния игры.

### Прямой вызов

```vb
SUB Main()
    UO.ClearShopList()
END SUB
```

### Вызов с явно заданными аргументами

```vb
SUB Main()
    UO.ClearShopList()
END SUB
```

### Выполнение действия внутри процедуры

```vb
SUB ReadResult()
    UO.ClearShopList()
END SUB

SUB Main()
    ReadResult()
END SUB
```

## Возвращает

Unit — команда не возвращает значение. Вызывайте её отдельной строкой. Не используйте её результат как serial, type или логический признак успеха. Завершение вызова само по себе не подтверждает выполнение действия сервером.

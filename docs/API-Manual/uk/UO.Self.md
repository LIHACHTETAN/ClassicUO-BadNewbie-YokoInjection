# UO.Self

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Повертає ID поточного персонажа.

## Точний синтаксис

```text
UO.Self() -> Integer
```

## Параметри

Параметрів немає.

## Повертає

Integer — serial/ID, не graphic/type, шар, кількість предметів чи Boolean. 0 — поточного об’єкта немає. Зберігаються всі 32 біти serial; перевіряйте <> 0, не = TRUE чи > 0. Збережений результат сам не оновлюється. Читає World.Player.Serial; відсутній або знищений Player дає 0. Смерть відрізняється від видалення: наявний привид має ID персонажа.

## Поведінка

- Параметрів немає. Читає локальні дані через Invoke на ігровому потоці; скасування скрипта перериває очікування потоку. Не надсилає пакета, не відкриває контейнера/target і не переносить предмета.
- Вбудоване self/backpack без дужок читається заново, якщо його не перекрила змінна. Рядкові імена обробляє команда-одержувач. У призначенні перенесення "self" означає рюкзак, а UO.Self() повертає serial персонажа. Для ID контейнера явно використовуйте UO.Backpack().
- World.Clear прибирає Player; подальші читання дають 0. Вхід у світ або заміна сумки можуть змінити ID. Окремі читання не атомарні. Ненульовий ID не доводить підключення, дозволу сервера чи завантаження вмісту.

## Приклади

### Прочитати й вивести ID

```vb
# Прочитати й вивести ID
#
# Повертає ID поточного персонажа.
#
# Integer — serial/ID, не graphic/type, шар, кількість предметів чи Boolean. 0 — поточного
# об’єкта немає. Зберігаються всі 32 біти serial; перевіряйте <> 0, не = TRUE чи > 0. Збережений
# результат сам не оновлюється. Читає World.Player.Serial; відсутній або знищений Player дає 0.
# Смерть відрізняється від видалення: наявний привид має ID персонажа.

SUB Main()
    # id зберігає один результат; HEX форматує serial для журналу. Приклад нічого не обирає й не
    # використовує.

    VAR id = UO.Self()
    UO.Print('ID: ' + HEX(id))
END SUB
```

**Пояснення параметрів і виконання:**

- id зберігає один результат; HEX форматує serial для журналу. Приклад нічого не обирає й не використовує.

### Виявити зміну ID

```vb
# Виявити зміну ID
#
# Повертає ID поточного персонажа.
#
# Integer — serial/ID, не graphic/type, шар, кількість предметів чи Boolean. 0 — поточного
# об’єкта немає. Зберігаються всі 32 біти serial; перевіряйте <> 0, не = TRUE чи > 0. Збережений
# результат сам не оновлюється. Читає World.Player.Serial; відсутній або знищений Player дає 0.
# Смерть відрізняється від видалення: наявний привид має ID персонажа.

SUB Main()
    # before/after читаються з інтервалом 250 мс. WAIT додано лише в приклад. Рівність означає
    # однакові кінцеві ID; проміжні зміни можна пропустити.

    VAR before = UO.Self()
    WAIT(250)
    VAR after = UO.Self()
    IF before <> after THEN
        UO.Print('ID changed: ' + HEX(after))
    END IF
END SUB
```

**Пояснення параметрів і виконання:**

- before/after читаються з інтервалом 250 мс. WAIT додано лише в приклад. Рівність означає однакові кінцеві ID; проміжні зміни можна пропустити.

### Повна функція IsOwnSerial

```vb
# Повна функція IsOwnSerial
#
# Повертає ID поточного персонажа.
#
# Integer — serial/ID, не graphic/type, шар, кількість предметів чи Boolean. 0 — поточного
# об’єкта немає. Зберігаються всі 32 біти serial; перевіряйте <> 0, не = TRUE чи > 0. Збережений
# результат сам не оновлюється. Читає World.Player.Serial; відсутній або знищений Player дає 0.
# Смерть відрізняється від видалення: наявний привид має ID персонажа.

SUB Main()
    # candidate — збережений ID LastTarget. IsOwnSerial(candidate) приймає один serial і повертає
    # Integer Boolean: 1=TRUE для поточного ненульового власного ID, інакше 0=FALSE. Функція
    # наведена повністю; target не змінюється.

    VAR candidate = UO.LastTarget()
    IF IsOwnSerial(candidate) = TRUE THEN
        UO.Print('Own object selected')
    ELSE
        UO.Print('Different object or no own object')
    END IF
END SUB

SUB IsOwnSerial(candidate)
    VAR current = UO.Self()
    RETURN current <> 0 AND current = candidate
END SUB
```

**Пояснення параметрів і виконання:**

- candidate — збережений ID LastTarget. IsOwnSerial(candidate) приймає один serial і повертає Integer Boolean: 1=TRUE для поточного ненульового власного ID, інакше 0=FALSE. Функція наведена повністю; target не змінюється.

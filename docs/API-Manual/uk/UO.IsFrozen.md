# UO.IsFrozen

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Читає відомий клієнту прапорець паралічу персонажа.

## Точний синтаксис

```text
UO.IsFrozen() -> Integer
UO.IsFrozen(value:Any) -> Integer
```

## Параметри

- `value` — Необов’язковий serial/ID mobile: число, hex-рядок, self, lasttarget, інше стандартне ім’я об’єкта або ім’я AddObject. Це не graphic/type. Без аргументу вибирається self. Невідоме ім’я дає 0; курсор вибору не відкривається.

## Повертає

Integer Boolean: 1 = TRUE — завантажений mobile має прапорець IsParalyzed; 0 = FALSE — прапорця немає, mobile невідомий, видалений або об’єкт є предметом. Це не тривалість паралічу; 0 не гарантує можливість рухатися.

## Поведінка

- Використовуйте Paralyzed для перевірки прапорця паралічу. Варіанти Is/Get, GetParalisa, Frozen та GetLocked читають той самий прапорець.
- Команда лише читає локальні дані. Вона не накладає і не знімає параліч, не чекає його завершення та не запитує оновлення сервера.
- Для цієї перевірки value = TRUE, value = 1 та IF value рівнозначні. TRUE/FALSE пишуться без лапок. Це прапорець, а не кількість або ID.

## Приклади

### Перевірити себе через TRUE

```vb
# Перевірити себе через TRUE
#
# Читає відомий клієнту прапорець паралічу персонажа.
#
# Integer Boolean: 1 = TRUE — завантажений mobile має прапорець IsParalyzed; 0 = FALSE —
# прапорця немає, mobile невідомий, видалений або об’єкт є предметом. Це не тривалість паралічу;
# 0 не гарантує можливість рухатися.

SUB Main()
    # Порожні дужки вибирають self. state зберігає один знімок прапорця; TRUE — числова константа 1.
    # FALSE не виключає стіну, брак витривалості чи іншу причину зупинки.

    VAR state = UO.IsFrozen()
    IF state = TRUE THEN
        UO.Print('Paralysis flag is set')
    ELSE
        UO.Print('Paralysis flag is absent or unavailable')
    END IF
END SUB
```

**Пояснення параметрів і виконання:**

- Порожні дужки вибирають self. state зберігає один знімок прапорця; TRUE — числова константа 1.
- FALSE не виключає стіну, брак витривалості чи іншу причину зупинки.

### Перевірити вибраного mobile

```vb
# Перевірити вибраного mobile
#
# Читає відомий клієнту прапорець паралічу персонажа.
#
# Integer Boolean: 1 = TRUE — завантажений mobile має прапорець IsParalyzed; 0 = FALSE —
# прапорця немає, mobile невідомий, видалений або об’єкт є предметом. Це не тривалість паралічу;
# 0 не гарантує можливість рухатися.

SUB Main()
    # target зберігає serial останньої цілі як hex-рядок. IsNpc перевіряє завантаженого mobile,
    # зокрема гравця.
    # Аргумент вибирає саме збережений target. Новий курсор не відкривається, lasttarget не
    # змінюється.

    VAR target = UO.GetSerial('lasttarget')
    IF UO.IsNpc(target) THEN
        VAR state = UO.IsFrozen(target)
        UO.Print('Selected mobile paralysis 1/0: ' + STR(state))
    ELSE
        UO.Print('No loaded mobile selected')
    END IF
END SUB
```

**Пояснення параметрів і виконання:**

- target зберігає serial останньої цілі як hex-рядок. IsNpc перевіряє завантаженого mobile, зокрема гравця.
- Аргумент вибирає саме збережений target. Новий курсор не відкривається, lasttarget не змінюється.

### Обмежено чекати зняття паралічу

```vb
# Обмежено чекати зняття паралічу
#
# Читає відомий клієнту прапорець паралічу персонажа.
#
# Integer Boolean: 1 = TRUE — завантажений mobile має прапорець IsParalyzed; 0 = FALSE —
# прапорця немає, mobile невідомий, видалений або об’єкт є предметом. Це не тривалість паралічу;
# 0 не гарантує можливість рухатися.

SUB Main()
    # Не більше десяти пауз по 100 мс. Кожен виклик без аргументу повторно читає self.
    # Після циклу окремо перевіряється наявність self. Це спостереження приблизно одну секунду плюс
    # виконання команд, а не гарантоване одужання.

    VAR attempts = 0
    WHILE UO.IsFrozen() = TRUE AND attempts < 10
        WAIT(100)
        attempts = attempts + 1
    WEND
    IF UO.IsNpc('self') THEN
        IF UO.IsFrozen() = FALSE THEN
            UO.Print('Paralysis flag is clear')
        ELSE
            UO.Print('Still paralyzed')
        END IF
    ELSE
        UO.Print('Self is unavailable')
    END IF
END SUB
```

**Пояснення параметрів і виконання:**

- Не більше десяти пауз по 100 мс. Кожен виклик без аргументу повторно читає self.
- Після циклу окремо перевіряється наявність self. Це спостереження приблизно одну секунду плюс виконання команд, а не гарантоване одужання.

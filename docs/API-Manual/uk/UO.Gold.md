# UO.Gold

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Читає кількість золота зі статусу поточного персонажа.

## Точний синтаксис

```text
UO.Gold() -> Any
```

## Параметри

Параметрів немає.

## Повертає

Integer/Decimal — невід’ємна сума 0..4294967295. До 2147483647 включно повертається Integer, вище — Decimal (Double), що точно представляє кожне 32-бітне беззнакове ціле. 0 також означає відсутність поточного незнищеного Player або отриманої суми. Це не Boolean, ID, кількість стосів чи обхід рюкзака/банку.

## Поведінка

- Параметрів немає. Читає кеш Player.Gold із CharacterStatus (0x11). Сервер визначає склад свого лічильника; команда не перебирає вкладені сумки й не запитує баланс банку. Немає/знищено Player — 0; наявний привид може зберігати суму статусу.
- ReadGoldValue один раз читає bridge.Gold. Старий C# bridge зберігає сигнатуру Int32 і передає біти UInt32. unchecked-перетворення відновлює беззнакову суму: мала загортається в Integer, велика — у Decimal. Старший біт більше не робить баланс від’ємним. Перетворення локальне, без пакетів.
- Для великих сум зберігайте числовий результат. Не перетворюйте примусово через CInt/CLng: тут це 32-бітний Integer. Великий BASIC-літерал пишіть із крапкою, наприклад 3000000000.0. Знімок може застаріти до покупки; CanAfford — локальна перевірка, не дозвіл сервера.
- Кожен виклик читає локальні дані заново. Змінна зберігає знімок; окремі читання можуть бачити різні оновлення сервера. Ненульовий результат не перевіряє з’єднання. Нуль буває значенням або відсутністю даних.

### Повна функція CanAfford із великою ціною

```vb
# Повна функція CanAfford із великою ціною
#
# Читає кількість золота зі статусу поточного персонажа.
#
# Integer/Decimal — невід’ємна сума 0..4294967295. До 2147483647 включно повертається Integer,
# вище — Decimal (Double), що точно представляє кожне 32-бітне беззнакове ціле. 0 також означає
# відсутність поточного незнищеного Player або отриманої суми. Це не Boolean, ID, кількість
# стосів чи обхід рюкзака/банку.

SUB Main()
    # price=3000000000.0 — приклад ціни, не ліміт. CanAfford(price) відхиляє від’ємну ціну або
    # відсутнього Player, один раз читає суму й повертає Integer Boolean: 1=TRUE чи 0=FALSE за
    # умовою amount >= price. Сама сума не Boolean. Функція повністю визначена нижче.

    VAR price = 3000000000.0
    IF CanAfford(price) = TRUE THEN
        UO.Print('Local balance is sufficient')
    ELSE
        UO.Print('Local check failed')
    END IF
END SUB

SUB CanAfford(price)
    IF price < 0 OR UO.Self() = 0 THEN
        RETURN FALSE
    END IF
    VAR amount = UO.Gold()
    RETURN amount >= price
END SUB
```

**Пояснення параметрів і виконання:**

- price=3000000000.0 — приклад ціни, не ліміт. CanAfford(price) відхиляє від’ємну ціну або відсутнього Player, один раз читає суму й повертає Integer Boolean: 1=TRUE чи 0=FALSE за умовою amount >= price. Сама сума не Boolean. Функція повністю визначена нижче.

### Спостерігати зміну балансу

```vb
# Спостерігати зміну балансу
#
# Читає кількість золота зі статусу поточного персонажа.
#
# Integer/Decimal — невід’ємна сума 0..4294967295. До 2147483647 включно повертається Integer,
# вище — Decimal (Double), що точно представляє кожне 32-бітне беззнакове ціле. 0 також означає
# відсутність поточного незнищеного Player або отриманої суми. Це не Boolean, ID, кількість
# стосів чи обхід рюкзака/банку.

SUB Main()
    # before/after розділяє WAIT(500) мілісекунд. difference=after-before може бути від’ємною при
    # зменшенні балансу; це не виправлене переповнення беззнакового лічильника. Проміжні оновлення й
    # зміни персонажа можна пропустити.

    VAR before = UO.Gold()
    WAIT(500)
    VAR after = UO.Gold()
    VAR difference = after - before
    UO.Print('Balance change: ' + CStr(difference))
END SUB
```

**Пояснення параметрів і виконання:**

- before/after розділяє WAIT(500) мілісекунд. difference=after-before може бути від’ємною при зменшенні балансу; це не виправлене переповнення беззнакового лічильника. Проміжні оновлення й зміни персонажа можна пропустити.

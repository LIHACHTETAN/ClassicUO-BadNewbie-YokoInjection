# Sgn

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Повертає знак числа.

## Точний синтаксис

```text
Sgn(value:Any) -> Integer
```

## Параметри

- `value` — Обов’язковий Integer/Decimal або десятковий текст із крапкою й необов’язковою експонентою, наприклад "-1.25e2". Мова інтерфейсу не впливає. Нерозпізнаний текст (зокрема hex-рядок), Unit, Array та Object дають 0; числовий hex-літерал вже Integer. Можливі NaN/Infinity. -1 для від’ємного, 0 для нуля, +1 для додатного. NaN викликає математичну помилку; нескінченності повертають свій знак.

## Повертає

Integer — sign(value). -1 для від’ємного, 0 для нуля, +1 для додатного. NaN викликає математичну помилку; нескінченності повертають свій знак. Число, не ID чи ознака успіху; 1/0 тут не означають виконано/не виконано.

## Поведінка

- Локальне обчислення в потоці скрипту без запиту серверу, руху, прицілу, очікування чи зміни глобальних змінних.
- Decimal — двійковий Double, не .NET decimal. Результати можуть бути наближеними; порівнюйте скінченні дробові значення з допуском. NaN/Infinity не підходять для координат або кількості предметів.
- -1 для від’ємного, 0 для нуля, +1 для додатного. NaN викликає математичну помилку; нескінченності повертають свій знак.

### Внутрішні функції: від виклику до результату

Це реальні етапи реєстрації та перетворення. Повні помічники демонструють формули скрипту, не замінюючи математику платформи.

#### 1. Register

Register прив’язує ім’я BASIC з одним аргументом до нативного обчислення. Після перетворення викликає System.Math, не прихований скрипт чи процедуру сервера.

Integer — sign(value). -1 для від’ємного, 0 для нуля, +1 для додатного. NaN викликає математичну помилку; нескінченності повертають свій знак. Число, не ID чи ознака успіху; 1/0 тут не означають виконано/не виконано.

Код проєкту: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApi.cs`; функція `Register`.

#### 2. BasicDouble

BasicDouble зберігає Integer/Decimal, читає текст з інваріантним NumberStyles.Float і дає 0 для непідтримуваного значення. Abs обробляє звичайний Integer прямо перед переходом до Double.

Обов’язковий Integer/Decimal або десятковий текст із крапкою й необов’язковою експонентою, наприклад "-1.25e2". Мова інтерфейсу не впливає. Нерозпізнаний текст (зокрема hex-рядок), Unit, Array та Object дають 0; числовий hex-літерал вже Integer. Можливі NaN/Infinity.

Код проєкту: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApi.cs`; функція `BasicDouble`.

#### 3. BasicSgn

Integer — sign(value). -1 для від’ємного, 0 для нуля, +1 для додатного. NaN викликає математичну помилку; нескінченності повертають свій знак. Число, не ID чи ознака успіху; 1/0 тут не означають виконано/не виконано.

Код проєкту: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApi.cs`; функція `BasicSgn`.

## Приклади

### Пряме обчислення

```vb
# Пряме обчислення
#
# Повертає знак числа.
#
# Integer — sign(value). -1 для від’ємного, 0 для нуля, +1 для додатного. NaN викликає
# математичну помилку; нескінченності повертають свій знак. Число, не ID чи ознака успіху; 1/0
# тут не означають виконано/не виконано.

SUB Main()
    # value = -8; очікується -1 (~ означає приблизно). value зберігає результат, CStr лише форматує
    # його для Print.

    VAR value = Sgn(-8)
    UO.Print(CStr(value))
END SUB
```

**Пояснення параметрів і виконання:**

- value = -8; очікується -1 (~ означає приблизно). value зберігає результат, CStr лише форматує його для Print.

### Повна допоміжна функція

```vb
# Повна допоміжна функція
#
# Повертає знак числа.
#
# Integer — sign(value). -1 для від’ємного, 0 для нуля, +1 для додатного. NaN викликає
# математичну помилку; нескінченності повертають свій знак. Число, не ID чи ознака успіху; 1/0
# тут не означають виконано/не виконано.

# manual-check: scalar-math Sgn
SUB Main()
    # current/destination — зміщення по одній осі. StepToward дає -1/0/1, не код восьми напрямків;
    # не рухає.

    VAR value = StepToward(12,10)
    UO.Print(CStr(value))
END SUB

SUB StepToward(current,destination)
    RETURN Sgn(CDbl(destination)-CDbl(current))
END SUB
```

**Пояснення параметрів і виконання:**

- current/destination — зміщення по одній осі. StepToward дає -1/0/1, не код восьми напрямків; не рухає.

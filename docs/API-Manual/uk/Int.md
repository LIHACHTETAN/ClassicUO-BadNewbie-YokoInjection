# Int

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Int(value) округлює число Basic донизу, до мінус нескінченності.

## Точний синтаксис

```text
Int(value:Any) -> Integer
```

## Параметри

- `value` — Один обов’язковий Integer/Decimal або числовий текст із крапкою, незалежно від мови інтерфейсу. Нерозпізнаний текст, Array, Object і Unit перетворюються на 0; перевіряйте введення через IsNumeric.

## Повертає

Integer: floor(value), наприклад 2.9 -> 2, -2.9 -> -3. Результат має вміщуватися у знаковий Int32; не використовуйте нескінченність, NaN чи вихід за межі.

## Поведінка

- Функції виконуються локально без звернень до гри. Відсутній аргумент є помилкою. Характеристики читають UO.Int() та UO.Str(), а не Int()/Str(). Int використовує BasicDouble і Math.Floor; Str обирає InternalSubrutines.Str за видом аргументу та форматує незалежно від мови.

## Приклади

### Int — 1

```vb
# Int — 1
#
# Int(value) округлює число Basic донизу, до мінус нескінченності.
#
# Integer: floor(value), наприклад 2.9 -> 2, -2.9 -> -3. Результат має вміщуватися у знаковий
# Int32; не використовуйте нескінченність, NaN чи вихід за межі.

SUB Main()
    # value=2.9. Округлення донизу відкидає додатну дробову частину; Main повертає Integer 2.

    RETURN Int(2.9)
END SUB
```

**Пояснення параметрів і виконання:**

- value=2.9. Округлення донизу відкидає додатну дробову частину; Main повертає Integer 2.

### Int — 3

```vb
# Int — 3
#
# Int(value) округлює число Basic донизу, до мінус нескінченності.
#
# Integer: floor(value), наприклад 2.9 -> 2, -2.9 -> -3. Результат має вміщуватися у знаковий
# Int32; не використовуйте нескінченність, NaN чи вихід за межі.

SUB Main()
    # WholeUnits отримує total=27, size=5. Непозитивний size дає 0; інакше Int(total/size) округлює
    # 5.4 донизу. Main повертає 5 повних одиниць. Обидва параметри та вся функція наведені.

    RETURN WholeUnits(27,5)
END SUB

SUB WholeUnits(total,size)
    IF size <= 0 THEN
        RETURN 0
    END IF
    RETURN Int(total/size)
END SUB
```

**Пояснення параметрів і виконання:**

- WholeUnits отримує total=27, size=5. Непозитивний size дає 0; інакше Int(total/size) округлює 5.4 донизу. Main повертає 5 повних одиниць. Обидва параметри та вся функція наведені.

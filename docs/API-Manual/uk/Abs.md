# Abs

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Повертає модуль числа.

## Точний синтаксис

```text
Abs(value:Any) -> Any
```

## Параметри

- `value` — Обов’язковий Integer/Decimal або десятковий текст із крапкою й необов’язковою експонентою, наприклад "-1.25e2". Мова інтерфейсу не впливає. Нерозпізнаний текст (зокрема hex-рядок), Unit, Array та Object дають 0; числовий hex-літерал вже Integer. Можливі NaN/Infinity. Integer зберігає тип, крім -2147483648: модуль дає Decimal 2147483648. Decimal/текст дають Decimal. NaN зберігається; обидві нескінченності дають додатну.

## Повертає

Integer/Decimal — abs(value). Integer зберігає тип, крім -2147483648: модуль дає Decimal 2147483648. Decimal/текст дають Decimal. NaN зберігається; обидві нескінченності дають додатну. Число, не ID чи ознака успіху; 1/0 тут не означають виконано/не виконано.

## Поведінка

- Локальне обчислення в потоці скрипту без запиту серверу, руху, прицілу, очікування чи зміни глобальних змінних.
- Decimal — двійковий Double, не .NET decimal. Результати можуть бути наближеними; порівнюйте скінченні дробові значення з допуском. NaN/Infinity не підходять для координат або кількості предметів.
- Integer зберігає тип, крім -2147483648: модуль дає Decimal 2147483648. Decimal/текст дають Decimal. NaN зберігається; обидві нескінченності дають додатну.

### Внутрішні функції: від виклику до результату

Це реальні етапи реєстрації та перетворення. Повні помічники демонструють формули скрипту, не замінюючи математику платформи.

#### 1. Register

Register прив’язує ім’я BASIC з одним аргументом до нативного обчислення. Після перетворення викликає System.Math, не прихований скрипт чи процедуру сервера.

Integer/Decimal — abs(value). Integer зберігає тип, крім -2147483648: модуль дає Decimal 2147483648. Decimal/текст дають Decimal. NaN зберігається; обидві нескінченності дають додатну. Число, не ID чи ознака успіху; 1/0 тут не означають виконано/не виконано.

Код проєкту: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApi.cs`; функція `Register`.

#### 2. BasicDouble

BasicDouble зберігає Integer/Decimal, читає текст з інваріантним NumberStyles.Float і дає 0 для непідтримуваного значення. Abs обробляє звичайний Integer прямо перед переходом до Double.

Обов’язковий Integer/Decimal або десятковий текст із крапкою й необов’язковою експонентою, наприклад "-1.25e2". Мова інтерфейсу не впливає. Нерозпізнаний текст (зокрема hex-рядок), Unit, Array та Object дають 0; числовий hex-літерал вже Integer. Можливі NaN/Infinity.

Код проєкту: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApi.cs`; функція `BasicDouble`.

#### 3. BasicAbs

Integer зберігає тип, крім -2147483648: модуль дає Decimal 2147483648. Decimal/текст дають Decimal. NaN зберігається; обидві нескінченності дають додатну.

Integer/Decimal — abs(value). Integer зберігає тип, крім -2147483648: модуль дає Decimal 2147483648. Decimal/текст дають Decimal. NaN зберігається; обидві нескінченності дають додатну. Число, не ID чи ознака успіху; 1/0 тут не означають виконано/не виконано.

## Приклади

### Пряме обчислення

```vb
# Пряме обчислення
#
# Повертає модуль числа.
#
# Integer/Decimal — abs(value). Integer зберігає тип, крім -2147483648: модуль дає Decimal
# 2147483648. Decimal/текст дають Decimal. NaN зберігається; обидві нескінченності дають
# додатну. Число, не ID чи ознака успіху; 1/0 тут не означають виконано/не виконано.

SUB Main()
    # value = -12; очікується 12 (~ означає приблизно). value зберігає результат, CStr лише форматує
    # його для Print.

    VAR value = Abs(-12)
    UO.Print(CStr(value))
END SUB
```

**Пояснення параметрів і виконання:**

- value = -12; очікується 12 (~ означає приблизно). value зберігає результат, CStr лише форматує його для Print.

### Повна допоміжна функція

```vb
# Повна допоміжна функція
#
# Повертає модуль числа.
#
# Integer/Decimal — abs(value). Integer зберігає тип, крім -2147483648: модуль дає Decimal
# 2147483648. Decimal/текст дають Decimal. NaN зберігається; обидві нескінченності дають
# додатну. Число, не ID чи ознака успіху; 1/0 тут не означають виконано/не виконано.

# manual-check: scalar-math Abs
SUB Main()
    # value/target — числа, tolerance — невід’ємний допуск. IsWithin дає 1/0; від’ємний допуск дає
    # 0. Лише результат помічника є Boolean.

    VAR value = IsWithin(12,10,2)
    UO.Print(CStr(value))
END SUB

SUB IsWithin(value,target,tolerance)
    IF tolerance < 0 THEN
        RETURN 0
    END IF
    RETURN Abs(CDbl(value)-CDbl(target)) <= tolerance
END SUB
```

**Пояснення параметрів і виконання:**

- value/target — числа, tolerance — невід’ємний допуск. IsWithin дає 1/0; від’ємний допуск дає 0. Лише результат помічника є Boolean.

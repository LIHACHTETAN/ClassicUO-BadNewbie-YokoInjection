# UO.LastStatusX

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Повертає збережену координату X об’єкта останнього прийнятого статусу.

## Точний синтаксис

```text
UO.LastStatusX() -> Integer
```

## Параметри

Параметрів немає.

## Повертає

Integer — збережена координата X, не піксель вікна статусу і не Boolean. До першого статусу чи після очищення — 0; координата 0 теж допустима. Перевіряйте UO.LastStatus(), щоб відрізнити відсутній запис.

## Поведінка

- Без параметрів. Читання не надсилає пакетів, не відкриває вікна й не чекає відповіді. UO.GetStatus(id), RequestStats та UpdateObject лише запитують дані: надсилання не змінює LastStatus.
- Прийнятий пакет 0x11 разом зберігає serial і відомі X/Y у World для всіх скриптів. Невідомий/знищений об’єкт та неповний базовий пакет не замінюють запис. Наступний статус іншого об’єкта може його замінити.
- X/Y — знімок Entity під час приймання, не поточна позиція. Для mobile це світові клітини; предмет у контейнері може мати координати вмісту. Пакет статусу сам не містить X/Y. Рух/видалення потім не змінюють знімок; World.Clear скидає його. Поточні координати наявного об’єкта читають GetX/GetY.
- Окремі виклики не є атомарним знімком; між ними може прийти оновлення. Однаковий serial не доводить нову відповідь саме на ваш запит. laststatus без дужок — жива вбудована змінна, якщо її не перевизначив скрипт; UO.LastStatus() — зареєстрована функція.

### Внутрішні функції: від виклику до результату

Це справжні внутрішні етапи C#. ReadSavedStatus повністю визначена в прикладі; це допоміжна функція, а не прихована вбудована команда.

#### 1. CharacterStatus

CharacterStatus перевіряє базовий пакет та Entity через World.Get, оновлює статус і зберігає serial/X/Y. Позиція береться з Entity, не з байтів статусу.

Integer — збережена координата X, не піксель вікна статусу і не Boolean. До першого статусу чи після очищення — 0; координата 0 теж допустима. Перевіряйте UO.LastStatus(), щоб відрізнити відсутній запис.

Код проєкту: `src/ClassicUO.Client/Network/PacketHandlers.cs`; функція `CharacterStatus`.

#### 2. LastStatusX

ExecuteStealthCompatibility повертає serial bridge як Integer. LastStatusX/LastStatusY читають збережені координати через IStatusSnapshotBridge; старий сторонній bridge без нього залишає читання GetX/GetY.

Integer — збережена координата X, не піксель вікна статусу і не Boolean. До першого статусу чи після очищення — 0; координата 0 теж допустима. Перевіряйте UO.LastStatus(), щоб відрізнити відсутній запис.

Код проєкту: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApiUO.cs`; функція `LastStatusX`.

#### 3. Invoke

Invoke читає World на ігровому потоці з підтримкою скасування скрипту. Не чекає мережевої відповіді й не змінює статус.

Без параметрів. Читання не надсилає пакетів, не відкриває вікна й не чекає відповіді. UO.GetStatus(id), RequestStats та UpdateObject лише запитують дані: надсилання не змінює LastStatus.

Код проєкту: `src/ClassicUO.Client/Game/Managers/ClassicUOInjectionApiBridge.cs`; функція `Invoke`.

#### 4. Clear

Clear скидає serial та обидві координати в 0, навіть якщо очищення зберігає запущені скрипти.

X/Y — знімок Entity під час приймання, не поточна позиція. Для mobile це світові клітини; предмет у контейнері може мати координати вмісту. Пакет статусу сам не містить X/Y. Рух/видалення потім не змінюють знімок; World.Clear скидає його. Поточні координати наявного об’єкта читають GetX/GetY.

Код проєкту: `src/ClassicUO.Client/Game/World.cs`; функція `Clear`.

Окремі виклики не є атомарним знімком; між ними може прийти оновлення. Однаковий serial не доводить нову відповідь саме на ваш запит. laststatus без дужок — жива вбудована змінна, якщо її не перевизначив скрипт; UO.LastStatus() — зареєстрована функція.

### Повний помічник ReadSavedStatus

```vb
# Повний помічник ReadSavedStatus
#
# Повертає збережену координату X об’єкта останнього прийнятого статусу.
#
# Integer — збережена координата X, не піксель вікна статусу і не Boolean. До першого статусу чи
# після очищення — 0; координата 0 теж допустима. Перевіряйте UO.LastStatus(), щоб відрізнити
# відсутній запис.

SUB Main()
    # expectedId — serial, збережений у Main. Помічник повністю визначений нижче; -1 означає, що
    # запис вже інший, а не код повернення самої команди. Перевірки до/після зменшують ризик
    # змішування об’єктів, але не гарантують атомарності для того самого serial.

    VAR expectedId = UO.LastStatus()
    IF expectedId <> 0 THEN
        VAR value = ReadSavedStatus(expectedId)
        UO.Print('Checked value: ' + CStr(value))
    END IF
END SUB

SUB ReadSavedStatus(expectedId)
    IF expectedId = 0 OR UO.LastStatus() <> expectedId THEN
        RETURN -1
    END IF
    VAR value = UO.LastStatusX()
    IF UO.LastStatus() <> expectedId THEN
        RETURN -1
    END IF
    RETURN value
END SUB
```

**Пояснення параметрів і виконання:**

- expectedId — serial, збережений у Main. Помічник повністю визначений нижче; -1 означає, що запис вже інший, а не код повернення самої команди. Перевірки до/після зменшують ризик змішування об’єктів, але не гарантують атомарності для того самого serial.

# UO.Random

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Вибирає одне псевдовипадкове ціле число. Random(min,max) включає обидві межі; стара форма Random(max) не включає верхню межу.

## Точний синтаксис

```text
UO.Random(max:Integer) -> Integer
UO.Random(min:Integer, max:Integer) -> Integer
```

## Параметри

- `min` — Нижня межа лише у формі з двома аргументами. Знакове 32-бітне ціле від -2147483648 до 2147483647; має бути <= max.
- `max` — Два аргументи: включена верхня межа, будь-який Integer. Один аргумент: виключена верхня межа 0..2147483647. Random(0) повертає 0.

## Повертає

Integer — одне вибране число, не логічний результат і не serial. Два аргументи: min <= результат <= max. Один додатний аргумент: 0 <= результат < max. Повторення дозволені.

## Поведінка

- Форми без аргументів немає. Однакові межі дають це число. Зворотний порядок меж або від’ємний єдиний аргумент спричиняють помилку скрипту; межі не міняються місцями.
- Підтримується весь знаковий 32-бітний діапазон без переповнення max+1. Для дробів можна вибрати цілі одиниці й поділити: Random(0,100)/100.0.
- Генератор належить runtime скрипту, одночасні виклики синхронізовані. Параметра seed немає; це інша функція, ніж BASIC Rnd. Збережіть результат для повторного використання.
- Команда локальна: не чекає, не рухає персонажа та не надсилає пакетів. Випадкову клітинку треба перевіряти; Random(0)=0 не створює індекс у порожньому масиві.

## Приклади

### Кинути кубик

```vb
# Кинути кубик
#
# Вибирає одне псевдовипадкове ціле число. Random(min,max) включає обидві межі; стара форма
# Random(max) не включає верхню межу.
#
# Integer — одне вибране число, не логічний результат і не serial. Два аргументи: min <=
# результат <= max. Один додатний аргумент: 0 <= результат < max. Повторення дозволені.

SUB Main()
    # min=1 та max=6 включають усі шість значень. roll зберігає один вибір; STR перетворює його на
    # текст. Наступний виклик може дати те саме число.

    VAR roll = UO.Random(1, 6)
    UO.Print(STR(roll))
END SUB
```

**Пояснення параметрів і виконання:**

- min=1 та max=6 включають усі шість значень. roll зберігає один вибір; STR перетворює його на текст. Наступний виклик може дати те саме число.

### Випадкова пауза

```vb
# Випадкова пауза
#
# Вибирає одне псевдовипадкове ціле число. Random(min,max) включає обидві межі; стара форма
# Random(max) не включає верхню межу.
#
# Integer — одне вибране число, не логічний результат і не serial. Два аргументи: min <=
# результат <= max. Один додатний аргумент: 0 <= результат < max. Повторення дозволені.

SUB Main()
    # min=350 і max=700 — включені межі в мілісекундах. Random обчислює delay; UO.Wait(delay) чекає.
    # Зберігайте мінімальну затримку, потрібну серверу.

    VAR delay = UO.Random(350, 700)
    UO.Print(STR(delay))
    UO.Wait(delay)
END SUB
```

**Пояснення параметрів і виконання:**

- min=350 і max=700 — включені межі в мілісекундах. Random обчислює delay; UO.Wait(delay) чекає. Зберігайте мінімальну затримку, потрібну серверу.

### Старі індекси й однакові межі

```vb
# Старі індекси й однакові межі
#
# Вибирає одне псевдовипадкове ціле число. Random(min,max) включає обидві межі; стара форма
# Random(max) не включає верхню межу.
#
# Integer — одне вибране число, не логічний результат і не serial. Два аргументи: min <=
# результат <= max. Один додатний аргумент: 0 <= результат < max. Повторення дозволені.

SUB Main()
    # Random(10) дає 0..9, ніколи 10. Random(7,7) завжди дає 7. Random(-2,2) може дати -2,-1,0,1,2.
    # Кожен вираз — окремий вибір.

    VAR index = UO.Random(10)
    VAR fixedValue = UO.Random(7, 7)
    VAR offset = UO.Random(-2, 2)
    UO.Print(STR(index) + ', ' + STR(fixedValue) + ', ' + STR(offset))
END SUB
```

**Пояснення параметрів і виконання:**

- Random(10) дає 0..9, ніколи 10. Random(7,7) завжди дає 7. Random(-2,2) може дати -2,-1,0,1,2. Кожен вираз — окремий вибір.

# Sin

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Обчислює синус.

## Точний синтаксис

```text
Sin(radians:Any) -> Decimal
```

## Параметри

- `radians` — Обов’язковий Integer/Decimal або десятковий текст із крапкою й необов’язковою експонентою, наприклад "-1.25e2". Мова інтерфейсу не впливає. Нерозпізнаний текст (зокрема hex-рядок), Unit, Array та Object дають 0; числовий hex-літерал вже Integer. Можливі NaN/Infinity. Вхід у радіанах, не градусах чи ігрових напрямках. Скінченний результат у [-1,1]; NaN/нескінченний вхід дає NaN.

## Повертає

Decimal — sin(radians). Вхід у радіанах, не градусах чи ігрових напрямках. Скінченний результат у [-1,1]; NaN/нескінченний вхід дає NaN. Число, не ID чи ознака успіху; 1/0 тут не означають виконано/не виконано.

## Поведінка

- Локальне обчислення в потоці скрипту без запиту серверу, руху, прицілу, очікування чи зміни глобальних змінних.
- Decimal — двійковий Double, не .NET decimal. Результати можуть бути наближеними; порівнюйте скінченні дробові значення з допуском. NaN/Infinity не підходять для координат або кількості предметів.
- Вхід у радіанах, не градусах чи ігрових напрямках. Скінченний результат у [-1,1]; NaN/нескінченний вхід дає NaN.

### Внутрішні функції: від виклику до результату

Це реальні етапи реєстрації та перетворення. Повні помічники демонструють формули скрипту, не замінюючи математику платформи.

#### 1. Register

Register прив’язує ім’я BASIC з одним аргументом до нативного обчислення. Після перетворення викликає System.Math, не прихований скрипт чи процедуру сервера.

Decimal — sin(radians). Вхід у радіанах, не градусах чи ігрових напрямках. Скінченний результат у [-1,1]; NaN/нескінченний вхід дає NaN. Число, не ID чи ознака успіху; 1/0 тут не означають виконано/не виконано.

Код проєкту: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApi.cs`; функція `Register`.

#### 2. BasicDouble

BasicDouble зберігає Integer/Decimal, читає текст з інваріантним NumberStyles.Float і дає 0 для непідтримуваного значення. Abs обробляє звичайний Integer прямо перед переходом до Double.

Обов’язковий Integer/Decimal або десятковий текст із крапкою й необов’язковою експонентою, наприклад "-1.25e2". Мова інтерфейсу не впливає. Нерозпізнаний текст (зокрема hex-рядок), Unit, Array та Object дають 0; числовий hex-літерал вже Integer. Можливі NaN/Infinity.

Код проєкту: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApi.cs`; функція `BasicDouble`.

Локальне обчислення в потоці скрипту без запиту серверу, руху, прицілу, очікування чи зміни глобальних змінних.


## Приклади

### Пряме обчислення

```vb
# Пряме обчислення
#
# Обчислює синус.
#
# Decimal — sin(radians). Вхід у радіанах, не градусах чи ігрових напрямках. Скінченний
# результат у [-1,1]; NaN/нескінченний вхід дає NaN. Число, не ID чи ознака успіху; 1/0 тут не
# означають виконано/не виконано.

SUB Main()
    # radians = 0; очікується 0 (~ означає приблизно). value зберігає результат, CStr лише форматує
    # його для Print.

    VAR value = Sin(0)
    UO.Print(CStr(value))
END SUB
```

**Пояснення параметрів і виконання:**

- radians = 0; очікується 0 (~ означає приблизно). value зберігає результат, CStr лише форматує його для Print.

### Інший аргумент через змінну

```vb
# Інший аргумент через змінну
#
# Обчислює синус.
#
# Decimal — sin(radians). Вхід у радіанах, не градусах чи ігрових напрямках. Скінченний
# результат у [-1,1]; NaN/нескінченний вхід дає NaN. Число, не ID чи ознака успіху; 1/0 тут не
# означають виконано/не виконано.

SUB Main()
    # radians = 1.5707963267948966; очікується ~1 (~ означає приблизно). value зберігає результат,
    # CStr лише форматує його для Print.

    VAR inputValue = 1.5707963267948966
    VAR value = Sin(inputValue)
    UO.Print(CStr(value))
END SUB
```

**Пояснення параметрів і виконання:**

- radians = 1.5707963267948966; очікується ~1 (~ означає приблизно). value зберігає результат, CStr лише форматує його для Print.

### Повна допоміжна функція

```vb
# Повна допоміжна функція
#
# Обчислює синус.
#
# Decimal — sin(radians). Вхід у радіанах, не градусах чи ігрових напрямках. Скінченний
# результат у [-1,1]; NaN/нескінченний вхід дає NaN. Число, не ID чи ознака успіху; 1/0 тут не
# означають виконано/не виконано.

# manual-check: scalar-math Sin
SUB Main()
    # degrees — градуси, pi/180 переводить їх у радіани перед Sin. SineDegrees(30)≈0.5.

    VAR value = SineDegrees(30)
    UO.Print(CStr(value))
END SUB

SUB SineDegrees(degrees)
    RETURN Sin(degrees*3.141592653589793/180)
END SUB
```

**Пояснення параметрів і виконання:**

- degrees — градуси, pi/180 переводить їх у радіани перед Sin. SineDegrees(30)≈0.5.

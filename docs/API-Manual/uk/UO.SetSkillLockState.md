# UO.SetSkillLockState

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Запитує зміну режиму навички.

## Точний синтаксис

```text
UO.SetSkillLockState(SkillName:Any, skillState:Any) -> Unit
```

## Параметри

- `SkillName` — Обов’язкова навичка: ім’я з даних клієнта, як "Mining" або "Animal Lore", чи десятковий індекс 0..Skills.Length−1 числом або рядком. Регістр не важливий, крайні пробіли прибираються, _ замінюється пробілом. Це не ID предмета й не індекс від 1. Числовий рядок завжди означає індекс.
- `skillState` — Обов’язковий режим: 0 — підвищення, 1 — зниження, 2 — блокування. Це три коди, не Boolean; true/false не описують усі режими.

## Повертає

Unit — значення не повертається. Не сприймайте результат як успіх/помилку й не порівнюйте з true. Наступне читання показує локальну модель, не підтвердження сервера.

- Допустимий запит надсилає один пакет через GameActions і відразу змінює локальний режим. Правила сервера залишаються чинними; зростання не гарантується. Невідома навичка, недопустимий індекс/режим і відсутність персонажа ігноруються без пакета.

#
# Запитує зміну режиму навички.
#
# Unit — значення не повертається. Не сприймайте результат як успіх/помилку й не порівнюйте з

SUB Main()
    # Поріг 95.1 і режими 0/1/2 — налаштування прикладу. −1 перевіряється до зміни режиму. Читання

### Повна допоміжна функція

```vb
# Повна допоміжна функція
#
# Запитує зміну режиму навички.
#
# Unit — значення не повертається. Не сприймайте результат як успіх/помилку й не порівнюйте з
# true. Наступне читання показує локальну модель, не підтвердження сервера.

SUB Main()
    # Повний помічник наведений після Main. selector обирає навичку/характеристику, mode — режим
    # запису. ReadValue/ReadMode повертають вихідне число; ApplyMode перевіряє аргументи, виконує
    # дію та не повертає значення. WAIT(1000) розділяє два знімки читання.

    ApplyMode('Mining', 2)
END SUB

SUB ApplyMode(selector, mode)
    IF mode < 0 OR mode > 2 THEN
        RETURN
    END IF
    IF UO.GetSkillLockState(selector) < 0 THEN
        RETURN
    END IF
    UO.SetSkillLockState(selector, mode)
END SUB
```

**Пояснення параметрів і виконання:**

- Повний помічник наведений після Main. selector обирає навичку/характеристику, mode — режим запису. ReadValue/ReadMode повертають вихідне число; ApplyMode перевіряє аргументи, виконує дію та не повертає значення. WAIT(1000) розділяє два знімки читання.

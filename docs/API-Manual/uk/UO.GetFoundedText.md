# UO.GetFoundedText

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Читає збережений текст запису журналу, вибраного цим скриптом.

## Точний синтаксис

```text
UO.GetFoundedText() -> String
```

## Параметри

Параметрів немає.

## Повертає

String — вибраний текст або порожній рядок, якщо запис не вибрано. Справжній запис також може мати порожній текст. Це не serial, не індекс рядка та не логічна ознака успіху.

## Поведінка

- InJournal, InJournalBetweenTimes, Journal/GetJournal і LastJournalMessage змінюють вибір. Невдалий пошук, неправильний індекс Journal або очищення цим скриптом скидають його. Getter не приймає аргументів і не виконує нового пошуку.
- Нові повідомлення не підміняють збережений текст. Якщо запис видалено або витіснено, текст лишається, а GetFoundedTextIndex/LineIndex стає -1. Інший скрипт може очистити спільний журнал; збережені змінні не зміняться.

## Приклади

### Прочитати знайдене повідомлення

```vb
# Прочитати знайдене повідомлення
#
# Читає збережений текст запису журналу, вибраного цим скриптом.
#
# String — вибраний текст або порожній рядок, якщо запис не вибрано. Справжній запис також може
# мати порожній текст. Це не serial, не індекс рядка та не логічна ознака успіху.

SUB Main()
    # needle — підрядок із урахуванням регістру. Перевіряйте InJournal > 0: результат — позиція плюс
    # 1, а не кількість збігів.

    IF UO.InJournal('needle') > 0 THEN
        VAR text = UO.GetFoundedText()
        UO.Print(text)
    END IF
END SUB
```

**Пояснення параметрів і виконання:**

- needle — підрядок із урахуванням регістру. Перевіряйте InJournal > 0: результат — позиція плюс 1, а не кількість збігів.

### Прочитати вибраний рядок

```vb
# Прочитати вибраний рядок
#
# Читає збережений текст запису журналу, вибраного цим скриптом.
#
# String — вибраний текст або порожній рядок, якщо запис не вибрано. Справжній запис також може
# мати порожній текст. Це не serial, не індекс рядка та не логічна ознака успіху.

SUB Main()
    # Journal(0) вибирає найновіший запис. Збережіть текст та індекс до Print, який може додати
    # повідомлення. Порожній текст сам по собі не означає відсутності запису.

    VAR latest = UO.Journal(0)
    VAR index = UO.LineIndex()
    VAR text = UO.GetFoundedText()
    IF index >= 0 THEN
        UO.Print(text)
    END IF
END SUB
```

**Пояснення параметрів і виконання:**

- Journal(0) вибирає найновіший запис. Збережіть текст та індекс до Print, який може додати повідомлення. Порожній текст сам по собі не означає відсутності запису.

### Зберегти текст перед іншим пошуком

```vb
# Зберегти текст перед іншим пошуком
#
# Читає збережений текст запису журналу, вибраного цим скриптом.
#
# String — вибраний текст або порожній рядок, якщо запис не вибрано. Справжній запис також може
# мати порожній текст. Це не serial, не індекс рядка та не логічна ознака успіху.

SUB Main()
    # saved копіює перший результат до другого пошуку, який змінює вибір. Подальші повідомлення й
    # пошуки не змінять цю змінну.

    IF UO.InJournal('success') > 0 THEN
        VAR saved = UO.GetFoundedText()
        VAR another = UO.InJournal('failed')
        UO.Print(saved)
    END IF
END SUB
```

**Пояснення параметрів і виконання:**

- saved копіює перший результат до другого пошуку, який змінює вибір. Подальші повідомлення й пошуки не змінять цю змінну.

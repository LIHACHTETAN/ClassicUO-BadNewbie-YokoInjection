# UO.GetStr

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Читає поточну силу (Strength, STR) персонажа.

## Точний синтаксис

```text
UO.GetStr() -> Integer
UO.GetStr(ObjID:Any) -> Integer
```

## Параметри

- `ObjID` — ObjID лише у показаній формі з одним аргументом: serial персонажа числом, десятковим/0x hex-рядком, "self", "lasttarget" чи ім’ям AddObject. Обирає об’єкт, не graphic/type. Без аргументу читається поточний персонаж.

## Повертає

Integer — поточні очки характеристики, 0..65535 у моделі клієнта; не відсоток, ID, навичка, режим блокування чи Boolean. 0 також означає відсутнього/видаленого персонажа або недоступний об’єкт. Порівнюйте з числовою вимогою, не = TRUE. Це не ліміт характеристики й не гарантоване базове значення без модифікаторів.

## Поведінка

- Підтримуються () для self і (ObjID) для явного об’єкта. Інших необов’язкових аргументів немає.
- Читає Player.Strength, якщо Player існує й не знищений; інакше 0. Наявний мертвий персонаж не є видаленим об’єктом. Характеристика не обчислюється з HP, мани чи витривалості.
- GetStr/GetInt/GetDex приймають ObjID, але клієнт зберігає ці характеристики лише у PlayerMobile: будь-який інший serial дає 0, навіть для завантаженого mobile. Це обмеження щодо загального опису Stealth; чужа характеристика не вгадується.
- Invoke читає на ігровому потоці; очікування можна скасувати разом зі скриптом. Не запитує status, не відкриває target, не надсилає пакета, не змінює характеристику й не додає затримки.
- Кожен виклик читає локальні дані заново. Змінна зберігає знімок; окремі читання можуть бачити різні оновлення сервера. Ненульовий результат не перевіряє з’єднання. Нуль буває значенням або відсутністю даних.
- Рівнозначні імена характеристики з UO. та без нього, без урахування регістру: `Str Strength GetStr GetStrength`.
- Int(value) без UO. округлює BASIC-число вниз, Str(value) без UO. форматує значення в текст. Це інші операції, ніж UO.Int()/UO.Str(), які читають характеристики. GetInt(ObjID) не округлює числа.
- ExecuteStealthCompatibility.Arg спершу розпізнає ім’я об’єкта, потім перетворює число. Невідомий нечисловий рядок спричиняє помилку перетворення, не приціл. Decimal приводиться до Integer, Array/Unit — до 0. Для вибору персонажа використовуйте коректний serial.

### Прочитати й вивести очки

```vb
# Прочитати й вивести очки

# Читає поточну силу (Strength, STR) персонажа.
#
# Integer — поточні очки характеристики, 0..65535 у моделі клієнта; не відсоток, ID, навичка,
# режим блокування чи Boolean. 0 також означає відсутнього/видаленого персонажа або недоступний
# об’єкт. Порівнюйте з числовою вимогою, не = TRUE. Це не ліміт характеристики й не гарантоване
# базове значення без модифікаторів.

SUB Main()
    # value зберігає числовий результат; CStr лише форматує його для журналу. Аргументів і дії
    # персонажа немає.

    VAR value = UO.GetStr()

```

### Порівняти два знімки

```vb
# Порівняти два знімки
#
# Читає поточну силу (Strength, STR) персонажа.
#
# Integer — поточні очки характеристики, 0..65535 у моделі клієнта; не відсоток, ID, навичка,
# режим блокування чи Boolean. 0 також означає відсутнього/видаленого персонажа або недоступний
# об’єкт. Порівнюйте з числовою вимогою, не = TRUE. Це не ліміт характеристики й не гарантоване
# базове значення без модифікаторів.

SUB Main()
    # before та after розділяє 1000 мс; WAIT додано до прикладу. change=after-before може бути
    # додатним, нульовим або від’ємним. Сам він не розрізняє всі проміжні оновлення й вихід зі
    # світу.

    VAR before = UO.GetStr()
    WAIT(1000)
    VAR after = UO.GetStr()
    VAR change = after - before
    UO.Print('Change: ' + CStr(change))
END SUB
```

**Пояснення параметрів і виконання:**

- before та after розділяє 1000 мс; WAIT додано до прикладу. change=after-before може бути додатним, нульовим або від’ємним. Сам він не розрізняє всі проміжні оновлення й вихід зі світу.

### Повна функція перевірки вимоги

```vb
# Повна функція перевірки вимоги
#
# Читає поточну силу (Strength, STR) персонажа.
#
# Integer — поточні очки характеристики, 0..65535 у моделі клієнта; не відсоток, ID, навичка,
# режим блокування чи Boolean. 0 також означає відсутнього/видаленого персонажа або недоступний
# об’єкт. Порівнюйте з числовою вимогою, не = TRUE. Це не ліміт характеристики й не гарантоване
# базове значення без модифікаторів.

SUB Main()
    # minimum=80 — приклад вимоги, не ліміт клієнта. AttributeAtLeast(minimum) відхиляє відсутнього
    # персонажа, один раз читає характеристику й повертає Integer Boolean: 1=TRUE або 0=FALSE за
    # умовою >= minimum. Логічний результат дає порівняння, не сама характеристика.

    IF AttributeAtLeast(80) = TRUE THEN
        UO.Print('Requirement met')
    ELSE
        UO.Print('Requirement not met or no player')
    END IF
END SUB

SUB AttributeAtLeast(minimum)
    IF UO.Self() = 0 THEN
        RETURN FALSE
    END IF
    VAR value = UO.GetStr()
    RETURN value >= minimum
END SUB
```

**Пояснення параметрів і виконання:**

- minimum=80 — приклад вимоги, не ліміт клієнта. AttributeAtLeast(minimum) відхиляє відсутнього персонажа, один раз читає характеристику й повертає Integer Boolean: 1=TRUE або 0=FALSE за умовою >= minimum. Логічний результат дає порівняння, не сама характеристика.

### Обрати персонажа за serial та ім’ям об’єкта

```vb
# Обрати персонажа за serial та ім’ям об’єкта
#
# Читає поточну силу (Strength, STR) персонажа.
#
# Integer — поточні очки характеристики, 0..65535 у моделі клієнта; не відсоток, ID, навичка,
# режим блокування чи Boolean. 0 також означає відсутнього/видаленого персонажа або недоступний
# об’єкт. Порівнюйте з числовою вимогою, не = TRUE. Це не ліміт характеристики й не гарантоване
# базове значення без модифікаторів.

SUB Main()
    # id — результат UO.Self(), не type. AddObject зберігає ID як statSubject без прицілу, оскільки
    # другий аргумент указано. Обидва виклики обирають одного персонажа, але читання не атомарні.

    VAR id = UO.Self()
    IF id <> 0 THEN
        UO.AddObject('statSubject', id)
        VAR direct = UO.GetStr(id)
        VAR byName = UO.GetStr('statSubject')
        UO.Print('Direct: ' + CStr(direct) + '; alias: ' + CStr(byName))
    END IF
END SUB
```

**Пояснення параметрів і виконання:**

- id — результат UO.Self(), не type. AddObject зберігає ID як statSubject без прицілу, оскільки другий аргумент указано. Обидва виклики обирають одного персонажа, але читання не атомарні.

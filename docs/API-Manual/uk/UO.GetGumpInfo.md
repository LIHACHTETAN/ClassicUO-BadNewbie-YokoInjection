# UO.GetGumpInfo

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Читає узгоджений знімок одного серверного гампа та його елементів.

## Точний синтаксис

```text
UO.GetGumpInfo(GumpIndex:Any) -> Array
```

## Параметри

- `GumpIndex` — Обов’язковий Integer: індекс від 0 до GetGumpsCount()-1. Це не serial і не GumpID. Від’ємний індекс та індекс поза списком недійсні. Відкриття, закриття або зміна порядку вікон змінюють індекси.

## Повертає

Array із п’яти полів: [0] Integer serial; [1] Integer GumpID; [2] Array<String> непорожніх текстів; [3] Array<String> описів звичайних кнопок; [4] Array<String> усіх живих елементів, включно з вкладеними. Недійсний, закритий або ігнорований гамп повертає []. ID зі старшим бітом — від’ємні Integer; Hex показує їхні біти.

## Поведінка

- Увесь знімок копіюється одним запитом ігрового потоку. Подальші зміни або закриття вікна не змінюють масиви. Список містить лише активні серверні гампи; локальні вікна рюкзака, мапи та налаштувань не входять до нього.
- Це масив BASIC, а не запис Pascal TGumpInfo чи початковий пакет розмітки. Опис містить тип, page, ID, X/Y та розміри; для кнопок — ButtonID, action, toPage і графіку; для перемикачів — checked та графіку inactive/active. Текст може містити пробіли та знаки =. Радіокнопки входять до [4], а не [3].
- AddGumpIgnoreByID/BySerial приховують результат цього читання в поточному скрипті; ClearGumpsIgnore скидає фільтр. GetGumpsCount не змінюється. Порожні масиви текстів можливі й у наявного гампа. Довжину масиву читає GetArrayLength, а не Len.

## Приклади

### Прочитати обидва ID

```vb
# Прочитати обидва ID
#
# Читає узгоджений знімок одного серверного гампа та його елементів.
#
# Array із п’яти полів: [0] Integer serial; [1] Integer GumpID; [2] Array<String> непорожніх
# текстів; [3] Array<String> описів звичайних кнопок; [4] Array<String> усіх живих елементів,
# включно з вкладеними. Недійсний, закритий або ігнорований гамп повертає []. ID зі старшим
# бітом — від’ємні Integer; Hex показує їхні біти.

SUB Main()
    # 0 вибирає перший серверний гамп. Перевірте GetArrayLength(info)=5 до звернення до полів.
    # info[0] — serial, info[1] — GumpID того самого знімка.

    VAR info = UO.GetGumpInfo(0)
    IF GetArrayLength(info) = 5 THEN
        UO.Print('Serial=' + Hex(info[0]))
        UO.Print('GumpID=' + Hex(info[1]))
    END IF
END SUB
```

**Пояснення параметрів і виконання:**

- 0 вибирає перший серверний гамп. Перевірте GetArrayLength(info)=5 до звернення до полів. info[0] — serial, info[1] — GumpID того самого знімка.

### Перелічити справжні ButtonID

```vb
# Перелічити справжні ButtonID
#
# Читає узгоджений знімок одного серверного гампа та його елементів.
#
# Array із п’яти полів: [0] Integer serial; [1] Integer GumpID; [2] Array<String> непорожніх
# текстів; [3] Array<String> описів звичайних кнопок; [4] Array<String> усіх живих елементів,
# включно з вкладеними. Недійсний, закритий або ігнорований гамп повертає []. ID зі старшим
# бітом — від’ємні Integer; Hex показує їхні біти.

SUB Main()
    # info[3] містить описи кнопок. i — індекс рядка, а поле ButtonID в описі задає ID для
    # відповіді. Радіокнопки належать до повного списку елементів.

    VAR info = UO.GetGumpInfo(0)
    IF GetArrayLength(info) = 5 THEN
        VAR buttons = info[3]
        VAR i = 0
        WHILE i < GetArrayLength(buttons)
            UO.Print(buttons[i])
            i = i + 1
        WEND
    END IF
END SUB
```

**Пояснення параметрів і виконання:**

- info[3] містить описи кнопок. i — індекс рядка, а поле ButtonID в описі задає ID для відповіді. Радіокнопки належать до повного списку елементів.

### Зберегти текст перед закриттям

```vb
# Зберегти текст перед закриттям
#
# Читає узгоджений знімок одного серверного гампа та його елементів.
#
# Array із п’яти полів: [0] Integer serial; [1] Integer GumpID; [2] Array<String> непорожніх
# текстів; [3] Array<String> описів звичайних кнопок; [4] Array<String> усіх живих елементів,
# включно з вкладеними. Недійсний, закритий або ігнорований гамп повертає []. ID зі старшим
# бітом — від’ємні Integer; Hex показує їхні біти.

SUB Main()
    # info[2] — копія текстів. CloseSimpleGump(0) закриває локально лише без заборони NoClose і
    # нічого не повертає. Збережені тексти залишаються; перед texts[0] перевіряється довжина масиву.

    VAR info = UO.GetGumpInfo(0)
    IF GetArrayLength(info) = 5 THEN
        VAR texts = info[2]
        UO.CloseSimpleGump(0)
        IF GetArrayLength(texts) > 0 THEN
            UO.Print(texts[0])
        END IF
    END IF
END SUB
```

**Пояснення параметрів і виконання:**

- info[2] — копія текстів. CloseSimpleGump(0) закриває локально лише без заборони NoClose і нічого не повертає. Збережені тексти залишаються; перед texts[0] перевіряється довжина масиву.

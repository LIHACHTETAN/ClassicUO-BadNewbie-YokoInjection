# UO.IsWorldCellPassable

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Перевіряє один перехід у сусідню світову клітину й повертає прохідність разом із висотою.

## Точний синтаксис

```text
UO.IsWorldCellPassable(CurrX:Any, CurrY:Any, CurrZ:Any, DestX:Any, DestY:Any, DestZ:Any, WorldNum:Any) -> Array
```

## Параметри

- `CurrX` — Обов’язкова світова координата X початкової клітини. Ціле 0..65535 у межах завантаженої карти, не координата гампа.
- `CurrY` — Обов’язкова світова координата Y початкової клітини. Ціле 0..65535 у межах завантаженої карти, не координата гампа.
- `CurrZ` — Обов’язкова початкова висота −128..127. Висота світу, не номер поверху. Недопустима висота відхиляється, не обрізається.
- `DestX` — Обов’язкова світова координата X цільової клітини. Ціле 0..65535 у межах завантаженої карти, не координата гампа.
- `DestY` — Обов’язкова світова координата Y цільової клітини. Ціле 0..65535 у межах завантаженої карти, не координата гампа.
- `DestZ` — Обов’язковий вхідний запасний Z, зазвичай CurrZ. Це не var: змінна не змінюється й не задає потрібний поверх. Розраховану висоту читайте з result[1]. Цей bridge завжди надає свою висоту; аргумент зберігає форму сигнатури Pascal.
- `WorldNum` — Обов’язковий номер карти: UO.WorldNum(). Перевіряється лише поточна карта з відомими розмірами; інша не завантажується.

## Повертає

Array із двох Integer: [0] — прохідність, 1 = TRUE, 0 = FALSE; [1] — розрахована Z. Лише перший елемент логічний. Сам масив не порівнюйте з TRUE. Нульова/від’ємна висота допустима; при [0]=0 вона не доводить досяжність. Відхилені аргументи дають [0, CurrZ].

## Поведінка

- Без руху, відкриття дверей, прицілу чи мережевих пакетів. Читає наявну локальну геометрію; сервер може згодом відхилити крок. Окремі запити можуть бачити різний стан.
- Допускається сусідня клітина з різницями X/Y не більше 1. Дальша ціль, вихід за карту, відсутній персонаж/карта та IsDestroyed відхиляються до колізій. Для всього маршруту використовуйте GetPathArray чи NewMoveXY.
- Однакові допустимі X/Y дають [1, CurrZ] без перевірки колізій: крок не потрібний. Це не перевірка можливості залишити клітину. Стан персонажа й чинні правила Pathfinder впливають на сусідній крок; без завантаженої геометрії він може відхилятися.

## Приклади

### Перевірити клітину на схід

```vb
# Перевірити клітину на схід
#
# Перевіряє один перехід у сусідню світову клітину й повертає прохідність разом із висотою.
#
# Array із двох Integer: [0] — прохідність, 1 = TRUE, 0 = FALSE; [1] — розрахована Z. Лише
# перший елемент логічний. Сам масив не порівнюйте з TRUE. Нульова/від’ємна висота допустима;
# при [0]=0 вона не доводить досяжність. Відхилені аргументи дають [0, CurrZ].

SUB Main()
    # x/y/z — початок; x+1/y — сусідня клітина; шостий z — запасна висота, останній аргумент —
    # поточна карта. Перевірте result[0] до використання result[1].

    VAR x = UO.GetX()
    VAR y = UO.GetY()
    VAR z = UO.GetZ()
    VAR result = UO.IsWorldCellPassable(x,y,z,x+1,y,z,UO.WorldNum())
    IF result[0] = TRUE THEN
        UO.Print('Passable, Z=' + CStr(result[1]))
    ELSE
        UO.Print('Blocked')
    END IF
END SUB
```

**Пояснення параметрів і виконання:**

- x/y/z — початок; x+1/y — сусідня клітина; шостий z — запасна висота, останній аргумент — поточна карта. Перевірте result[0] до використання result[1].

### Прочитати Z без зміни вхідного аргументу

```vb
# Прочитати Z без зміни вхідного аргументу
#
# Перевіряє один перехід у сусідню світову клітину й повертає прохідність разом із висотою.
#
# Array із двох Integer: [0] — прохідність, 1 = TRUE, 0 = FALSE; [1] — розрахована Z. Лише
# перший елемент логічний. Сам масив не порівнюйте з TRUE. Нульова/від’ємна висота допустима;
# при [0]=0 вона не доводить досяжність. Відхилені аргументи дають [0, CurrZ].

SUB Main()
    # proposedZ залишається 0. targetZ читається з result[1], не з аргументу. Після відмови приклад
    # не робить висновків про висоту.

    VAR x = UO.GetX()
    VAR y = UO.GetY()
    VAR z = UO.GetZ()

    VAR result = UO.IsWorldCellPassable(x,y,z,x,y+1,proposedZ,UO.WorldNum())
    IF result[0] = 1 THEN
        VAR targetZ = result[1]
        UO.Print('Input=' + CStr(proposedZ) + '; result=' + CStr(targetZ))
    END IF
END SUB
```

**Пояснення параметрів і виконання:**

- proposedZ залишається 0. targetZ читається з result[1], не з аргументу. Після відмови приклад не робить висновків про висоту.

### Повна функція IsCellOpen

```vb
# Повна функція IsCellOpen
#
# Перевіряє один перехід у сусідню світову клітину й повертає прохідність разом із висотою.
#
# Array із двох Integer: [0] — прохідність, 1 = TRUE, 0 = FALSE; [1] — розрахована Z. Лише
# перший елемент логічний. Сам масив не порівнюйте з TRUE. Нульова/від’ємна висота допустима;
# при [0]=0 вона не доводить досяжність. Відхилені аргументи дають [0, CurrZ].

SUB Main()
    # Повний помічник після Main приймає початкові X/Y/Z, цільові X/Y та карту. Додає обов’язковий
    # шостий аргумент і повертає лише Integer 1/0, не масив. Тому IsCellOpen можна порівнювати з
    # TRUE. Персонаж не рухається.

    VAR x = UO.GetX()
    VAR y = UO.GetY()
    VAR openCell = IsCellOpen(x,y,UO.GetZ(),x+1,y+1,UO.WorldNum())
    IF openCell = TRUE THEN
        UO.Print('Diagonal cell is locally passable')
    END IF
END SUB

SUB IsCellOpen(x,y,z,toX,toY,map)
    VAR cellResult = UO.IsWorldCellPassable(x,y,z,toX,toY,z,map)
    IF GetArrayLength(cellResult) <> 2 THEN
        RETURN 0
    END IF
    RETURN cellResult[0]
END SUB
```

**Пояснення параметрів і виконання:**

- Повний помічник після Main приймає початкові X/Y/Z, цільові X/Y та карту. Додає обов’язковий шостий аргумент і повертає лише Integer 1/0, не масив. Тому IsCellOpen можна порівнювати з TRUE. Персонаж не рухається.

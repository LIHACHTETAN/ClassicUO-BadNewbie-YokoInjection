# UO.GetStamina

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Читає поточну витривалість з локальної моделі.

## Точний синтаксис

```text
UO.GetStamina() -> Integer
```

## Параметри

Параметрів немає.

## Повертає

Integer — значення поля Stamina, не відсоток і не Boolean. 0 може бути справжнім значенням або відсутніми даними. Не діліть на нульовий максимум. Значення іншого mobile можуть бути невідомі. HP/HitsMax можуть містити відносну шкалу сервера замість точних очок. HP=0 не доводить смерть; для цього є Dead/IsDead.

## Поведінка

- Не відкриває status і не запитує оновлення сервера. На відміну від автоматичного запиту відсутніх HP у Stealth, цей клієнт лише читає наявні дані. Не змінює характеристики й не надсилає пакети.
- Результат — окреме читання. Світ може змінитися між Exists і наступним викликом; кілька запитів не утворюють атомарного знімка.
- Для об’єкта World.Get відкидає відсутні або IsDestroyed записи й отримує 0. HP/HitsMax читають поля Entity, зокрема предметів із цими полями; Mana/Stamina потребують Mobile. Без аргументу читається self. Не кожне ім’я без аргументів має форму з ID: дивіться сигнатури.
- Читання без аргументів також повертає 0 для відсутнього або знищеного Player. Це стосується прямих Mana/Stamina та їхніх максимумів, а не лише форм через World.Get. Наявний мертвий персонаж може зберігати значення.

### Внутрішні функції: від виклику до результату

Це справжні внутрішні етапи C#. ReadValue повністю визначена в прикладі; це допоміжна функція, а не прихована вбудована команда.

#### 1. RegisterCharacterGetterAliases

Під час створення runtime RegisterCharacterGetterAliases реєструє імена й форми. Без аргументу береться bridge.Self; з аргументом — вибраний serial. Наявні реєстрації зберігаються.

Integer — значення поля Stamina, не відсоток і не Boolean. 0 може бути справжнім значенням або відсутніми даними. Не діліть на нульовий максимум. Значення іншого mobile можуть бути невідомі. HP/HitsMax можуть містити відносну шкалу сервера замість точних очок. HP=0 не доводить смерть; для цього є Dead/IsDead.

Код проєкту: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApiUO.cs`; функція `RegisterCharacterGetterAliases`.

#### 2. Invoke

Invoke читає дані в ігровому потоці; робочий потік чекає обробки запиту менеджером. Скасування скрипту перериває очікування. Додаткові затримки й мережеві запити не додаються.

Результат — окреме читання. Світ може змінитися між Exists і наступним викликом; кілька запитів не утворюють атомарного знімка.

Код проєкту: `src/ClassicUO.Client/Game/Managers/ClassicUOInjectionApiBridge.cs`; функція `Invoke`.

## Приклади

### Показати значення свого персонажа

```vb
# Показати значення свого персонажа
#
# Читає поточну витривалість з локальної моделі.
#
# Integer — значення поля Stamina, не відсоток і не Boolean. 0 може бути справжнім значенням або
# відсутніми даними. Не діліть на нульовий максимум. Значення іншого mobile можуть бути
# невідомі. HP/HitsMax можуть містити відносну шкалу сервера замість точних очок. HP=0 не
# доводить смерть; для цього є Dead/IsDead.

SUB Main()
    # Виклик без аргументів читає self. value зберігає одне число; STR перетворює його лише для
    # повідомлення.

    VAR value = UO.GetStamina()
    UO.Print('GetStamina: ' + STR(value))
END SUB
```

**Пояснення параметрів і виконання:**

- Виклик без аргументів читає self. value зберігає одне число; STR перетворює його лише для повідомлення.

### Повна допоміжна функція ReadValue

```vb
# Повна допоміжна функція ReadValue
#
# Читає поточну витривалість з локальної моделі.
#
# Integer — значення поля Stamina, не відсоток і не Boolean. 0 може бути справжнім значенням або
# відсутніми даними. Не діліть на нульовий максимум. Значення іншого mobile можуть бути
# невідомі. HP/HitsMax можуть містити відносну шкалу сервера замість точних очок. HP=0 не
# доводить смерть; для цього є Dead/IsDead.

SUB Main()
    # Це ім’я не має форми з ID. ReadValue без параметрів читає self; WAIT(1000) розділяє два
    # виклики. Порівняння знімків може пропустити проміжні зміни.

    VAR before = ReadValue()
    WAIT(1000)
    VAR after = ReadValue()
    UO.Print('Before: ' + CStr(before) + '; after: ' + CStr(after))
END SUB

SUB ReadValue()
    RETURN UO.GetStamina()
END SUB
```

**Пояснення параметрів і виконання:**

- Це ім’я не має форми з ID. ReadValue без параметрів читає self; WAIT(1000) розділяє два виклики. Порівняння знімків може пропустити проміжні зміни.

# UO.GetMaxMana

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Читає максимальну ману з локальної моделі.

## Точний синтаксис

```text
UO.GetMaxMana() -> Integer
UO.GetMaxMana(ObjID:Any) -> Any
```

## Параметри

- `ObjID` — Необов’язковий об’єкт у показаних формах: serial числом/hex-рядком, self, lasttarget або зареєстроване ім’я AddObject. Це не type. Без аргументу читається self. Невідомий текст у деяких формах спричиняє помилку перетворення; спочатку перевірте ім’я.

## Повертає

Integer — значення поля ManaMax, не відсоток і не Boolean. 0 може бути справжнім значенням або відсутніми даними. Не діліть на нульовий максимум. Значення іншого mobile можуть бути невідомі. HP/HitsMax можуть містити відносну шкалу сервера замість точних очок. HP=0 не доводить смерть; для цього є Dead/IsDead.

## Поведінка

- Не відкриває status і не запитує оновлення сервера. На відміну від автоматичного запиту відсутніх HP у Stealth, цей клієнт лише читає наявні дані. Не змінює характеристики й не надсилає пакети.
- Результат — окреме читання. Світ може змінитися між Exists і наступним викликом; кілька запитів не утворюють атомарного знімка.
- Для об’єкта World.Get відкидає відсутні або IsDestroyed записи й отримує 0. HP/HitsMax читають поля Entity, зокрема предметів із цими полями; Mana/Stamina потребують Mobile. Без аргументу читається self. Не кожне ім’я без аргументів має форму з ID: дивіться сигнатури.
- Читання без аргументів також повертає 0 для відсутнього або знищеного Player. Це стосується прямих Mana/Stamina та їхніх максимумів, а не лише форм через World.Get. Наявний мертвий персонаж може зберігати значення.

#### 2. TryGetObject

#### 3. Invoke

Invoke читає дані в ігровому потоці; робочий потік чекає обробки запиту менеджером. Скасування скрипту перериває очікування. Додаткові затримки й мережеві запити не додаються.

# Повна допоміжна функція ReadValue
#
# Читає максимальну ману з локальної моделі.
#
# Integer — значення поля ManaMax, не відсоток і не Boolean. 0 може бути справжнім значенням або

SUB Main()
    # lasttarget — раніше вибраний об’єкт; Exists перевіряє наявність. obj — єдиний параметр

        VAR value = ReadValue('lasttarget')

    RETURN UO.GetMaxMana(obj)
END SUB

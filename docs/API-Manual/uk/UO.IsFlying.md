# UO.IsFlying

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Перевіряє політ персонажа.

## Точний синтаксис

```text
UO.IsFlying() -> Integer
UO.IsFlying(value:Any) -> Integer
```

## Параметри

- `value` — Необов’язковий об’єкт у показаних формах: serial числом/hex-рядком, self, lasttarget або зареєстроване ім’я AddObject. Це не type. Без аргументу читається self. Невідомий текст у деяких формах спричиняє помилку перетворення; спочатку перевірте ім’я.

## Повертає

Integer Boolean: 1 = TRUE, 0 = FALSE. Можна порівнювати з числами або логічними константами без лапок. 1 — mobile має IsFlying; 0 — прапорця немає або mobile відсутній. Висота Z сама по собі не означає політ.

Це логічний результат: 1 = TRUE, 0 = FALSE. Після VAR result = команда(...) можна писати IF result = TRUE THEN або IF result = 1 THEN; для негативного результату — IF result = FALSE THEN або IF result = 0 THEN. TRUE/FALSE без лапок. Викличте команду один раз і збережіть результат: повторний виклик може повторити дію або прочитати змінений стан.

## Поведінка

- Читає локальну модель: не відкриває target, не запитує status, не змінює прапорець і не надсилає пакет. Знищений об’єкт відсутній навіть до вилучення запису зі словника.
- Результат — окреме читання. Світ може змінитися між Exists і наступним викликом; кілька запитів не утворюють атомарного знімка.
- Poisoned/Flying враховують версію протоколу: до 7.0.0.0 біт 0x04 означає отруту; від 7.0.0.0 — політ, а отрута зберігається окремо. Політ не визначається за Z.

### Внутрішні функції: від виклику до результату

Це справжні внутрішні етапи C#. ReadState повністю визначена в прикладі; це допоміжна функція, а не прихована вбудована команда.

#### 1. RegisterCharacterGetterAliases

Під час створення runtime RegisterCharacterGetterAliases реєструє імена й форми. Без аргументу береться bridge.Self; з аргументом — вибраний serial. Наявні реєстрації зберігаються.

1 — mobile має IsFlying; 0 — прапорця немає або mobile відсутній. Висота Z сама по собі не означає політ.

Код проєкту: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApiUO.cs`; функція `RegisterCharacterGetterAliases`.

#### 2. TryGetObject

TryGetObject розпізнає число, hex-рядок і збережене ім’я. Ім’я AddObject визначається заново при кожному виклику; це не пошук graphic/type і не інтерактивний вибір.

Необов’язковий об’єкт у показаних формах: serial числом/hex-рядком, self, lasttarget або зареєстроване ім’я AddObject. Це не type. Без аргументу читається self. Невідомий текст у деяких формах спричиняє помилку перетворення; спочатку перевірте ім’я.

Код проєкту: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApiUO.cs`; функція `TryGetObject`.

#### 3. Invoke

Invoke читає дані в ігровому потоці; робочий потік чекає обробки запиту менеджером. Скасування скрипту перериває очікування. Додаткові затримки й мережеві запити не додаються.

Результат — окреме читання. Світ може змінитися між Exists і наступним викликом; кілька запитів не утворюють атомарного знімка.

Код проєкту: `src/ClassicUO.Client/Game/Managers/ClassicUOInjectionApiBridge.cs`; функція `Invoke`.

#### 4. Get

World.Get знаходить serial і повертає null для IsDestroyed. Потім читається прапорець Mobile. Alive перевіряє Exists і відсутність IsDead; предмети допускаються. Для власного Dead читається Player.IsDead.

1 — mobile має IsFlying; 0 — прапорця немає або mobile відсутній. Висота Z сама по собі не означає політ.

Код проєкту: `src/ClassicUO.Client/Game/World.cs`; функція `Get`.

Читає локальну модель: не відкриває target, не запитує status, не змінює прапорець і не надсилає пакет. Знищений об’єкт відсутній навіть до вилучення запису зі словника.

```vb
    # Порожні дужки читають self. active зберігає один результат; TRUE і FALSE обирають дві гілки.
```

```vb

#
# Перевіряє політ персонажа.
#
# Integer Boolean: 1 = TRUE, 0 = FALSE. Можна порівнювати з числами або логічними константами
# без лапок. 1 — mobile має IsFlying; 0 — прапорця немає або mobile відсутній. Висота Z сама по
```

```vb
# повторний виклик може повторити дію або прочитати змінений стан.

SUB Main()
    # Обидва виклики без аргументів читають self; WAIT(500) означає 500 мілісекунд. Порівнюються два

    IF before <> after THEN
        UO.Print('State changed: ' + CStr(before) + ' -> ' + CStr(after))
    END IF
```

# UO.FindCount

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Рахує об’єкти пошуку або кількість у конкретній стопці за ID.

## Точний синтаксис

```text
UO.FindCount() -> Integer
UO.FindCount(id:Any) -> Integer
```

## Параметри

- `id` — Необов’язковий лише для FindCount. Serial предмета: Integer, десятковий/hex-рядок, lasttarget, lastobject, backpack або ім’я AddObject. Потрібен ID, не graphic/type. Невідоме ім’я дає 0; self означає персонажа, тому тут також 0. Без аргументу повертається число об’єктів пошуку.

## Повертає

Integer — FindCount() повертає число знайдених об’єктів: одна стопка рахується як один item. FindCount(id) повертає поточний Amount цієї стопки; для невідомого/видаленого ID та персонажа — 0. Окремий предмет зазвичай має Amount=1. Це не ID, type чи Boolean.

## Поведінка

- Звичайний FindType з 1–5 аргументами, FindTypeEx і Count/CountEx/CountGround замінюють результати пошуку цього скрипту. Пошук без збігів очищує знімок. Зберігайте потрібні значення перед новим пошуком.
- Ці виклики не запускають пошук, не відкривають контейнери, не переміщують речі та не надсилають пакетів. Читаються завантажені клієнтом дані. FindCount(id) не потребує попереднього пошуку й не змінює його результати.
- FindItem/FindCount()/FindFullQuantity — знімок пошуку. FindQuantity та FindCount(id) читають поточну кількість: після пошуку предмет може змінитися чи зникнути.

## Приклади

### Прочитати результат пошуку золота

```vb
# Прочитати результат пошуку золота
#
# Рахує об’єкти пошуку або кількість у конкретній стопці за ID.
#
# Integer — FindCount() повертає число знайдених об’єктів: одна стопка рахується як один item.
# FindCount(id) повертає поточний Amount цієї стопки; для невідомого/видаленого ID та персонажа
# — 0. Окремий предмет зазвичай має Amount=1. Це не ID, type чи Boolean.

SUB Main()
    # type=0x0EED — золото, color=-1 — будь-який колір; backpack у цій формі FindType означає прямий
    # вміст рюкзака. value зберігає результат обраної команди; STR показує його текстом.

    UO.FindType(0x0EED, -1, 'backpack')
    VAR value = UO.FindCount()
    UO.Print(STR(value))
END SUB
```

**Пояснення параметрів і виконання:**

- type=0x0EED — золото, color=-1 — будь-який колір; backpack у цій формі FindType означає прямий вміст рюкзака. value зберігає результат обраної команди; STR показує його текстом.

### Порівняти предмети, стопку й суму

```vb
# Порівняти предмети, стопку й суму
#
# Рахує об’єкти пошуку або кількість у конкретній стопці за ID.
#
# Integer — FindCount() повертає число знайдених об’єктів: одна стопка рахується як один item.
# FindCount(id) повертає поточний Amount цієї стопки; для невідомого/видаленого ID та персонажа
# — 0. Окремий предмет зазвичай має Amount=1. Це не ID, type чи Boolean.

SUB Main()
    # Чотири читання стосуються одного пошуку. Дві стопки по 50: число об’єктів=2, перша стопка=50,
    # сума=100. FindItem — унікальний ID першої стопки, не її type.

    UO.FindType(0x0EED, -1, 'backpack')
    UO.Print(STR(UO.FindCount()))
    UO.Print(STR(UO.FindQuantity()))
    UO.Print(STR(UO.FindFullQuantity()))
    UO.Print('0x' + Hex(UO.FindItem()))
END SUB
```

**Пояснення параметрів і виконання:**

- Чотири читання стосуються одного пошуку. Дві стопки по 50: число об’єктів=2, перша стопка=50, сума=100. FindItem — унікальний ID першої стопки, не її type.

### Зберегти значення перед новим пошуком

```vb
# Зберегти значення перед новим пошуком
#
# Рахує об’єкти пошуку або кількість у конкретній стопці за ID.
#
# Integer — FindCount() повертає число знайдених об’єктів: одна стопка рахується як один item.
# FindCount(id) повертає поточний Amount цієї стопки; для невідомого/видаленого ID та персонажа
# — 0. Окремий предмет зазвичай має Amount=1. Це не ID, type чи Boolean.

SUB Main()
    # Перший type — золото, 0x0F7A — інший тип реагенту. Другий FindType замінює знімок. saved
    # зберігає попереднє значення; останній виклик читає новий результат.

    UO.FindType(0x0EED, -1, 'backpack')
    VAR saved = UO.FindCount()
    UO.FindType(0x0F7A, -1, 'backpack')
    UO.Print(STR(saved))
    UO.Print(STR(UO.FindCount()))
END SUB
```

**Пояснення параметрів і виконання:**

- Перший type — золото, 0x0F7A — інший тип реагенту. Другий FindType замінює знімок. saved зберігає попереднє значення; останній виклик читає новий результат.

### Прочитати предмет безпосередньо за ID

```vb
# Прочитати предмет безпосередньо за ID
#
# Рахує об’єкти пошуку або кількість у конкретній стопці за ID.
#
# Integer — FindCount() повертає число знайдених об’єктів: одна стопка рахується як один item.
# FindCount(id) повертає поточний Amount цієї стопки; для невідомого/видаленого ID та персонажа
# — 0. Окремий предмет зазвичай має Amount=1. Це не ID, type чи Boolean.

SUB Main()
    # lasttarget має вказувати на вже обраний у грі предмет. Новий курсор цілі не з’являється.
    # FindCount(id) читає поточну стопку, дає 0 для відсутнього предмета й не змінює знімок пошуку.

    VAR id = lasttarget
    VAR amount = UO.FindCount(id)
    UO.Print(STR(amount))
END SUB
```

**Пояснення параметрів і виконання:**

- lasttarget має вказувати на вже обраний у грі предмет. Новий курсор цілі не з’являється. FindCount(id) читає поточну стопку, дає 0 для відсутнього предмета й не змінює знімок пошуку.

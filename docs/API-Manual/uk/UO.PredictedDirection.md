# UO.PredictedDirection

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Читає прогнозовану сторону напрямку після вже поставлених у чергу кроків персонажа.

## Точний синтаксис

```text
UO.PredictedDirection() -> Integer
```

## Параметри

Параметрів немає.

## Повертає

Integer напрямку 0..7 без біта бігу. 0 — північ або відсутній персонаж.

## Поведінка

- Лише показана в синтаксисі функція UO без аргументів. Немає параметрів target, serial, type, цілі, відстані чи timeout. Число не Boolean, ID або запис tile: 1 не означає досягнення цілі.
- GetEndPosition читає X/Y/Z/напрямок останнього вже доданого Mobile.Step. Якщо черга порожня, читає поточне положення/напрямок персонажа. Читання O(1) не вилучає крок, не рухає, не надсилає пакет, не розраховує маршрут і не чекає прибуття.
- Напрямки світу: 0 північ, 1 північний схід, 2 схід, 3 південний схід, 4 південь, 5 південний захід, 6 захід, 7 північний захід. Екран ізометричний. Direction.Mask прибирає прапорець бігу; швидкість не повертається.
- Це локальний прогноз, не підтверджене прибуття. Нові/завершені кроки, відмова сервера, очищення черги чи телепорт можуть його змінити. Окремі виклики компонентів не атомарні; збіг X не доводить збіг Y/Z чи підтвердження сервера.
- Invoke читає дані в ігровому потоці; робочий потік чекає обробки запиту менеджером. Скасування скрипту перериває очікування. Додаткові затримки й мережеві запити не додаються.
- Зовнішні реалізації IApiBridge без IPredictedMovementBridge зберігають резервне читання поточних координат/напрямку. Classic UO реалізує інтерфейс з урахуванням черги.

PredictionEquals(expected) приймає числову координату/висоту/напрямок, перевіряє наявність персонажа та порівнює один компонент прогнозу. Повертає Integer Boolean: 1=TRUE або 0=FALSE. Не чекає і не гарантує прибуття.


## Приклади

### Прочитати один компонент

```vb
# Прочитати один компонент
#
# Читає прогнозовану сторону напрямку після вже поставлених у чергу кроків персонажа.
#
# Integer напрямку 0..7 без біта бігу. 0 — північ або відсутній персонаж.

SUB Main()
    # predicted зберігає один виклик без аргументів; CStr форматує число для журналу.

    VAR predicted = UO.PredictedDirection()
    UO.Print('Predicted: ' + CStr(predicted))
END SUB
```

**Пояснення параметрів і виконання:**

- predicted зберігає один виклик без аргументів; CStr форматує число для журналу.

### Спостерігати зміну прогнозу

```vb
# Спостерігати зміну прогнозу
#
# Читає прогнозовану сторону напрямку після вже поставлених у чергу кроків персонажа.
#
# Integer напрямку 0..7 без біта бігу. 0 — північ або відсутній персонаж.

SUB Main()
    # WAIT(100) зупиняє приклад на 100 мс. before та after можуть збігтися попри проміжний рух; ці
    # читання руху не запускають.

    VAR before = UO.PredictedDirection()
    WAIT(100)
    VAR after = UO.PredictedDirection()
    IF before <> after THEN
        UO.Print('Prediction changed: ' + CStr(before) + ' -> ' + CStr(after))
    END IF
END SUB
```

**Пояснення параметрів і виконання:**

- WAIT(100) зупиняє приклад на 100 мс. before та after можуть збігтися попри проміжний рух; ці читання руху не запускають.

### Повна функція порівняння

```vb
# Повна функція порівняння
#
# Читає прогнозовану сторону напрямку після вже поставлених у чергу кроків персонажа.
#
# Integer напрямку 0..7 без біта бігу. 0 — північ або відсутній персонаж.

SUB Main()
    # expected — приклад координати/висоти/напрямку, не аргумент нативної команди. PredictionEquals
    # перевіряє UO.Self(), читає один раз та повертає 1=TRUE при рівності, інакше 0=FALSE. Увесь код
    # функції наведено нижче Main. Збіг одного компонента не означає прибуття.

    IF PredictionEquals(4) = TRUE THEN
        UO.Print('Queued endpoint matches this component')
    ELSE
        UO.Print('Different component or no player')
    END IF
END SUB

SUB PredictionEquals(expected)
    IF UO.Self() = 0 THEN
        RETURN FALSE
    END IF
    VAR predicted = UO.PredictedDirection()
    RETURN predicted = expected
END SUB
```

**Пояснення параметрів і виконання:**

- expected — приклад координати/висоти/напрямку, не аргумент нативної команди. PredictionEquals перевіряє UO.Self(), читає один раз та повертає 1=TRUE при рівності, інакше 0=FALSE. Увесь код функції наведено нижче Main. Збіг одного компонента не означає прибуття.

# UO.GetLandTilesArray

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Шукає тайли землі за graphic/type у прямокутнику.

## Точний синтаксис

```text
UO.GetLandTilesArray(Xmin:Any, Ymin:Any, Xmax:Any, Ymax:Any, WorldNum:Any, TileType:Any) -> Any
```

## Параметри

- `Xmin` — Світові координати двох кутів включно, 0..65535. Переставлені кути нормалізуються. Не більше 1 000 000 клітинок; неправильні межі спричиняють помилку скрипту до читання карти.
- `Ymin` — Світові координати двох кутів включно, 0..65535. Переставлені кути нормалізуються. Не більше 1 000 000 клітинок; неправильні межі спричиняють помилку скрипту до читання карти.
- `Xmax` — Світові координати двох кутів включно, 0..65535. Переставлені кути нормалізуються. Не більше 1 000 000 клітинок; неправильні межі спричиняють помилку скрипту до читання карти.
- `Ymax` — Світові координати двох кутів включно, 0..65535. Переставлені кути нормалізуються. Не більше 1 000 000 клітинок; неправильні межі спричиняють помилку скрипту до читання карти.
- `WorldNum` — Номер карти/фасета 0..255; використовуйте UO.WorldNum(). Інша карта дає порожній Array. Зміна карти між порціями відкидає частковий результат.
- `TileType` — Один graphic/type тайла, зазвичай 0..65535, а не serial. 0 шукає саме graphic 0; -1 не означає будь-який тип. Без збігів результат порожній.

## Повертає

Array записів [graphic, X, Y, Z], усі поля Integer. graphic — тип землі, Z — висота її основи. Без збігів: порожній Array. Кількість записів — GetArrayLength(result). Індекси починаються з 0. Це не Boolean, serial чи Pascal record; сьомого вихідного параметра немає.

## Поведінка

- Читає локальні дані, не змінює FindItem/FindCount, не рухає персонажа, не вмикає target і не надсилає команд серверу.
- X зростає; для кожного X зростає Y. Записи клітинки зберігають порядок bridge, а не сортування за відстанню чи висотою.
- Обробляє до 32 клітинок за порцію з м’яким бюджетом близько 1 мс. Між порціями перевіряє скасування. Складна клітинка або холодне читання можуть перевищити бюджет. Діліть великі області; світ може змінюватися під час пошуку.

### Внутрішні функції: від виклику до результату

Справжні етапи C#, а не додаткові UO-команди. Допоміжну процедуру повністю наведено в прикладах.

#### 1. ExecuteStealthCompatibility

Приймає шість аргументів; звичайна форма передає один тип, Ex перетворює Array або скаляр на типи.

Викликає FindPortableTiles у режимі land/static та повертає Array записів.

Вихідний код проєкту: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApiUO.cs`; функція `ExecuteStealthCompatibility`.

#### 2. FindPortableTiles

Перевіряє координати, карту та площу 64-бітною арифметикою, нормалізує кути й створює HashSet типів.

Зберігає курсор X/Y, планує ScanSlice через ExecutePathQuerySlice. Wait(0) перевіряє скасування між порціями; зміна карти дає порожній Array.

Вихідний код проєкту: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApiUO.cs`; функція `FindPortableTiles`.

#### 3. ScanSlice

Обробляє до 32 клітинок на ігровому потоці, зберігаючи курсор після кожної.

GetLandscapeTile дає graphic/Z/flags; GetStaticTiles — трійки graphic/Z/hue. Збіги додаються до результату; між порціями керування повертається клієнту.

Вихідний код проєкту: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApiUO.cs`; функція `ScanSlice`.

#### 4. GetChunk2

Приймає координати блока та прапорець завантаження; перевіряє обидві осі до лінійного індексу.

Повертає Chunk або null; Y за межами карти не підміняє сусіднім стовпцем. Повторно використовує завантажені блоки, нові читає за потреби.

Вихідний код проєкту: `src/ClassicUO.Client/Game/Map/Map.cs`; функція `GetChunk2`.

Читає локальні дані, не змінює FindItem/FindCount, не рухає персонажа, не вмикає target і не надсилає команд серверу.


## Приклади

### Пошук біля персонажа

```vb
# Пошук біля персонажа
#
# Шукає тайли землі за graphic/type у прямокутнику.
#
# Array записів [graphic, X, Y, Z], усі поля Integer. graphic — тип землі, Z — висота її основи.
# Без збігів: порожній Array. Кількість записів — GetArrayLength(result). Індекси починаються з
# 0. Це не Boolean, serial чи Pascal record; сьомого вихідного параметра немає.

SUB Main()
    # x/y — координати self, map — поточна карта. Область 3×3 включає межі. Ex отримує два зразки
    # типів, звичайна форма — один. Замініть graphic відповідно до ресурсів; це не ID предмета.

    VAR x = UO.GetX()
    VAR y = UO.GetY()
    VAR map = UO.WorldNum()
    VAR rows = UO.GetLandTilesArray(x, y, x + 2, y + 2, map, 0x0003)
    UO.Print("Records: " + CStr(GetArrayLength(rows)))
END SUB
```

**Пояснення параметрів і виконання:**

- x/y — координати self, map — поточна карта. Область 3×3 включає межі. Ex отримує два зразки типів, звичайна форма — один. Замініть graphic відповідно до ресурсів; це не ID предмета.

### Переставлені кути та всі поля

```vb
# Переставлені кути та всі поля
#
# Шукає тайли землі за graphic/type у прямокутнику.
#
# Array записів [graphic, X, Y, Z], усі поля Integer. graphic — тип землі, Z — висота її основи.
# Без збігів: порожній Array. Кількість записів — GetArrayLength(result). Індекси починаються з
# 0. Це не Boolean, serial чи Pascal record; сьомого вихідного параметра немає.

SUB Main()
    # Область 2×2 задана від більшого кута до меншого; межі нормалізуються. row — один запис.
    # Повністю наведена PrintTile лише друкує числа. Для землі hue=0 є заглушкою процедури; у записі
    # землі кольору немає.

    VAR x = UO.GetX()
    VAR y = UO.GetY()
    VAR map = UO.WorldNum()
    VAR rows = UO.GetLandTilesArray(x + 1, y + 1, x, y, map, 0x0003)
    VAR i = 0
    WHILE i < GetArrayLength(rows)
        VAR row = rows[i]
        PrintTile(row[0], row[1], row[2], row[3], 0)
        i = i + 1
    WEND
END SUB

SUB PrintTile(graphic, x, y, z, hue)
    UO.Print("Type=" + CStr(graphic) + " X=" + CStr(x) + " Y=" + CStr(y))
    UO.Print("Z=" + CStr(z) + " hue=" + CStr(hue))
END SUB
```

**Пояснення параметрів і виконання:**

- Область 2×2 задана від більшого кута до меншого; межі нормалізуються. row — один запис. Повністю наведена PrintTile лише друкує числа. Для землі hue=0 є заглушкою процедури; у записі землі кольору немає.

### Повторний пошук з обмеженням спроб

```vb
# Повторний пошук з обмеженням спроб
#
# Шукає тайли землі за graphic/type у прямокутнику.
#
# Array записів [graphic, X, Y, Z], усі поля Integer. graphic — тип землі, Z — висота її основи.
# Без збігів: порожній Array. Кількість записів — GetArrayLength(result). Індекси починаються з
# 0. Це не Boolean, serial чи Pascal record; сьомого вихідного параметра немає.

SUB Main()
    # Не більше трьох пошуків однієї клітинки з WAIT(250) між спробами. Кожен виклик створює новий
    # результат. Нульова довжина означає відсутність збігів зараз, а не назавжди на сервері.

    VAR x = UO.GetX()
    VAR y = UO.GetY()
    VAR map = UO.WorldNum()
    VAR attempt = 0
    WHILE attempt < 3
        VAR rows = UO.GetLandTilesArray(x, y, x, y, map, 0x0003)
        UO.Print("Records: " + CStr(GetArrayLength(rows)))
        attempt = attempt + 1
        WAIT(250)
    WEND
END SUB
```

**Пояснення параметрів і виконання:**

- Не більше трьох пошуків однієї клітинки з WAIT(250) між спробами. Кожен виклик створює новий результат. Нульова довжина означає відсутність збігів зараз, а не назавжди на сервері.

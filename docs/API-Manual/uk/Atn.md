# Atn

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Обчислює арктангенс.

## Точний синтаксис

```text
Atn(number:Any) -> Decimal
```

## Параметри

- `number` — Обов’язковий Integer/Decimal або десятковий текст із крапкою й необов’язковою експонентою, наприклад "-1.25e2". Мова інтерфейсу не впливає. Нерозпізнаний текст (зокрема hex-рядок), Unit, Array та Object дають 0; числовий hex-літерал вже Integer. Можливі NaN/Infinity. Вхід — нахил, вихід — радіани в [-pi/2,pi/2]; нескінченності дають межі, NaN зберігається. Це не atan2 з двома координатами.

## Повертає

Decimal — atan(number). Вхід — нахил, вихід — радіани в [-pi/2,pi/2]; нескінченності дають межі, NaN зберігається. Це не atan2 з двома координатами. Число, не ID чи ознака успіху; 1/0 тут не означають виконано/не виконано.

## Поведінка

- Локальне обчислення в потоці скрипту без запиту серверу, руху, прицілу, очікування чи зміни глобальних змінних.
- Decimal — двійковий Double, не .NET decimal. Результати можуть бути наближеними; порівнюйте скінченні дробові значення з допуском. NaN/Infinity не підходять для координат або кількості предметів.
- Вхід — нахил, вихід — радіани в [-pi/2,pi/2]; нескінченності дають межі, NaN зберігається. Це не atan2 з двома координатами.

### Внутрішні функції: від виклику до результату

Це реальні етапи реєстрації та перетворення. Повні помічники демонструють формули скрипту, не замінюючи математику платформи.

#### 1. Register

Register прив’язує ім’я BASIC з одним аргументом до нативного обчислення. Після перетворення викликає System.Math, не прихований скрипт чи процедуру сервера.

Decimal — atan(number). Вхід — нахил, вихід — радіани в [-pi/2,pi/2]; нескінченності дають межі, NaN зберігається. Це не atan2 з двома координатами. Число, не ID чи ознака успіху; 1/0 тут не означають виконано/не виконано.

Код проєкту: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApi.cs`; функція `Register`.

#### 2. BasicDouble

BasicDouble зберігає Integer/Decimal, читає текст з інваріантним NumberStyles.Float і дає 0 для непідтримуваного значення. Abs обробляє звичайний Integer прямо перед переходом до Double.

Обов’язковий Integer/Decimal або десятковий текст із крапкою й необов’язковою експонентою, наприклад "-1.25e2". Мова інтерфейсу не впливає. Нерозпізнаний текст (зокрема hex-рядок), Unit, Array та Object дають 0; числовий hex-літерал вже Integer. Можливі NaN/Infinity.

Код проєкту: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApi.cs`; функція `BasicDouble`.

Локальне обчислення в потоці скрипту без запиту серверу, руху, прицілу, очікування чи зміни глобальних змінних.


## Приклади

### Пряме обчислення

```vb
# Пряме обчислення
#
# Обчислює арктангенс.
#
# Decimal — atan(number). Вхід — нахил, вихід — радіани в [-pi/2,pi/2]; нескінченності дають
# межі, NaN зберігається. Це не atan2 з двома координатами. Число, не ID чи ознака успіху; 1/0
# тут не означають виконано/не виконано.

SUB Main()
    # number = 0; очікується 0 (~ означає приблизно). value зберігає результат, CStr лише форматує
    # його для Print.

    VAR value = Atn(0)
    UO.Print(CStr(value))
END SUB
```

**Пояснення параметрів і виконання:**

- number = 0; очікується 0 (~ означає приблизно). value зберігає результат, CStr лише форматує його для Print.

### Інший аргумент через змінну

```vb
# Інший аргумент через змінну
#
# Обчислює арктангенс.
#
# Decimal — atan(number). Вхід — нахил, вихід — радіани в [-pi/2,pi/2]; нескінченності дають
# межі, NaN зберігається. Це не atan2 з двома координатами. Число, не ID чи ознака успіху; 1/0
# тут не означають виконано/не виконано.

SUB Main()
    # number = 1; очікується ~0.7853981633974483 (~ означає приблизно). value зберігає результат,
    # CStr лише форматує його для Print.

    VAR inputValue = 1
    VAR value = Atn(inputValue)
    UO.Print(CStr(value))
END SUB
```

**Пояснення параметрів і виконання:**

- number = 1; очікується ~0.7853981633974483 (~ означає приблизно). value зберігає результат, CStr лише форматує його для Print.

### Повна допоміжна функція

```vb
# Повна допоміжна функція
#
# Обчислює арктангенс.
#
# Decimal — atan(number). Вхід — нахил, вихід — радіани в [-pi/2,pi/2]; нескінченності дають
# межі, NaN зберігається. Це не atan2 з двома координатами. Число, не ID чи ознака успіху; 1/0
# тут не означають виконано/не виконано.

# manual-check: scalar-math Atn
SUB Main()
    # rise/run — нахил. При run=0 запасний 0 не означає вертикального кута. SlopeDegrees(1,1)≈45;
    # усі квадранти не розрізняються.

    VAR value = SlopeDegrees(1,1)
    UO.Print(CStr(value))
END SUB

SUB SlopeDegrees(rise,run)
    IF run = 0 THEN
        RETURN 0
    END IF
    RETURN Atn(CDbl(rise)/CDbl(run))*180/3.141592653589793
END SUB
```

**Пояснення параметрів і виконання:**

- rise/run — нахил. При run=0 запасний 0 не означає вертикального кута. SlopeDegrees(1,1)≈45; усі квадранти не розрізняються.

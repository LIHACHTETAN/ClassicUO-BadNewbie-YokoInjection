# Exp

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Підносить e до степеня.

## Точний синтаксис

```text
Exp(power:Any) -> Decimal
```

## Параметри

- `power` — Обов’язковий Integer/Decimal або десятковий текст із крапкою й необов’язковою експонентою, наприклад "-1.25e2". Мова інтерфейсу не впливає. Нерозпізнаний текст (зокрема hex-рядок), Unit, Array та Object дають 0; числовий hex-літерал вже Integer. Можливі NaN/Infinity. Exp(0)=1. Великий додатний степінь дає Infinity, дуже від’ємний — 0 через втрату розрядності. NaN зберігається.

## Повертає

Decimal — e^power. Exp(0)=1. Великий додатний степінь дає Infinity, дуже від’ємний — 0 через втрату розрядності. NaN зберігається. Число, не ID чи ознака успіху; 1/0 тут не означають виконано/не виконано.

## Поведінка

- Локальне обчислення в потоці скрипту без запиту серверу, руху, прицілу, очікування чи зміни глобальних змінних.
- Decimal — двійковий Double, не .NET decimal. Результати можуть бути наближеними; порівнюйте скінченні дробові значення з допуском. NaN/Infinity не підходять для координат або кількості предметів.
- Exp(0)=1. Великий додатний степінь дає Infinity, дуже від’ємний — 0 через втрату розрядності. NaN зберігається.

### Внутрішні функції: від виклику до результату

Це реальні етапи реєстрації та перетворення. Повні помічники демонструють формули скрипту, не замінюючи математику платформи.

#### 1. Register

Register прив’язує ім’я BASIC з одним аргументом до нативного обчислення. Після перетворення викликає System.Math, не прихований скрипт чи процедуру сервера.

Decimal — e^power. Exp(0)=1. Великий додатний степінь дає Infinity, дуже від’ємний — 0 через втрату розрядності. NaN зберігається. Число, не ID чи ознака успіху; 1/0 тут не означають виконано/не виконано.

Код проєкту: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApi.cs`; функція `Register`.

#### 2. BasicDouble

BasicDouble зберігає Integer/Decimal, читає текст з інваріантним NumberStyles.Float і дає 0 для непідтримуваного значення. Abs обробляє звичайний Integer прямо перед переходом до Double.

Обов’язковий Integer/Decimal або десятковий текст із крапкою й необов’язковою експонентою, наприклад "-1.25e2". Мова інтерфейсу не впливає. Нерозпізнаний текст (зокрема hex-рядок), Unit, Array та Object дають 0; числовий hex-літерал вже Integer. Можливі NaN/Infinity.

Код проєкту: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApi.cs`; функція `BasicDouble`.

Локальне обчислення в потоці скрипту без запиту серверу, руху, прицілу, очікування чи зміни глобальних змінних.


## Приклади

### Пряме обчислення

```vb
# Пряме обчислення
#
# Підносить e до степеня.
#
# Decimal — e^power. Exp(0)=1. Великий додатний степінь дає Infinity, дуже від’ємний — 0 через
# втрату розрядності. NaN зберігається. Число, не ID чи ознака успіху; 1/0 тут не означають
# виконано/не виконано.

SUB Main()
    # power = 0; очікується 1 (~ означає приблизно). value зберігає результат, CStr лише форматує
    # його для Print.

    VAR value = Exp(0)
    UO.Print(CStr(value))
END SUB
```

**Пояснення параметрів і виконання:**

- power = 0; очікується 1 (~ означає приблизно). value зберігає результат, CStr лише форматує його для Print.

### Інший аргумент через змінну

```vb
# Інший аргумент через змінну
#
# Підносить e до степеня.
#
# Decimal — e^power. Exp(0)=1. Великий додатний степінь дає Infinity, дуже від’ємний — 0 через
# втрату розрядності. NaN зберігається. Число, не ID чи ознака успіху; 1/0 тут не означають
# виконано/не виконано.

SUB Main()
    # power = 1; очікується ~2.718281828459045 (~ означає приблизно). value зберігає результат, CStr
    # лише форматує його для Print.

    VAR inputValue = 1
    VAR value = Exp(inputValue)
    UO.Print(CStr(value))
END SUB
```

**Пояснення параметрів і виконання:**

- power = 1; очікується ~2.718281828459045 (~ означає приблизно). value зберігає результат, CStr лише форматує його для Print.

### Повна допоміжна функція

```vb
# Повна допоміжна функція
#
# Підносить e до степеня.
#
# Decimal — e^power. Exp(0)=1. Великий додатний степінь дає Infinity, дуже від’ємний — 0 через
# втрату розрядності. NaN зберігається. Число, не ID чи ознака успіху; 1/0 тут не означають
# виконано/не виконано.

# manual-check: scalar-math Exp
SUB Main()
    # value — початок, rate — неперервний темп за одиницю часу, period — кількість одиниць.
    # Growth(100,0.05,2)≈110.517; числовий приклад.

    VAR value = Growth(100,0.05,2)
    UO.Print(CStr(value))
END SUB

SUB Growth(value,rate,period)
    RETURN value*Exp(rate*period)
END SUB
```

**Пояснення параметрів і виконання:**

- value — початок, rate — неперервний темп за одиницю часу, period — кількість одиниць. Growth(100,0.05,2)≈110.517; числовий приклад.

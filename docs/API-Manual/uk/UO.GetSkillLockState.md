# UO.GetSkillLockState

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Читає локальний режим зміни навички.

## Точний синтаксис

```text
UO.GetSkillLockState(SkillName:Any) -> Integer
```

## Параметри

- `SkillName` — Обов’язкова навичка: ім’я з даних клієнта, як "Mining" або "Animal Lore", чи десятковий індекс 0..Skills.Length−1 числом або рядком. Регістр не важливий, крайні пробіли прибираються, _ замінюється пробілом. Це не ID предмета й не індекс від 1. Числовий рядок завжди означає індекс.

## Повертає

Integer: 0 — підвищення, 1 — зниження, 2 — блокування. Код режиму, не true/false. Для невідомої навички чи відсутнього персонажа повертається −1.

## Поведінка

- Invoke читає наявні дані на ігровому потоці без мережевих пакетів. Навичка не використовується й не тренується. Два запити — окремі знімки.
- Обов’язкова навичка: ім’я з даних клієнта, як "Mining" або "Animal Lore", чи десятковий індекс 0..Skills.Length−1 числом або рядком. Регістр не важливий, крайні пробіли прибираються, _ замінюється пробілом. Це не ID предмета й не індекс від 1. Числовий рядок завжди означає індекс.

## Приклади

### Прочитати й показати

```vb
# Прочитати й показати
#
# Читає локальний режим зміни навички.
#
# Integer: 0 — підвищення, 1 — зниження, 2 — блокування. Код режиму, не true/false. Для
# невідомої навички чи відсутнього персонажа повертається −1.

SUB Main()
    # Приклад явно задає selector і, для запису, mode. Перший рядок обирає навичку за ім’ям чи
    # характеристику за номером. Print лише показує результат.

    VAR selector = 'Mining'
    VAR mode = UO.GetSkillLockState(selector)
    UO.Print(CStr(mode))
END SUB
```

**Пояснення параметрів і виконання:**

- Приклад явно задає selector і, для запису, mode. Перший рядок обирає навичку за ім’ям чи характеристику за номером. Print лише показує результат.

### Застосувати в умові або порівнянні

```vb
# Застосувати в умові або порівнянні
#
# Читає локальний режим зміни навички.
#
# Integer: 0 — підвищення, 1 — зниження, 2 — блокування. Код режиму, не true/false. Для
# невідомої навички чи відсутнього персонажа повертається −1.

SUB Main()
    # Поріг 95.1 і режими 0/1/2 — налаштування прикладу. −1 перевіряється до зміни режиму. Читання
    # після запису показує локальну копію без очікування сервера.

    VAR mode = UO.GetSkillLockState('Mining')
    IF mode = 2 THEN
        UO.Print("Locked")
    ELSE
        IF mode = -1 THEN
            UO.Print("Unknown selector")
        ELSE
            UO.Print("Mode: " + CStr(mode))
        END IF
    END IF
END SUB
```

**Пояснення параметрів і виконання:**

- Поріг 95.1 і режими 0/1/2 — налаштування прикладу. −1 перевіряється до зміни режиму. Читання після запису показує локальну копію без очікування сервера.

### Повна допоміжна функція

```vb
# Повна допоміжна функція
#
# Читає локальний режим зміни навички.
#
# Integer: 0 — підвищення, 1 — зниження, 2 — блокування. Код режиму, не true/false. Для
# невідомої навички чи відсутнього персонажа повертається −1.

SUB Main()
    # Повний помічник наведений після Main. selector обирає навичку/характеристику, mode — режим
    # запису. ReadValue/ReadMode повертають вихідне число; ApplyMode перевіряє аргументи, виконує
    # дію та не повертає значення. WAIT(1000) розділяє два знімки читання.

    VAR before = ReadMode('Mining')
    WAIT(1000)
    VAR after = ReadMode('Mining')
    UO.Print(CStr(before) + " -> " + CStr(after))
END SUB

SUB ReadMode(selector)
    RETURN UO.GetSkillLockState(selector)
END SUB
```

**Пояснення параметрів і виконання:**

- Повний помічник наведений після Main. selector обирає навичку/характеристику, mode — режим запису. ReadValue/ReadMode повертають вихідне число; ApplyMode перевіряє аргументи, виконує дію та не повертає значення. WAIT(1000) розділяє два знімки читання.

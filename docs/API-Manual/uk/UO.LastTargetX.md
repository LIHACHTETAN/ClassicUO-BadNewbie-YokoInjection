# UO.LastTargetX

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Читає координату X, збережену під час вибору останньої цілі.

## Точний синтаксис

```text
UO.LastTargetX() -> Integer
```

## Параметри

Параметрів немає.

## Повертає

Integer — збережена координата X, не піксель екрана. До вибору/після Clear чи для невідомого об’єкта — 0; справжня координата 0 теж допустима. Не Boolean. Земля/статика працюють і при LastTarget()=0.

## Поведінка

- Без параметрів. Не відкриває прицілу, не обирає ціль, не атакує й не надсилає пакетів. LastTarget відрізняється від LastAttack та LastStatus. Звичайний вибір self не замінює останню ціль; явний ClientMarkChar може змінити її.
- SetEntity зберігає відомі Entity.X/Y; предмет у контейнері може мати координати вмісту. SetLand/SetStatic зберігають світові X/Y точки. Подальший рух/видалення не змінює знімка. Поточну позицію читають GetX/GetY(serial).
- Clear та World.Clear скидають запис, навіть зі збереженням скриптів. Явно встановлений невідомий serial не успадковує попередні X/Y: вони стають 0. Це не гарантує існування цілі на сервері.
- Окремі читання serial та X/Y не атомарні. Для об’єкта LastTile зберігає мережеві X/Y=65535, не позицію об’єкта. Для землі/статики LastTile(1)/(2) читають X/Y точки. lasttarget без дужок — жива вбудована змінна, якщо її не перекрито.
- World.Clear викликає ClearWorldState: скидає активний приціл/callback, збережену ціль і пакет повтору. Звичайний Reset зберігає історію. Внутрішній TargetLast надсилає збережений пакет лише для активного серверного прицілу; без історії чи для локального callback нічого не надсилає й залишає приціл. Активний клієнтський callback один раз отримує null як скасування: ClientTargetResponsePresent стає 1 із порожньою відповіддю. Завершений вибір повторно не сповіщається.

```vb
# Прочитати збережене значення
#
# Читає координату X, збережену під час вибору останньої цілі.
#
# Integer — збережена координата X, не піксель екрана. До вибору/після Clear чи для невідомого
# об’єкта — 0; справжня координата 0 теж допустима. Не Boolean. Земля/статика працюють і при
# LastTarget()=0.

SUB Main()
    # value містить один результат; HEX показує ID, CStr — координату. Виклик нічого не обирає.

    VAR value = UO.LastTargetX()
    UO.Print('Saved value: ' + CStr(value))
END SUB
```

**Пояснення параметрів і виконання:**

- value містить один результат; HEX показує ID, CStr — координату. Виклик нічого не обирає.

### Порівняти збережену й поточну позиції

```vb
# Порівняти збережену й поточну позиції
#
# Читає координату X, збережену під час вибору останньої цілі.
#
# Integer — збережена координата X, не піксель екрана. До вибору/після Clear чи для невідомого
# об’єкта — 0; справжня координата 0 теж допустима. Не Boolean. Земля/статика працюють і при
# LastTarget()=0.

SUB Main()
    # id — збережений serial. Exists перевіряє об’єкт перед GetX/GetY. Збережена й поточна позиції
    # можуть відрізнятися. При serial=0 показується точка, але 0 не доводить попереднього вибору
    # точки.

    VAR id = UO.LastTarget()
    VAR x = UO.LastTargetX()
    VAR y = UO.LastTargetY()
    UO.Print('Saved XY: ' + CStr(x) + ',' + CStr(y))
    IF id <> 0 AND UO.Exists(id) THEN
        UO.Print('Live XY: ' + CStr(UO.GetX(id)) + ',' + CStr(UO.GetY(id)))
    END IF
END SUB
```

**Пояснення параметрів і виконання:**

- id — збережений serial. Exists перевіряє об’єкт перед GetX/GetY. Збережена й поточна позиції можуть відрізнятися. При serial=0 показується точка, але 0 не доводить попереднього вибору точки.

### Повний помічник ReadTargetValue

```vb
# Повний помічник ReadTargetValue
#
# Читає координату X, збережену під час вибору останньої цілі.
#
# Integer — збережена координата X, не піксель екрана. До вибору/після Clear чи для невідомого
# об’єкта — 0; справжня координата 0 теж допустима. Не Boolean. Земля/статика працюють і при
# LastTarget()=0.

SUB Main()
    # minimum/maximum задають діапазон для помічника, не параметри API. Повний помічник повертає
    # власний -1 поза діапазоном. Для ID інша перевірка зберігає кожний ненульовий serial, включно
    # зі старшим бітом.

    VAR value = ReadTargetValue(0,65535)
    UO.Print('Checked value: ' + CStr(value))
END SUB

SUB ReadTargetValue(minimum,maximum)
    VAR value = UO.LastTargetX()
    IF value < minimum OR value > maximum THEN
        RETURN -1
    END IF
    RETURN value
END SUB
```

**Пояснення параметрів і виконання:**

- minimum/maximum задають діапазон для помічника, не параметри API. Повний помічник повертає власний -1 поза діапазоном. Для ID інша перевірка зберігає кожний ненульовий serial, включно зі старшим бітом.

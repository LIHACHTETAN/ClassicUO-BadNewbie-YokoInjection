# Log

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Обчислює натуральний логарифм.

## Точний синтаксис

```text
Log(number:Any) -> Decimal
```

## Параметри

- `number` — Обов’язковий Integer/Decimal або десятковий текст із крапкою й необов’язковою експонентою, наприклад "-1.25e2". Мова інтерфейсу не впливає. Нерозпізнаний текст (зокрема hex-рядок), Unit, Array та Object дають 0; числовий hex-літерал вже Integer. Можливі NaN/Infinity. Основа e, не 10. Log(1)=0, Log(0)=-Infinity, від’ємний вхід дає NaN, додатна нескінченність — Infinity.

## Повертає

Decimal — ln(number). Основа e, не 10. Log(1)=0, Log(0)=-Infinity, від’ємний вхід дає NaN, додатна нескінченність — Infinity. Число, не ID чи ознака успіху; 1/0 тут не означають виконано/не виконано.

## Поведінка

- Локальне обчислення в потоці скрипту без запиту серверу, руху, прицілу, очікування чи зміни глобальних змінних.
- Decimal — двійковий Double, не .NET decimal. Результати можуть бути наближеними; порівнюйте скінченні дробові значення з допуском. NaN/Infinity не підходять для координат або кількості предметів.
- Основа e, не 10. Log(1)=0, Log(0)=-Infinity, від’ємний вхід дає NaN, додатна нескінченність — Infinity.

### Внутрішні функції: від виклику до результату

Це реальні етапи реєстрації та перетворення. Повні помічники демонструють формули скрипту, не замінюючи математику платформи.

#### 1. Register

Register прив’язує ім’я BASIC з одним аргументом до нативного обчислення. Після перетворення викликає System.Math, не прихований скрипт чи процедуру сервера.

Decimal — ln(number). Основа e, не 10. Log(1)=0, Log(0)=-Infinity, від’ємний вхід дає NaN, додатна нескінченність — Infinity. Число, не ID чи ознака успіху; 1/0 тут не означають виконано/не виконано.

Код проєкту: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApi.cs`; функція `Register`.

#### 2. BasicDouble

BasicDouble зберігає Integer/Decimal, читає текст з інваріантним NumberStyles.Float і дає 0 для непідтримуваного значення. Abs обробляє звичайний Integer прямо перед переходом до Double.

Обов’язковий Integer/Decimal або десятковий текст із крапкою й необов’язковою експонентою, наприклад "-1.25e2". Мова інтерфейсу не впливає. Нерозпізнаний текст (зокрема hex-рядок), Unit, Array та Object дають 0; числовий hex-літерал вже Integer. Можливі NaN/Infinity.

Код проєкту: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApi.cs`; функція `BasicDouble`.

Локальне обчислення в потоці скрипту без запиту серверу, руху, прицілу, очікування чи зміни глобальних змінних.


## Приклади

### Пряме обчислення

```vb
# Пряме обчислення
#
# Обчислює натуральний логарифм.
#
# Decimal — ln(number). Основа e, не 10. Log(1)=0, Log(0)=-Infinity, від’ємний вхід дає NaN,
# додатна нескінченність — Infinity. Число, не ID чи ознака успіху; 1/0 тут не означають
# виконано/не виконано.

SUB Main()
    # number = 1; очікується 0 (~ означає приблизно). value зберігає результат, CStr лише форматує
    # його для Print.

    VAR value = Log(1)
    UO.Print(CStr(value))
END SUB
```

**Пояснення параметрів і виконання:**

- number = 1; очікується 0 (~ означає приблизно). value зберігає результат, CStr лише форматує його для Print.

### Інший аргумент через змінну

```vb
# Інший аргумент через змінну
#
# Обчислює натуральний логарифм.
#
# Decimal — ln(number). Основа e, не 10. Log(1)=0, Log(0)=-Infinity, від’ємний вхід дає NaN,
# додатна нескінченність — Infinity. Число, не ID чи ознака успіху; 1/0 тут не означають
# виконано/не виконано.

SUB Main()
    # number = 2.718281828459045; очікується ~1 (~ означає приблизно). value зберігає результат,
    # CStr лише форматує його для Print.

    VAR inputValue = 2.718281828459045
    VAR value = Log(inputValue)
    UO.Print(CStr(value))
END SUB
```

**Пояснення параметрів і виконання:**

- number = 2.718281828459045; очікується ~1 (~ означає приблизно). value зберігає результат, CStr лише форматує його для Print.

### Повна допоміжна функція

```vb
# Повна допоміжна функція
#
# Обчислює натуральний логарифм.
#
# Decimal — ln(number). Основа e, не 10. Log(1)=0, Log(0)=-Infinity, від’ємний вхід дає NaN,
# додатна нескінченність — Infinity. Число, не ID чи ознака успіху; 1/0 тут не означають
# виконано/не виконано.

# manual-check: scalar-math Log
SUB Main()
    # value>0, baseValue>0 та baseValue<>1. LogBase дає Log(value)/Log(baseValue);
    # LogBase(100,10)≈2. Недопустимий вхід дає запасний 0, можливий і для правильного логарифма.

    VAR value = LogBase(100,10)
    UO.Print(CStr(value))
END SUB

SUB LogBase(value,baseValue)
    IF value <= 0 OR baseValue <= 0 OR baseValue = 1 THEN
        RETURN 0
    END IF
    RETURN Log(value)/Log(baseValue)
END SUB
```

**Пояснення параметрів і виконання:**

- value>0, baseValue>0 та baseValue<>1. LogBase дає Log(value)/Log(baseValue); LogBase(100,10)≈2. Недопустимий вхід дає запасний 0, можливий і для правильного логарифма.

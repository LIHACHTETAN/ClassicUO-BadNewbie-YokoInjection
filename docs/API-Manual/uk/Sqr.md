# Sqr

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Обчислює квадратний корінь.

## Точний синтаксис

```text
Sqr(number:Any) -> Decimal
```

## Параметри

- `number` — Обов’язковий Integer/Decimal або десятковий текст із крапкою й необов’язковою експонентою, наприклад "-1.25e2". Мова інтерфейсу не впливає. Нерозпізнаний текст (зокрема hex-рядок), Unit, Array та Object дають 0; числовий hex-літерал вже Integer. Можливі NaN/Infinity. Для входу >=0 дає невід’ємний корінь. Від’ємне дає NaN, додатна нескінченність — Infinity, NaN зберігається.

## Повертає

Decimal — sqrt(number). Для входу >=0 дає невід’ємний корінь. Від’ємне дає NaN, додатна нескінченність — Infinity, NaN зберігається. Число, не ID чи ознака успіху; 1/0 тут не означають виконано/не виконано.

## Поведінка

- Локальне обчислення в потоці скрипту без запиту серверу, руху, прицілу, очікування чи зміни глобальних змінних.
- Decimal — двійковий Double, не .NET decimal. Результати можуть бути наближеними; порівнюйте скінченні дробові значення з допуском. NaN/Infinity не підходять для координат або кількості предметів.
- Для входу >=0 дає невід’ємний корінь. Від’ємне дає NaN, додатна нескінченність — Infinity, NaN зберігається.

### Внутрішні функції: від виклику до результату

Це реальні етапи реєстрації та перетворення. Повні помічники демонструють формули скрипту, не замінюючи математику платформи.

#### 1. Register

Register прив’язує ім’я BASIC з одним аргументом до нативного обчислення. Після перетворення викликає System.Math, не прихований скрипт чи процедуру сервера.

Decimal — sqrt(number). Для входу >=0 дає невід’ємний корінь. Від’ємне дає NaN, додатна нескінченність — Infinity, NaN зберігається. Число, не ID чи ознака успіху; 1/0 тут не означають виконано/не виконано.

Код проєкту: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApi.cs`; функція `Register`.

#### 2. BasicDouble

BasicDouble зберігає Integer/Decimal, читає текст з інваріантним NumberStyles.Float і дає 0 для непідтримуваного значення. Abs обробляє звичайний Integer прямо перед переходом до Double.

Обов’язковий Integer/Decimal або десятковий текст із крапкою й необов’язковою експонентою, наприклад "-1.25e2". Мова інтерфейсу не впливає. Нерозпізнаний текст (зокрема hex-рядок), Unit, Array та Object дають 0; числовий hex-літерал вже Integer. Можливі NaN/Infinity.

Код проєкту: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApi.cs`; функція `BasicDouble`.

## Приклади

### Пряме обчислення

```vb
# Пряме обчислення
#
# Обчислює квадратний корінь.
#
# Decimal — sqrt(number). Для входу >=0 дає невід’ємний корінь. Від’ємне дає NaN, додатна
# нескінченність — Infinity, NaN зберігається. Число, не ID чи ознака успіху; 1/0 тут не
# означають виконано/не виконано.

SUB Main()
    # number = 25; очікується 5 (~ означає приблизно). value зберігає результат, CStr лише форматує
    # його для Print.

    VAR value = Sqr(25)
    UO.Print(CStr(value))
END SUB
```

**Пояснення параметрів і виконання:**

- number = 25; очікується 5 (~ означає приблизно). value зберігає результат, CStr лише форматує його для Print.

### Інший аргумент через змінну

```vb
# Інший аргумент через змінну
#
# Обчислює квадратний корінь.
#
# Decimal — sqrt(number). Для входу >=0 дає невід’ємний корінь. Від’ємне дає NaN, додатна
# нескінченність — Infinity, NaN зберігається. Число, не ID чи ознака успіху; 1/0 тут не

SUB Main()
    # number = 2; очікується ~1.4142135623730951 (~ означає приблизно). value зберігає результат,

    VAR inputValue = 2
    VAR value = Sqr(inputValue)
    UO.Print(CStr(value))
END SUB
```

**Пояснення параметрів і виконання:**

- number = 2; очікується ~1.4142135623730951 (~ означає приблизно). value зберігає результат, CStr лише форматує його для Print.

### Повна допоміжна функція

```vb
# Повна допоміжна функція
#
# Обчислює квадратний корінь.
#
# Decimal — sqrt(number). Для входу >=0 дає невід’ємний корінь. Від’ємне дає NaN, додатна
# нескінченність — Infinity, NaN зберігається. Число, не ID чи ознака успіху; 1/0 тут не
# означають виконано/не виконано.

# manual-check: scalar-math Sqr
SUB Main()
    # dx/dy — різниці координат. CDbl запобігає цілочисленному переповненню до sqrt(dx²+dy²);
    # SegmentLength(3,4)=5. Евклідова довжина, не маршрут чи перевірка колізій.

    VAR value = SegmentLength(3,4)
    UO.Print(CStr(value))
END SUB

SUB SegmentLength(dx,dy)
    VAR x = CDbl(dx)
    VAR y = CDbl(dy)
    RETURN Sqr(x*x+y*y)
END SUB
```

**Пояснення параметрів і виконання:**

- dx/dy — різниці координат. CDbl запобігає цілочисленному переповненню до sqrt(dx²+dy²); SegmentLength(3,4)=5. Евклідова довжина, не маршрут чи перевірка колізій.

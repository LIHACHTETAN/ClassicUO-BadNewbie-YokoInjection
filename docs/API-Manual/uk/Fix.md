# Fix

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Відкидає дробову частину до нуля.

## Точний синтаксис

```text
Fix(value:Any) -> Integer
```

## Параметри

- `value` — Обов’язковий Integer/Decimal або десятковий текст із крапкою й необов’язковою експонентою, наприклад "-1.25e2". Мова інтерфейсу не впливає. Нерозпізнаний текст (зокрема hex-рядок), Unit, Array та Object дають 0; числовий hex-літерал вже Integer. Можливі NaN/Infinity. Лише скінченний вхід з результатом -2147483648..2147483647. -2.9 дає -2, а floor(-2.9)=-3. Вихід за діапазон та NaN/Infinity не підходять для перетворення.

## Повертає

Integer — truncate(value). Лише скінченний вхід з результатом -2147483648..2147483647. -2.9 дає -2, а floor(-2.9)=-3. Вихід за діапазон та NaN/Infinity не підходять для перетворення. Число, не ID чи ознака успіху; 1/0 тут не означають виконано/не виконано.

## Поведінка

- Локальне обчислення в потоці скрипту без запиту серверу, руху, прицілу, очікування чи зміни глобальних змінних.
- Decimal — двійковий Double, не .NET decimal. Результати можуть бути наближеними; порівнюйте скінченні дробові значення з допуском. NaN/Infinity не підходять для координат або кількості предметів.
- Лише скінченний вхід з результатом -2147483648..2147483647. -2.9 дає -2, а floor(-2.9)=-3. Вихід за діапазон та NaN/Infinity не підходять для перетворення.

### Внутрішні функції: від виклику до результату

Це реальні етапи реєстрації та перетворення. Повні помічники демонструють формули скрипту, не замінюючи математику платформи.

#### 1. Register

Register прив’язує ім’я BASIC з одним аргументом до нативного обчислення. Після перетворення викликає System.Math, не прихований скрипт чи процедуру сервера.

Integer — truncate(value). Лише скінченний вхід з результатом -2147483648..2147483647. -2.9 дає -2, а floor(-2.9)=-3. Вихід за діапазон та NaN/Infinity не підходять для перетворення. Число, не ID чи ознака успіху; 1/0 тут не означають виконано/не виконано.

Код проєкту: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApi.cs`; функція `Register`.

#### 2. BasicDouble

BasicDouble зберігає Integer/Decimal, читає текст з інваріантним NumberStyles.Float і дає 0 для непідтримуваного значення. Abs обробляє звичайний Integer прямо перед переходом до Double.

Обов’язковий Integer/Decimal або десятковий текст із крапкою й необов’язковою експонентою, наприклад "-1.25e2". Мова інтерфейсу не впливає. Нерозпізнаний текст (зокрема hex-рядок), Unit, Array та Object дають 0; числовий hex-літерал вже Integer. Можливі NaN/Infinity.

Код проєкту: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApi.cs`; функція `BasicDouble`.

Локальне обчислення в потоці скрипту без запиту серверу, руху, прицілу, очікування чи зміни глобальних змінних.


## Приклади

### Пряме обчислення

```vb
# Пряме обчислення
#
# Відкидає дробову частину до нуля.
#
# Integer — truncate(value). Лише скінченний вхід з результатом -2147483648..2147483647. -2.9
# дає -2, а floor(-2.9)=-3. Вихід за діапазон та NaN/Infinity не підходять для перетворення.
# Число, не ID чи ознака успіху; 1/0 тут не означають виконано/не виконано.

SUB Main()
    # value = 2.9; очікується 2 (~ означає приблизно). value зберігає результат, CStr лише форматує
    # його для Print.

    VAR value = Fix(2.9)
    UO.Print(CStr(value))
END SUB
```

**Пояснення параметрів і виконання:**

- value = 2.9; очікується 2 (~ означає приблизно). value зберігає результат, CStr лише форматує його для Print.

### Повна допоміжна функція

```vb
# Повна допоміжна функція
#
# Відкидає дробову частину до нуля.
#
# Integer — truncate(value). Лише скінченний вхід з результатом -2147483648..2147483647. -2.9
# дає -2, а floor(-2.9)=-3. Вихід за діапазон та NaN/Infinity не підходять для перетворення.
# Число, не ID чи ознака успіху; 1/0 тут не означають виконано/не виконано.

# manual-check: scalar-math Fix
SUB Main()
    # total>=0 та size>0 задають повні партії: 27/5 дає 5. Недопустимий вхід дає запасний 0,
    # можливий і без повної партії. Частка має вміщатися в Integer.

    VAR value = WholeBatches(27,5)
    UO.Print(CStr(value))
END SUB

SUB WholeBatches(total,size)
    IF total < 0 OR size <= 0 THEN
        RETURN 0
    END IF
    RETURN Fix(CDbl(total)/CDbl(size))
END SUB
```

**Пояснення параметрів і виконання:**

- total>=0 та size>0 задають повні партії: 27/5 дає 5. Недопустимий вхід дає запасний 0, можливий і без повної партії. Частка має вміщатися в Integer.

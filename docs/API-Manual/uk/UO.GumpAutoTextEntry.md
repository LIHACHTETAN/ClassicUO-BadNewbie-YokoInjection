# UO.GumpAutoTextEntry

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: uk -->

Одноразово задає значення елемента в першому відповідному серверному гампі; якщо елемента ще немає, зберігає очікування.

## Точний синтаксис

```text
UO.GumpAutoTextEntry(TextEntryID:Any, Value:Any) -> Unit
```

## Параметри

- `TextEntryID` — Integer — точний ID елемента відповідного типу. Це не індекс, GumpID або serial вікна. 0 — звичайний ID, без підстановки першого елемента.
- `Value` — String — текст поля; порожній рядок очищає його. Обмеження довжини та символів самого поля зберігаються.

## Повертає

Unit — нічого не повертає: ані успіх, ані нове значення, ані підтвердження сервера.

## Поведінка

- Спочатку перевіряє відкриті вікна в поточному порядку інтерфейсу, потім нові або оновлені серверні розмітки. Виконується один раз за першим збігом типу та ID. Для конкретного вікна використовуйте NumGump* з індексом.
- Очікувані поля заповнюються до автоматичної відповіді кнопкою. Повтор того самого типу та ID в одному скрипті замінює ще не виконане значення. Ліміт клієнта — 1024 очікувані поля; перевищення спричиняє помилку скрипту.
- Звичайне завершення процедури зберігає очікування. Скасування власника або Terminate з його іменем видаляє його дії; TerminateAll видаляє всі, включно з діями завершених процедур. Зміна світу очищає чергу. Дії не записуються в профіль.
- Поле може скоротити або відхилити текст через власні обмеження; знайдений елемент усе одно витрачає одноразову дію. Команда не відповідає кнопкою та не чекає сервера. Перевіряйте текст через GetGumpInfo/NumGumpTextEntry.

## Приклади

### Заповнити відкритий елемент

```vb
# Заповнити відкритий елемент
#
# Одноразово задає значення елемента в першому відповідному серверному гампі; якщо елемента ще
# немає, зберігає очікування.
#
# Unit — нічого не повертає: ані успіх, ані нове значення, ані підтвердження сервера.

SUB Main()
    # 33 — приклад ID елемента; замініть його справжнім ID з InfoGump. Другий аргумент — нове
    # значення. Якщо елемента немає, дія очікує.

    UO.GumpAutoTextEntry(33, '500')
END SUB
```

**Пояснення параметрів і виконання:**

- 33 — приклад ID елемента; замініть його справжнім ID з InfoGump. Другий аргумент — нове значення. Якщо елемента немає, дія очікує.

### Заповнити до відкриття

```vb
# Заповнити до відкриття
#
# Одноразово задає значення елемента в першому відповідному серверному гампі; якщо елемента ще
# немає, зберігає очікування.
#
# Unit — нічого не повертає: ані успіх, ані нове значення, ані підтвердження сервера.

SUB Main()
    # 33 — ID елемента, 100 — приклад ButtonID підтвердження, 0x40001234 — serial об’єкта, що
    # відкриває форму. Замініть усі три. Поле заповниться перед відповіддю, навіть якщо вікно
    # надійде пізніше.

    UO.GumpAutoTextEntry(33, '500')
    UO.WaitGump(100)
    UO.UseObject('0x40001234')
END SUB
```

**Пояснення параметрів і виконання:**

- 33 — ID елемента, 100 — приклад ButtonID підтвердження, 0x40001234 — serial об’єкта, що відкриває форму. Замініть усі три. Поле заповниться перед відповіддю, навіть якщо вікно надійде пізніше.

### Замінити очікуване значення

```vb
# Замінити очікуване значення
#
# Одноразово задає значення елемента в першому відповідному серверному гампі; якщо елемента ще
# немає, зберігає очікування.
#
# Unit — нічого не повертає: ані успіх, ані нове значення, ані підтвердження сервера.

SUB Main()
    # Обидва виклики використовують ID 33. Якщо елемент ще не з’явився, діє останнє значення. Якщо
    # вікно відкрите, обидві зміни виконуються негайно в порядку викликів.

    UO.GumpAutoTextEntry(33, '500')
    UO.GumpAutoTextEntry(33, '')
END SUB
```

**Пояснення параметрів і виконання:**

- Обидва виклики використовують ID 33. Якщо елемент ще не з’явився, діє останнє значення. Якщо вікно відкрите, обидві зміни виконуються негайно в порядку викликів.

# Space

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->

Создаёт строку из обычных пробелов.

## Точный синтаксис

```text
Space(count:Integer) -> String
```

Выберите одну из зарегистрированных форм. Параметры передаются позиционно. Any означает значение BASIC с преобразованием внутри команды; Unit — отсутствие возвращаемого значения.

## Параметры

- `count` — Число пробелов U+0020. <=0 даёт пустую строку. Большие значения требуют соответствующего объёма памяти.

## Возвращает

String из count пробелов, либо пустая строка при count<=0. Это не пауза выполнения.

## Поведение

- Выполняется локально и не обращается к игровому серверу. Исходная строка не изменяется: результат нужно сохранить или передать дальше.
- Позиции и длины строк считаются в единицах UTF-16. Символ за пределами BMP, например emoji, занимает две единицы. Это не количество байтов UTF-8.

## Примеры

### Пример 1. Разделить подписи

```vb
# Разделить подписи
#
# Создаёт строку из обычных пробелов.
#
# String из count пробелов, либо пустая строка при count<=0. Это не пауза выполнения.

SUB Main()
    # count=3 вставляет три пробела между A и B.
    # Ожидаемый результат: строка A   B. В result сохраняется результат выражения; Print только
    # показывает его.

    VAR result = 'A' + Space(3) + 'B'
    UO.Print(CStr(result))
END SUB
```

**Разбор параметров и выполнения:**

- count=3 вставляет три пробела между A и B.
- Ожидаемый результат: строка A   B. В result сохраняется результат выражения; Print только показывает его.

### Пример 2. Проверить длину

```vb
# Проверить длину
#
# Создаёт строку из обычных пробелов.
#
# String из count пробелов, либо пустая строка при count<=0. Это не пауза выполнения.

SUB Main()
    # Пять пробелов занимают пять единиц UTF-16.
    # Ожидаемый результат: 5. В result сохраняется результат выражения; Print только показывает его.

    VAR result = Len(Space(5))
    UO.Print(CStr(result))
END SUB
```

**Разбор параметров и выполнения:**

- Пять пробелов занимают пять единиц UTF-16.
- Ожидаемый результат: 5. В result сохраняется результат выражения; Print только показывает его.

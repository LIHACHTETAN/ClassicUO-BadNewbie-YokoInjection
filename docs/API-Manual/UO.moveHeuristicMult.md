# UO.moveHeuristicMult

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->

Множитель эвристики Pathfinder в процентах.

## Точный синтаксис

```text
UO.moveHeuristicMult() -> Any
UO.moveHeuristicMult(value:Any) -> Any
```

Выберите одну из зарегистрированных форм. Параметры передаются позиционно. Any означает значение BASIC с преобразованием внутри команды; Unit — отсутствие возвращаемого значения.

## Параметры

- `value` — Необязательное новое значение. Целое >=0 сохраняется; перед поиском минимум 1. Значение 100 соответствует обычной оценке; >100 может предпочесть более быстрый поиск без гарантии минимальной стоимости. При Optimized=FALSE используется 1.

## Возвращает

Integer — текущее сохранённое значение. Без аргумента только читает; с аргументом возвращает значение после применения правил выше. Это настройка, не результат движения.

## Поведение

- Настройка хранится в состоянии runtime и используется соответствующими командами при запуске; изменение не переписывает уже построенный путь автоматически.
- Возврат исходного значения показан для обычного завершения. После аварийной остановки следующие строки восстановления не выполняются.

## Примеры

### Пример 1. Прочитать настройку

```vb
# Прочитать настройку
#
# Множитель эвристики Pathfinder в процентах.
#
# Integer — текущее сохранённое значение. Без аргумента только читает; с аргументом возвращает
# значение после применения правил выше. Это настройка, не результат движения.

SUB Main()
    # Аргументов нет, состояние не меняется.
    # value — числовое значение этой настройки.

    VAR value = UO.moveHeuristicMult()
    UO.Print(STR(value))
END SUB
```

**Разбор параметров и выполнения:**

- Аргументов нет, состояние не меняется.
- value — числовое значение этой настройки.

#
# Множитель эвристики Pathfinder в процентах.

# Integer — текущее сохранённое значение. Без аргумента только читает; с аргументом возвращает

### Пример 3. Применить на один участок скрипта

```vb
# Применить на один участок скрипта
#
# Множитель эвристики Pathfinder в процентах.
#
# Integer — текущее сохранённое значение. Без аргумента только читает; с аргументом возвращает
# значение после применения правил выше. Это настройка, не результат движения.

SUB Main()
    # previous хранит исходную настройку; NewMoveXY ограничен 3000 мс.
    # Последняя команда восстанавливает настройку после обычного возврата движения.

    VAR previous = UO.moveHeuristicMult()
    UO.moveHeuristicMult(100)
    VAR ok = UO.NewMoveXY(UO.GetX() + 2, UO.GetY(), TRUE, 0, FALSE, 0, 3000)
    UO.moveHeuristicMult(previous)
    UO.Print(STR(ok))
END SUB
```

**Разбор параметров и выполнения:**

- previous хранит исходную настройку; NewMoveXY ограничен 3000 мс.
- Последняя команда восстанавливает настройку после обычного возврата движения.

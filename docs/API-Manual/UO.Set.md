# UO.Set

ClassicUO • Runtime API • `UO.Set.md`

В этой реализации изменяет только три именованные настройки: finddistance (расстояние поиска), grabdelay (задержка переноса в мс), equipfordress (режим экипировки при Dress). Имена сравниваются без учёта регистра. Числовая и строковая перегрузки используют один путь; строка поддерживает 0x/0X, неверное число превращается в 0. Неизвестное имя не меняет настройки и не вызывает ошибку. Это не универсальный setter всех 310 runtime-значений.

## Точный синтаксис / Registered signatures

```text
UO.Set(name:String, value:Integer) -> Unit
UO.Set(name:String, valueStr:String) -> Unit
```

Порядок аргументов соответствует строкам выше. `Unit` означает отсутствие возвращаемого значения. `Any` — значение BASIC с преобразованием при вызове. Имена нечувствительны к регистру.

## Параметры

- `name` — finddistance, grabdelay или equipfordress. Другие имена этой командой не обрабатываются.
- `value` — Числовое значение соответствующей настройки.
- `valueStr` — Строковое число: десятичное или 0x/0X. Неверная строка превращается в 0.

## Варианты использования

Это отдельные сценарии. Подставьте свои serial, пути и координаты; серверные действия зависят от текущего состояния игры.

### Числовая задержка в миллисекундах

```vb
SUB Main()
    UO.Set('grabdelay', 250)
END SUB
```

### То же значение через hex-строку

```vb
SUB Main()
    UO.Set('grabdelay', '0XFA')
END SUB
```

### Изменить расстояние поиска

```vb
SUB Main()
    UO.Set('finddistance', 10)
END SUB
```

### Условный вызов из игрового скрипта

```vb
SUB Main()
    IF UO.Connected THEN
        VAR arg1 = 'example' # name
        VAR arg2 = 'example' # valueStr
        UO.Set(arg1, arg2)
    END IF
END SUB
```

### Повторное использование через процедуру

```vb
SUB RunAction()
    VAR arg1 = 'example' # name
    VAR arg2 = 'example' # valueStr
    UO.Set(arg1, arg2)
END SUB

SUB Main()
    # Запуск процедуры выполняет действие:
    RunAction()
END SUB
```

## Реализация для проверки поведения

## Возвращает

Unit — команда не возвращает значение. Вызывайте её отдельной строкой. Не используйте её результат как serial, type или логический признак успеха. Завершение вызова само по себе не подтверждает выполнение действия сервером.

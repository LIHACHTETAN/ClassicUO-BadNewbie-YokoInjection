# UO.CancelMove

ClassicUO • Runtime API • `UO.CancelMove.md`

Запрещает дальнейшее перемещение через менеджер скриптов. CancelMove вызывает тот же путь, что MoveOff. Для последующих команд перемещения разрешение можно восстановить MoveOn().

## Точный синтаксис / Registered signatures

```text
UO.CancelMove() -> Unit
```

Порядок аргументов соответствует строкам выше. `Unit` означает отсутствие возвращаемого значения. `Any` — значение BASIC с преобразованием при вызове. Имена нечувствительны к регистру.

## Варианты использования

Это отдельные сценарии. Подставьте свои serial, пути и координаты; серверные действия зависят от текущего состояния игры.

### Прямой вызов

```vb
SUB Main()
    UO.CancelMove()
END SUB
```

### Условный вызов из игрового скрипта

```vb
SUB Main()
    IF UO.Connected THEN
        UO.CancelMove()
    END IF
END SUB
```

### Повторное использование через процедуру

```vb
SUB RunAction()
    UO.CancelMove()
END SUB

SUB Main()
    # Запуск процедуры выполняет действие:
    RunAction()
END SUB
```

## Возвращает

Unit — команда не возвращает значение. Вызывайте её отдельной строкой. Не используйте её результат как serial, type или логический признак успеха. Завершение вызова само по себе не подтверждает выполнение действия сервером.

# UO.GumpAutoCheckBox

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->
<!-- yoko-locale: ja -->

最初に一致するサーバー Gump のコントロールへ一度だけ値を設定します。見つからない場合は待機中の操作を保存します。

## 正確な構文

```text
UO.GumpAutoCheckBox(CheckBoxID:Any, Value:Any) -> Unit
```

## パラメーター

- `CheckBoxID` — Integer — 対象の種類に属するコントロールの正確な ID。インデックス、GumpID、ウィンドウの serial ではありません。0 は通常の ID であり、先頭要素を代わりに選びません。
- `Value` — Integer — 1 で有効、0 で無効。他の 0 以外の数値も有効にしますが、0/1 を推奨します。ラジオボタンを選ぶと同じグループの他の選択が解除されます。

## 戻り値

Unit — 戻り値はありません。成功、新しい値、サーバーの確認のいずれも返しません。

## 動作

- 現在の UI 順で既存のウィンドウを調べ、続いて受信または再構築されたサーバーレイアウトを調べます。種類と ID が最初に一致した要素で一度だけ消費されます。特定のウィンドウにはインデックス付き NumGump* を使います。
- 待機中の入力値は自動ボタン応答より先に適用されます。同じスクリプトで種類と ID を再指定すると未実行の値を置き換えます。クライアント全体で待機中の入力操作は最大 1024 件。超過はスクリプトエラーです。
- プロシージャの正常終了後も待機操作は残ります。所有者の中止または名前付き Terminate はその操作を削除します。TerminateAll は終了済みプロシージャの分も含め全件削除します。ワールド変更でもキューを消去します。プロファイルには保存しません。

## 使用例

### 開いている要素に入力

```vb
# 開いている要素に入力
#
# 最初に一致するサーバー Gump のコントロールへ一度だけ値を設定します。見つからない場合は待機中の操作を保存します。
#
# Unit — 戻り値はありません。成功、新しい値、サーバーの確認のいずれも返しません。

SUB Main()
    # 33 は例のコントロール ID です。InfoGump の実際の ID に置き換えます。第 2 引数は設定値です。要素がなければ操作は待機します。

    UO.GumpAutoCheckBox(33, 1)
END SUB
```

**パラメーターと実行の説明:**

- 33 は例のコントロール ID です。InfoGump の実際の ID に置き換えます。第 2 引数は設定値です。要素がなければ操作は待機します。

### 開く前に入力を準備

```vb
# 開く前に入力を準備
#
# 最初に一致するサーバー Gump のコントロールへ一度だけ値を設定します。見つからない場合は待機中の操作を保存します。
#
# Unit — 戻り値はありません。成功、新しい値、サーバーの確認のいずれも返しません。

SUB Main()
    # 33 は要素の ID、100 は確認ボタンの ButtonID の例、0x40001234 はフォームを開くオブジェクトの serial
    # です。すべて実際の値に置き換えます。後からウィンドウが届いても応答前に入力します。

    UO.GumpAutoCheckBox(33, 1)
    UO.WaitGump(100)
    UO.UseObject('0x40001234')
END SUB
```

**パラメーターと実行の説明:**

- 33 は要素の ID、100 は確認ボタンの ButtonID の例、0x40001234 はフォームを開くオブジェクトの serial です。すべて実際の値に置き換えます。後からウィンドウが届いても応答前に入力します。

### 待機中の値を置換

```vb
# 待機中の値を置換
#
# 最初に一致するサーバー Gump のコントロールへ一度だけ値を設定します。見つからない場合は待機中の操作を保存します。
#
# Unit — 戻り値はありません。成功、新しい値、サーバーの確認のいずれも返しません。

SUB Main()
    # どちらも ID 33 を指定します。要素がまだ届いていなければ最後の値が残ります。開いていれば呼び出し順に両方の変更を直ちに適用します。

    UO.GumpAutoCheckBox(33, 1)
    UO.GumpAutoCheckBox(33, 0)
END SUB
```

**パラメーターと実行の説明:**

- どちらも ID 33 を指定します。要素がまだ届いていなければ最後の値が残ります。開いていれば呼び出し順に両方の変更を直ちに適用します。

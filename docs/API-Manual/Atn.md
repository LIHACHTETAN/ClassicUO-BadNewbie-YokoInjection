# Atn

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->

Вычисляет арктангенс.

## Точный синтаксис

```text
Atn(number:Any) -> Decimal
```

Выберите одну из зарегистрированных форм. Параметры передаются позиционно. Any означает значение BASIC с преобразованием внутри команды; Unit — отсутствие возвращаемого значения.

## Параметры

- `number` — Обязательное число Integer/Decimal либо десятичная строка с точкой и необязательной экспонентой, например "-1.25e2". Язык интерфейса не влияет. Нераспознанный текст (включая hex-строку), Unit, Array и Object дают 0; числовой hex-литерал уже является Integer. Возможны NaN/Infinity. Вход — наклон, выход — радианы в [-pi/2,pi/2]; бесконечности дают границы, NaN сохраняется. Это не atan2 с двумя координатами.

## Возвращает

Decimal — atan(number). Вход — наклон, выход — радианы в [-pi/2,pi/2]; бесконечности дают границы, NaN сохраняется. Это не atan2 с двумя координатами. Число, не ID и не признак успеха; 1/0 здесь нельзя трактовать как выполнено/не выполнено.

## Поведение

- Вычисляется локально в потоке скрипта: без запроса серверу, движения, прицела, ожидания и изменения глобальных переменных.
- Decimal хранится как двоичный Double, не .NET decimal. Результат может быть приближённым; сравнивайте конечные дробные значения с допуском. NaN/Infinity не используйте как координаты или количество предметов.
- Вход — наклон, выход — радианы в [-pi/2,pi/2]; бесконечности дают границы, NaN сохраняется. Это не atan2 с двумя координатами.

### Внутренние функции: от вызова до результата

Ниже реальные этапы регистрации и преобразования. Полные функции примеров показывают полезные формулы скрипта, не заменяя математическую реализацию платформы.

#### 1. Register

Register связывает имя BASIC с одним аргументом с нативным вычислением. После преобразования вызывается System.Math; скрытые скрипты и процедуры сервера не запускаются.

Decimal — atan(number). Вход — наклон, выход — радианы в [-pi/2,pi/2]; бесконечности дают границы, NaN сохраняется. Это не atan2 с двумя координатами. Число, не ID и не признак успеха; 1/0 здесь нельзя трактовать как выполнено/не выполнено.

Исходник проекта: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApi.cs`; функция `Register`.

#### 2. BasicDouble

BasicDouble сохраняет Integer/Decimal, читает строку через инвариантный NumberStyles.Float, для неподдерживаемого значения даёт 0. Abs обрабатывает обычный Integer напрямую до перехода к Double.

Обязательное число Integer/Decimal либо десятичная строка с точкой и необязательной экспонентой, например "-1.25e2". Язык интерфейса не влияет. Нераспознанный текст (включая hex-строку), Unit, Array и Object дают 0; числовой hex-литерал уже является Integer. Возможны NaN/Infinity.

Исходник проекта: `external/InjectionScript/src/InjectionScript/Runtime/InjectionApi.cs`; функция `BasicDouble`.

## Примеры

### Пример 1. Прямое вычисление

```vb
# Прямое вычисление
#
# Вычисляет арктангенс.
#
# Decimal — atan(number). Вход — наклон, выход — радианы в [-pi/2,pi/2]; бесконечности дают
# границы, NaN сохраняется. Это не atan2 с двумя координатами. Число, не ID и не признак успеха;
# 1/0 здесь нельзя трактовать как выполнено/не выполнено.

SUB Main()
    # number = 0; ожидается 0 (~ означает приближённо). value хранит результат, CStr лишь
    # форматирует его для Print.

    VAR value = Atn(0)
    UO.Print(CStr(value))
END SUB
```

**Разбор параметров и выполнения:**

- number = 0; ожидается 0 (~ означает приближённо). value хранит результат, CStr лишь форматирует его для Print.

### Пример 2. Другой аргумент через переменную

```vb

#
# Вычисляет арктангенс.
#
# Decimal — atan(number). Вход — наклон, выход — радианы в [-pi/2,pi/2]; бесконечности дают
# границы, NaN сохраняется. Это не atan2 с двумя координатами. Число, не ID и не признак успеха;
```

### Пример 3. Полная вспомогательная функция

```vb
# Полная вспомогательная функция
#
# Вычисляет арктангенс.
#
# Decimal — atan(number). Вход — наклон, выход — радианы в [-pi/2,pi/2]; бесконечности дают
# границы, NaN сохраняется. Это не atan2 с двумя координатами. Число, не ID и не признак успеха;
# 1/0 здесь нельзя трактовать как выполнено/не выполнено.

# manual-check: scalar-math Atn
SUB Main()
    # rise/run — наклон. При run=0 помощник даёт запасной 0, не вертикальный угол.
    # SlopeDegrees(1,1)≈45; все квадранты не различаются.

    VAR value = SlopeDegrees(1,1)
    UO.Print(CStr(value))
END SUB

SUB SlopeDegrees(rise,run)
    IF run = 0 THEN
        RETURN 0
    END IF
    RETURN Atn(CDbl(rise)/CDbl(run))*180/3.141592653589793
END SUB
```

**Разбор параметров и выполнения:**

- rise/run — наклон. При run=0 помощник даёт запасной 0, не вертикальный угол. SlopeDegrees(1,1)≈45; все квадранты не различаются.

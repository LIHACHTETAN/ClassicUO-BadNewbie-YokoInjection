# UO.Backpack

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->

Возвращает ID надетого рюкзака текущего персонажа.

## Точный синтаксис

```text
UO.Backpack() -> Integer
```

Выберите одну из зарегистрированных форм. Параметры передаются позиционно. Any означает значение BASIC с преобразованием внутри команды; Unit — отсутствие возвращаемого значения.

## Параметры

Параметров нет.

## Возвращает

Integer — serial/ID, не graphic/type, слой, количество предметов или Boolean. 0 — текущего объекта нет. Сохраняются все 32 бита serial; проверяйте <> 0, не = TRUE или > 0. Сохранённый результат сам не обновляется. Ищет неудалённый предмет на слое Backpack текущего Player. Нет/уничтожен Player, нет рюкзака или сумка удалена — 0. Возвращает контейнер, не содержимое; новую сумку не создаёт.

## Поведение

- Параметров нет. Читает локальные данные через Invoke на игровом потоке; отмена скрипта прерывает ожидание этого потока. Не посылает пакет, не открывает контейнер/target и не переносит предмет.
- Встроенное self/backpack без скобок читается заново, если его не перекрыла переменная скрипта. Строковые имена обрабатывает принимающая команда. В назначении переноса "self" означает рюкзак, а UO.Self() возвращает serial персонажа. Для ID контейнера явно используйте UO.Backpack().
- World.Clear удаляет Player; последующие чтения дают 0. Вход в мир или замена надетой сумки могут изменить ID. Отдельные чтения не атомарны. Ненулевой ID не доказывает подключение, разрешение сервера или загрузку содержимого.

### Пример 1. Прочитать и вывести ID

```vb

# Возвращает ID надетого рюкзака текущего персонажа.
#
# Integer — serial/ID, не graphic/type, слой, количество предметов или Boolean. 0 — текущего
# объекта нет. Сохраняются все 32 бита serial; проверяйте <> 0, не = TRUE или > 0. Сохранённый
# результат сам не обновляется. Ищет неудалённый предмет на слое Backpack текущего Player.
# Нет/уничтожен Player, нет рюкзака или сумка удалена — 0. Возвращает контейнер, не содержимое;
# новую сумку не создаёт.

SUB Main()
    # id сохраняет результат одного вызова; HEX форматирует serial для журнала. Пример ничего не
    # выбирает и не использует.

    VAR id = UO.Backpack()
    UO.Print('ID: ' + HEX(id))
END SUB
```

**Разбор параметров и выполнения:**

- id сохраняет результат одного вызова; HEX форматирует serial для журнала. Пример ничего не выбирает и не использует.

### Пример 2. Обнаружить изменение ID

```vb
# Обнаружить изменение ID
#
# Возвращает ID надетого рюкзака текущего персонажа.
#
# Integer — serial/ID, не graphic/type, слой, количество предметов или Boolean. 0 — текущего
# объекта нет. Сохраняются все 32 бита serial; проверяйте <> 0, не = TRUE или > 0. Сохранённый
# результат сам не обновляется. Ищет неудалённый предмет на слое Backpack текущего Player.
# Нет/уничтожен Player, нет рюкзака или сумка удалена — 0. Возвращает контейнер, не содержимое;
# новую сумку не создаёт.

SUB Main()
    # before/after читаются с интервалом 250 мс. WAIT добавлен только в пример. Равенство означает
    # одинаковые конечные ID; промежуточные изменения могут быть пропущены.

    VAR before = UO.Backpack()
    WAIT(250)
    VAR after = UO.Backpack()
    IF before <> after THEN
        UO.Print('ID changed: ' + HEX(after))
    END IF
END SUB
```

**Разбор параметров и выполнения:**

- before/after читаются с интервалом 250 мс. WAIT добавлен только в пример. Равенство означает одинаковые конечные ID; промежуточные изменения могут быть пропущены.

### Пример 3. Полная функция IsOwnSerial

```vb
# Полная функция IsOwnSerial
#
# Возвращает ID надетого рюкзака текущего персонажа.
#
# Integer — serial/ID, не graphic/type, слой, количество предметов или Boolean. 0 — текущего
# объекта нет. Сохраняются все 32 бита serial; проверяйте <> 0, не = TRUE или > 0. Сохранённый
# результат сам не обновляется. Ищет неудалённый предмет на слое Backpack текущего Player.
# Нет/уничтожен Player, нет рюкзака или сумка удалена — 0. Возвращает контейнер, не содержимое;
# новую сумку не создаёт.

SUB Main()
    # candidate — сохранённый ID LastTarget. IsOwnSerial(candidate) принимает один serial и
    # возвращает Integer Boolean: 1=TRUE для текущего ненулевого собственного ID, иначе 0=FALSE.
    # Определение функции приведено полностью; target не изменяется.

    VAR candidate = UO.LastTarget()
    IF IsOwnSerial(candidate) = TRUE THEN
        UO.Print('Own object selected')
    ELSE
        UO.Print('Different object or no own object')
    END IF
END SUB

SUB IsOwnSerial(candidate)
    VAR current = UO.Backpack()
    RETURN current <> 0 AND current = candidate
END SUB
```

**Разбор параметров и выполнения:**

- candidate — сохранённый ID LastTarget. IsOwnSerial(candidate) принимает один serial и возвращает Integer Boolean: 1=TRUE для текущего ненулевого собственного ID, иначе 0=FALSE. Определение функции приведено полностью; target не изменяется.

# UO.AutoBuy

ClassicUO • Runtime API • `UO.AutoBuy.md`

Создаёт или обновляет правило покупки по типу и цвету в основном списке текущего профиля. AutoBuyEx также задаёт максимальную цену и фильтр имени. Положительное Quantity — общий лимит этого правила на одно поступление списка товаров вендора, Quantity <= 0 удаляет соответствующее правило. Проверка выполняется при получении списка покупки. Дополнительные именованные списки не изменяются этой командой; выключенный основной список сам не включается. Общий переключатель автоматической покупки и переключатель списка должны быть включены. Совпадающие правила не суммируют количество и не отправляют повторный заказ одного serial.

## Точный синтаксис / Registered signatures

```text
UO.AutoBuy(ItemType:Any, ItemColor:Any, Quantity:Any) -> Unit
```

Порядок аргументов соответствует строкам выше. `Unit` означает отсутствие возвращаемого значения. `Any` — значение BASIC с преобразованием при вызове. Имена нечувствительны к регистру.

## Варианты использования

Это отдельные сценарии. Подставьте свои serial, пути и координаты; серверные действия зависят от текущего состояния игры.

### Прямой вызов

```vb
SUB Main()
    UO.AutoBuy(1, 2, 3)
END SUB
```

### Вызов с явно заданными аргументами

```vb
SUB Main()
    VAR arg1 = 1 # ItemType
    VAR arg2 = 2 # ItemColor
    VAR arg3 = 3 # Quantity
    UO.AutoBuy(arg1, arg2, arg3)
END SUB
```

### Выполнение действия внутри процедуры

```vb
SUB ReadResult()
    VAR arg1 = 1 # ItemType
    VAR arg2 = 2 # ItemColor
    VAR arg3 = 3 # Quantity
    UO.AutoBuy(arg1, arg2, arg3)
END SUB

SUB Main()
    ReadResult()
END SUB
```

## Реализация для проверки поведения

- `InjectionScript.Runtime.InjectionApiUO+<>c__DisplayClass41_0.<RegisterStealthCompatibility>b__0`

## Возвращает

Unit — команда не возвращает значение. Вызывайте её отдельной строкой. Не используйте её результат как serial, type или логический признак успеха. Завершение вызова само по себе не подтверждает выполнение действия сервером.

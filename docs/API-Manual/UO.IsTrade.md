# UO.IsTrade

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->

Проверяет наличие открытого окна безопасного обмена между персонажами.

## Точный синтаксис

```text
UO.IsTrade() -> Integer
```

Выберите одну из зарегистрированных форм. Параметры передаются позиционно. Any означает значение BASIC с преобразованием внутри команды; Unit — отсутствие возвращаемого значения.

## Параметры

Параметров нет.

## Возвращает

Integer 1 — есть хотя бы один не закрытый TradingGump. Integer 0 — таких окон нет. Это не число обменов, не готовность другой стороны и не подтверждение завершённой передачи.

Это логический результат: 1 = TRUE, 0 = FALSE. После VAR result = команда(...) можно писать IF result = TRUE THEN или IF result = 1 THEN; для отрицательного результата — IF result = FALSE THEN или IF result = 0 THEN. TRUE/FALSE пишутся без кавычек. Вызовите команду один раз и сохраните результат: повторный вызов может повторить действие или прочитать уже изменившееся состояние.

## Поведение

- Читается локальная модель клиента; запросов серверу, ожидания и перемещения нет.
- Результат относится к моменту чтения. После WAIT или другого действия объект и его флаги могут измениться.
- Окна покупки/продажи NPC-вендора и обычные контейнеры не являются secure trade. Команда ничего не подтверждает и не отменяет.

## Примеры

### Пример 1. Проверить, открыт ли безопасный обмен

```vb
# Проверить, открыт ли безопасный обмен
#
# Проверяет наличие открытого окна безопасного обмена между персонажами.
#
# Integer 1 — есть хотя бы один не закрытый TradingGump. Integer 0 — таких окон нет. Это не
# число обменов, не готовность другой стороны и не подтверждение завершённой передачи.
#
# Это логический результат: 1 = TRUE, 0 = FALSE. После VAR result = команда(...) можно писать IF
# result = TRUE THEN или IF result = 1 THEN; для отрицательного результата — IF result = FALSE
# THEN или IF result = 0 THEN. TRUE/FALSE пишутся без кавычек. Вызовите команду один раз и
# сохраните результат: повторный вызов может повторить действие или прочитать уже изменившееся
# состояние.

SUB Main()
    # Аргументов нет; проверяются окна текущего клиента.
    # trade содержит 1/0. Наличие окна не означает, что обе стороны согласились.

    VAR trade = UO.IsTrade()
    IF trade THEN
        UO.Print('Secure trade is open')
    ELSE
        UO.Print('No secure trade')
    END IF
END SUB
```

**Разбор параметров и выполнения:**

- Аргументов нет; проверяются окна текущего клиента.
- trade содержит 1/0. Наличие окна не означает, что обе стороны согласились.

### Пример 2. Обнаружить закрытие окна

```vb
# Обнаружить закрытие окна
#
# Проверяет наличие открытого окна безопасного обмена между персонажами.
#
# Integer 1 — есть хотя бы один не закрытый TradingGump. Integer 0 — таких окон нет. Это не
# число обменов, не готовность другой стороны и не подтверждение завершённой передачи.
#
# Это логический результат: 1 = TRUE, 0 = FALSE. После VAR result = команда(...) можно писать IF
# result = TRUE THEN или IF result = 1 THEN; для отрицательного результата — IF result = FALSE
# THEN или IF result = 0 THEN. TRUE/FALSE пишутся без кавычек. Вызовите команду один раз и
# сохраните результат: повторный вызов может повторить действие или прочитать уже изменившееся
# состояние.

SUB Main()
    # Два снимка разделены паузой 500 мс.
    # Закрытие может означать успешный обмен или отмену. По IsTrade нельзя различить эти причины.

    VAR before = UO.IsTrade()
    WAIT(500)
    VAR after = UO.IsTrade()
    IF before = 1 AND after = 0 THEN
        UO.Print('Secure trade window closed')
    END IF
END SUB
```

**Разбор параметров и выполнения:**

- Два снимка разделены паузой 500 мс.
- Закрытие может означать успешный обмен или отмену. По IsTrade нельзя различить эти причины.

### Пример 3. Ограниченно ждать появления обмена

```vb
# Ограниченно ждать появления обмена
#
# Проверяет наличие открытого окна безопасного обмена между персонажами.
#
# Integer 1 — есть хотя бы один не закрытый TradingGump. Integer 0 — таких окон нет. Это не
# число обменов, не готовность другой стороны и не подтверждение завершённой передачи.
#
# Это логический результат: 1 = TRUE, 0 = FALSE. После VAR result = команда(...) можно писать IF
# result = TRUE THEN или IF result = 1 THEN; для отрицательного результата — IF result = FALSE
# THEN или IF result = 0 THEN. TRUE/FALSE пишутся без кавычек. Вызовите команду один раз и
# сохраните результат: повторный вызов может повторить действие или прочитать уже изменившееся
# состояние.

SUB Main()
    # Максимум 10 пауз по 200 мс. Последний вызов читает актуальное состояние после цикла.
    # Скрипт только наблюдает окно. Он не переносит предметы и не нажимает подтверждение обмена.

    VAR attempts = 0
    WHILE UO.IsTrade() = 0 AND attempts < 10
        WAIT(200)
        attempts = attempts + 1
    WEND
    UO.Print('Trade open 1/0: ' + STR(UO.IsTrade()))
END SUB
```

**Разбор параметров и выполнения:**

- Максимум 10 пауз по 200 мс. Последний вызов читает актуальное состояние после цикла.
- Скрипт только наблюдает окно. Он не переносит предметы и не нажимает подтверждение обмена.

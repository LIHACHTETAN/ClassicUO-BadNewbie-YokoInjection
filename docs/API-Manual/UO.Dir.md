# UO.Dir

ClassicUO • Runtime API

<!-- yoko-manual: 1 -->

Читает направление персонажа из модели клиента.

## Точный синтаксис

```text
UO.Dir() -> Integer
```

Выберите одну из зарегистрированных форм. Параметры передаются позиционно. Any означает значение BASIC с преобразованием внутри команды; Unit — отсутствие возвращаемого значения.

## Параметры

Параметров нет.

## Возвращает

Integer — направление mobile без бита бега: 0=N, 1=NE, 2=E, 3=SE, 4=S, 5=SW, 6=W, 7=NW. Для неизвестного mobile возвращается 0, которое также означает север.

## Поведение

- Читаются уже полученные локальные данные. Запрос не открывает status и не заставляет сервер прислать обновление. После смерти, перехода карты или удаления объекта значения могут измениться между двумя вызовами.
- Это функции чтения: присваивание результата переменной сохраняет снимок. Оно не изменяет характеристику персонажа. Имена нечувствительны к регистру; используйте именно показанную форму с нужным числом аргументов.

## Примеры

### Пример 1. Вывести текущее значение своего персонажа

```vb
# Вывести текущее значение своего персонажа
#
# Читает направление персонажа из модели клиента.
#
# Integer — направление mobile без бита бега: 0=N, 1=NE, 2=E, 3=SE, 4=S, 5=SW, 6=W, 7=NW. Для
# неизвестного mobile возвращается 0, которое также означает север.

SUB Main()
    # Вызов без аргументов относится к self. Направление персонажа сохраняется в value.
    # STR преобразует число для вывода и не меняет смысл результата.

    VAR value = UO.Dir()
    UO.Print('Dir: ' + STR(value))
END SUB
```

**Разбор параметров и выполнения:**

- Вызов без аргументов относится к self. Направление персонажа сохраняется в value.
- STR преобразует число для вывода и не меняет смысл результата.

#
# Читает направление персонажа из модели клиента.

### Пример 3. Наблюдать изменение за одну секунду

```vb
# Наблюдать изменение за одну секунду
#
# Читает направление персонажа из модели клиента.
#
# Integer — направление mobile без бита бега: 0=N, 1=NE, 2=E, 3=SE, 4=S, 5=SW, 6=W, 7=NW. Для
# неизвестного mobile возвращается 0, которое также означает север.

SUB Main()
    # Оба вызова без аргумента читают своё текущее значение. WAIT(1000) даёт паузу в миллисекундах
    # между снимками.
    # Сравнивается изменение: направление персонажа. Пример ничего не изменяет в мире и не ждёт
    # бесконечно. События внутри этой секунды могут быть пропущены.

    VAR before = UO.Dir()
    WAIT(1000)
    VAR after = UO.Dir()
    IF before <> after THEN
        UO.Print('Before: ' + STR(before) + '; after: ' + STR(after))
    END IF
END SUB
```

**Разбор параметров и выполнения:**

- Оба вызова без аргумента читают своё текущее значение. WAIT(1000) даёт паузу в миллисекундах между снимками.
- Сравнивается изменение: направление персонажа. Пример ничего не изменяет в мире и не ждёт бесконечно. События внутри этой секунды могут быть пропущены.

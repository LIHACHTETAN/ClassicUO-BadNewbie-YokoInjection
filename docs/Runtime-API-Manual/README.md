# ClassicUO - Bad Newbie & Basic IDE — API Manual

[Current command cards and Basic language](../API-Manual/README.md)

The GitHub copy is synchronized with the external API Manual shipped in the source project and client. Command names, parameters, return contracts, runnable examples and Basic language guides are stored as separate editable files.

The registry lists 802 command names. Detailed semantic review and translations are still being completed; this is not a claim that every game-server action has been tested.
